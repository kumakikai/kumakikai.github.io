{{< guide-anchor "1-基本方針" >}}
## 1. はじめに

{{< document-copy "privacyIntroduction" >}}

本アプリは、自分のペースで家族に意思を伝えるためのアプリです。本ポリシーは、公開準備中のiPhone版について定めます。

{{< guide-anchor "1-取得する情報と目的" "2-本アプリが扱う情報" >}}
## 2. 取得する情報

- **表示名と接続情報**：入力した表示名、本人・家族の役割、招待、接続の承認・解除、通信の休止など。本名や年齢の登録は求めません。
- **通信内容と設定**：意思表示、定型返信、依頼、会話のメッセージ、送信日時、会話の開始・終了、カスタマイズしたアイコンや定型文。「少ししんどい」など、利用者が選んで伝えた体調・気分の内容を含みます。健康状態を自動で測定・分析しません。
- **端末・認証情報**：インストールや認証の識別情報、端末の登録・失効状態、正規アプリの確認に使う鍵の識別子・公開鍵・検証結果。App Attestの秘密鍵はサーバーに保存しません。
- **通知情報**：通知を許可した端末の通知用トークンと配信先。
- **おためし・購入情報**：開始・終了日時、利用済みの記録、プラン、取引の識別情報、有効期限、更新・失効・返金などの状態。
- **技術的な記録**：通信の成否、エラーの種類、応答時間など。運用ログに通信本文、認証用の秘密情報、購入証明全文を記録しない設計です。接続元の情報をハッシュ化した短期間の記録も使います。
- **お問い合わせ情報**：種類、内容、任意のサポート情報、返信用メールアドレス。サポート情報と返信用メールアドレスは空欄でも送信できます。

「サポート情報をコピー」は、アプリ名、バージョン・ビルド番号、OS、端末の種類、選んだ使い方、言語、アプリ環境を端末内へコピーする操作です。自動送信はせず、利用者がフォームやメールに貼り付けて送った場合に受け取ります。

{{< guide-anchor "4-取得しない情報" "7-広告について" >}}
### 登録・取得を求めない情報

メールアドレスやパスワードによる会員登録はありません。ただし、安全に通信するための内部の認証情報は作成します。Apple Accountのメールアドレス、パスワード、クレジットカード番号は取得しません。

広告、広告目的の追跡、行動分析のためのSDKは使いません。位置情報、端末の連絡先、カメラ、マイクへアクセスしません。家族との接続情報はアドレス帳から取得するものではありません。

## 3. 情報の利用目的

表示名や接続情報は相手の確認と通信範囲の管理に、通信内容と設定は家族への配信・同期・引き継ぎに使います。通知情報はAppleのプッシュ通知に使います。

端末・認証情報は正規アプリの確認、なりすましや同じ要求の再利用防止に使います。おためし・購入情報は利用可否の判定、購入の復元、不正な繰り返し利用の防止に使います。技術的な記録は障害調査と安全な運用、アクセス集中の抑制に使います。お問い合わせ情報は回答と問題の解決に使います。

{{< guide-anchor "2-保存先と家族への共有" "3-保存と同期について" >}}
## 4. 情報の保存・管理

設定や通信の控えは端末内に、認証用の資格情報は端末の保護された保存領域に保存します。通信、同期、引き継ぎ、認証、購入確認に必要な情報はAWSへ送信し、主に東京リージョンに保存します。通信を保護し、接続関係と操作権限を確認して管理します。

端末だけに保存されるサービスや、運営者も復号できない方式の通信ではありません。

{{< guide-anchor "4-保存期間" >}}
### 保存期間

| 情報 | 保存期間・扱い |
|---|---|
| 家族との接続、通信内容、カスタマイズ、引き継ぎ用の控え | 対象となるデータを削除するまで保存します。会話を閉じることや、7日間のおためしの終了だけでは削除されません。 |
| 通知の配信先、通常の端末認証情報、検証用の公開鍵 | 利用中は保持し、引き継ぎ・接続解除・削除の対象に応じて失効・削除します。 |
| 招待・引き継ぎの一時情報 | 招待は通常30日、引き継ぎコードは通常7日が有効期限です。使用後の引き継ぎ応答の回復用記録は24時間です。期限切れの記録は順次削除します。 |
| 使い捨ての端末・購入確認情報 | 利用できる期間は2〜5分です。その期限から1時間後を削除対象時刻とします。 |
| 家族のおためし開始・終了日時 | 家族データの削除まで保持します。 |
| おためし利用済み・旧認証の再利用防止の記録 | 元の表示名や通信本文ではなく、ハッシュ化した識別情報と必要最小限の状態を保持します。再取得・旧端末の不正な復活を防ぐため固定日数での自動削除は行わず、この認証・おためし制度を提供する期間中に限って使います。 |
| 購入の復元に使う識別情報 | Appleが発行するNocca向け識別情報のハッシュと、購入時にAppleへ渡したランダムな照合用IDの対応を保持します。削除後の復元でも以前の正当な購入を照合するための記録で、家族の所属情報は切り離します。固定日数での自動削除は行いません。 |
| 現在の購入状態 | 契約の有効期限・猶予期限・最後のサーバー処理時刻のうち最も遅い時点から、400日後を削除対象時刻にします。更新が続く契約ではこの時刻も更新されます。 |
| 個々の取引の処理記録 | その取引の有効期限から400日後を削除対象時刻にします。 |
| Appleからの通知の重複処理防止記録 | 受信・処理から400日後を削除対象時刻にします。 |
| 運用ログ | 30日です。通信の集中を抑えるための短期記録は約2分です。 |

期限付きのデータは自動削除の対象となった後、クラウド側の処理により削除されます。削除対象時刻と物理的な消去時刻は一致しないことがあります。期限が過ぎた確認情報や利用権を、その遅延を理由に有効として扱うことはありません。

障害復旧用の自動バックアップは最大35日間です。更新作業などで作成する一時的なバックアップは、自動削除とは別に管理し、復旧に必要な確認を終えた後35日以内に運営者が削除します。これらには削除前のデータが残ることがあります。通常利用には戻さず、復旧時にも削除済みの情報を再び利用可能にしないよう取り扱います。

お問い合わせの記録は、対応が完了してから1年以内に削除する運用とします。継続中の問題や法令上の対応に必要な記録は、必要な範囲で期間を見直します。固定日数で自動削除しない照合情報も、その目的を廃止した後まで保持し続ける方針ではありません。購入経験のない方についても、後の購入確認に備える照合用IDが作成されます。


{{< guide-anchor "6-外部サービスと安全管理" "6-第三者サービスについて" >}}
## 5. 外部サービス・第三者提供

AWSを認証、データ保存、通知中継、運用ログに、Appleをアプリの安全性確認、購入・復元、契約状態の通知、プッシュ通知に利用します。目的に必要な情報を送り、委託先の選定、アクセス権の制限、通信・保存時の保護により管理します。

お問い合わせフォームと回答の保存にはGoogle Formsを、メールの受付・返信にはGoogleのGmailを利用します。外部サービス自身が扱う情報には各社のポリシーも適用されます。これらはアプリ内の広告・行動分析SDKではありません。

利用者が選んだ家族への通信、サービス提供に必要な委託、法令に基づく場合を除き、情報を第三者に提供しません。広告のためのデータ販売や他社データとの照合は行いません。

{{< guide-anchor "5-通信内容について" >}}
## 6. 家族への共有と通知

表示名、承認した接続関係、意思表示・返信・会話、共有に必要な設定は、接続した家族が確認できます。有効な契約がある場合は家族全体の利用可否を共有します。Apple Account、購入取引の識別子、認証情報を家族に表示しません。

プッシュ通知には一般的なお知らせ文と、必要な画面を開くための識別情報を含めます。意思表示・会話の本文や家族の表示名を含めません。通知はiPhoneの設定で変更できます。

{{< guide-anchor "3-おためしとサブスクリプション" "8-課金について" >}}
## 7. おためし・購入情報の処理

独自の7日間のおためしは、本人が最初の家族との接続を承認した時点から始まります。Appleでの購入やサブスクリプション登録は不要です。サーバーで期間を管理するため、端末の時計では延長できません。

再インストールや家族の作り直しによる繰り返し利用を防ぐため、Appleが本アプリ向けに発行する安定した識別情報をハッシュ化し、利用済み記録と照合します。広告IDや端末の特徴を組み合わせた追跡は行いません。

App Storeから受け取る署名付き購入情報と契約状態の通知を検証し、家族内の有効な契約、更新、期限終了、返金・取り消しを反映します。署名付きデータ全文は検証のため受信しますが、長期保存しません。

Appleの対象者向け14日間無料トライアルは、独自のおためしとは別です。購入後の契約管理・解約はApple側で行います。

{{< guide-anchor "5-削除と利用者の選択" >}}
## 8. 利用者によるデータ管理・削除

「設定 > データ管理 > すべてのデータを削除」から削除できます。おためしや契約の期限が過ぎていても利用できます。

本人側ではその家族全体の接続・通信データを、家族側ではその人の接続と対象データを削除します。家族側の削除で本人とほかの家族のグループは消えません。状態を矛盾させないため、本文を除いた完了・取り消し等の状態が残る場合があります。

サーバーで接続と資格情報の失効を確定した後に、端末内の状態を消去します。クラウド・通知サービス上の削除は再試行を含めて順次行います。不正利用防止、購入の整合性、ログ、バックアップの記録は「保存期間」に記載した範囲で残り、すべてが同時に完全消去されるわけではありません。

アンインストール、データ削除、家族からの離脱ではAppleのサブスクリプションは解約されません。購入した方がApple側で解約してください。相手のスクリーンショットなど、本アプリが管理しない控えは削除できません。

{{< guide-anchor "7-年齢について" "10-未成年の利用について" >}}
## 9. 未成年者の利用

本アプリは年齢・生年月日を取得せず、年齢や法定代理人の同意を自動確認する仕組みはありません。「本人」「家族」は年齢を表す役割ではありません。未成年の利用者は、利用や購入に法令上必要な同意について、保護者などの法定代理人と確認してください。
