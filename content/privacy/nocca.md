Noccaは、自分のペースで家族に意思を伝えるためのアプリです。このポリシーは、現在公開準備中のNocca正式公開版で扱う情報について説明します。

## 1. 取得する情報と目的

- **表示名と家族との接続情報**：入力した表示名、アプリ内の本人・家族の役割、招待、接続の承認・解除、通信の休止などを扱います。接続相手の確認と、本人が選んだ範囲で通信するために使います。本名や年齢の登録は求めません。
- **通信内容と設定**：送信した意思表示、定型返信、依頼、会話のメッセージ、送信日時、会話の開始・終了、カスタマイズしたアイコンや定型文を扱います。家族への配信、端末間の同期、引き継ぎに使います。「少ししんどい」など、利用者が選んで伝えた体調・気分に関する内容も含まれます。健康状態を自動で測定・分析する機能はありません。
- **端末と認証の情報**：アプリのインストールを識別するID、認証用ID、端末の登録・失効状態、正規アプリであることを確認するための鍵の識別子・公開鍵・検証結果を扱います。不正な登録やなりすまし、同じ要求の再利用を防ぐために使います。App Attestの秘密鍵はサーバーに保存しません。
- **通知の情報**：通知を許可した端末の通知用トークンと配信先を扱います。Appleのプッシュ通知サービスを通じてお知らせするために使います。
- **無料体験と購入状態**：家族ごとのおためし開始・終了日時、利用済みの記録、購入したプラン、取引を識別する情報、有効期限、更新・失効・返金などの状態を扱います。利用できる機能の判定、購入の復元、不正利用の防止に使います。
- **技術的な記録**：通信の成否、エラーの種類、応答時間などを記録します。障害の調査とサービスの安全な運用に使います。運用ログに通信本文、認証用の秘密情報、購入証明の全文を記録しない設計です。アクセスの集中を抑えるため、接続元の情報をハッシュ化した短期間の記録も使います。
- **お問い合わせ**：利用者が送信したメールアドレス、名前、相談内容などを、回答と問題の解決のために扱います。お問い合わせに、パスワード、引き継ぎコード、家族の通信全文などを記載する必要はありません。

メールアドレスやパスワードによる会員登録はありません。Apple Accountのメールアドレス、パスワード、クレジットカード番号をNoccaが取得することはありません。

広告、広告目的の追跡、行動分析のためのSDKは使っていません。位置情報、端末の連絡先、カメラ、マイクへのアクセスも行いません。家族との接続情報は、端末のアドレス帳を読み取って作成するものではありません。

## 2. 保存先と家族への共有

画面の設定や通信の控えなどは端末内に、認証用の資格情報は端末の保護された保存領域に保存します。家族との通信、端末間の同期、引き継ぎ、認証、購入状態の確認に必要な情報は、AWSのクラウドサービスへ送信し、主に東京リージョンに保存します。通信にはHTTPSを使い、サーバー側で接続関係と操作権限を確認します。端末だけに保存されるサービスや、運営者も復号できない方式の通信ではありません。

表示名、承認した接続関係、送った意思表示・返信・会話、共有に必要な設定は、接続した家族が確認できます。家族の誰かが契約している場合は、家族全体の利用可否を共有します。相手のApple Account、購入取引の識別子、認証情報を家族へ表示することはありません。

プッシュ通知は一般的なお知らせ文と、必要な画面を開くための識別情報をAppleへ送ります。意思表示や会話の本文をプッシュ通知に含めません。通知はiPhoneの設定で変更できます。

## 3. おためしとサブスクリプション

Nocca独自の7日間のおためしは、本人が最初の家族との接続を承認した時点から始まります。Appleでの購入やサブスクリプション登録は不要です。開始・終了はサーバーで管理し、端末の時計では延長できません。

再インストールや家族の作り直しによる繰り返し利用を防ぐため、AppleがNocca向けに発行する安定した識別情報をハッシュ化し、おためし利用済みの記録と照合します。広告IDや端末の特徴を組み合わせた追跡は行いません。

サブスクリプションはAppleのApp Storeを通じて購入します。NoccaはAppleの署名付き購入情報を検証し、同じ家族内で1件以上の有効な契約があるかを確認します。Appleから届くサーバー通知も検証し、更新、期限終了、返金・取り消しを反映します。購入証明や通知の署名付きデータ全文は、検証のために受信しますが、長期保存しません。

Appleの14日間無料トライアルは、Appleが対象と判断した方だけに適用される別の制度です。Nocca独自のおためしと区別され、購入後の管理・解約はApple側で行います。

## 4. 保存期間

| 情報 | 保存期間・扱い |
|---|---|
| 家族との接続、通信内容、カスタマイズ、引き継ぎ用の控え | 対象となるデータを削除するまで保存します。会話を閉じることや、7日間のおためしの終了だけでは削除されません。 |
| 通知の配信先、通常の端末認証情報、検証用の公開鍵 | 利用中は保持し、引き継ぎ・接続解除・削除の対象に応じて失効・削除します。 |
| 招待・引き継ぎの一時情報 | 招待は通常30日、引き継ぎコードは通常7日が有効期限です。使用後の引き継ぎ応答の回復用記録は24時間です。期限切れの記録は順次削除します。 |
| 使い捨ての端末・購入確認情報 | 利用できる期間は2〜5分です。その期限から1時間後を削除対象時刻とします。 |
| 家族のおためし開始・終了日時 | 家族データの削除まで保持します。 |
| おためし利用済み・旧認証の再利用防止の記録 | 元の表示名や通信本文ではなく、ハッシュ化した識別情報と必要最小限の状態を保持します。再取得・旧端末の不正な復活を防ぐため固定日数での自動削除は行わず、この認証・おためし制度を提供する期間中に限って使います。 |
| 購入の復元に使う識別情報 | Appleが発行するNocca向け識別情報のハッシュと、購入時にAppleへ渡したランダムな照合用IDの対応を保持します。削除後の復元でも以前の正当な購入を照合するための記録で、家族の所属情報は切り離します。固定日数での自動削除は行いません。 |
| 現在の購入状態 | 契約の有効期限・猶予期限・最後のサーバー処理時刻のうち最も遅い時点から、400日後を削除対象時刻にします。更新が続く契約ではこの時刻も更新されます。 |
| 個々の取引の処理記録 | その取引の有効期限から400日後を削除対象時刻にします。 |
| Appleからの通知の重複処理防止記録 | 受信・処理から400日後を削除対象時刻にします。 |
| 運用ログ | 30日です。通信の集中を抑えるための短期記録は約2分です。 |

期限付きのデータは自動削除の対象となった後、クラウド側の処理により削除されます。削除対象時刻と物理的な消去時刻は一致しないことがあります。期限が過ぎた確認情報や利用権を、その遅延を理由に有効として扱うことはありません。

障害復旧用の自動バックアップは最大35日間です。更新作業などで作成する一時的なバックアップは、自動削除とは別に管理し、復旧に必要な確認を終えた後35日以内に運営者が削除します。これらには削除前のデータが残ることがあります。通常利用には戻さず、復旧時にも削除済みの情報を再び利用可能にしないよう取り扱います。

お問い合わせの記録は、対応が完了してから1年以内に削除する運用とします。継続中の問題や法令上の対応に必要な記録は、必要な範囲で期間を見直します。固定日数で自動削除しない照合情報も、その目的を廃止した後まで保持し続ける方針ではありません。購入経験のない方についても、後の購入確認に備える照合用IDが作成されます。

## 5. 削除と利用者の選択

アプリの「設定」から「データ管理」→「すべてのデータを削除」を実行できます。おためしや契約の期限が過ぎていても利用できます。

本人側の削除では、その家族全体の接続・通信データを削除します。家族側の削除では、その人の接続と対象データを削除し、本人とほかの家族のグループは残します。通信上の状態を矛盾させないため、本文を除いた完了・取り消しなどの状態が残る場合があります。

サーバーで接続と資格情報の失効を確定してから、端末内の状態を消去します。クラウドや通知サービス上の後片付けは、失敗時の再試行を含めて順次行います。上記の不正利用防止、購入の整合性、ログ、バックアップに関する記録は、削除操作後も記載した範囲で残ります。「すべての情報が同時に完全消去される」という意味ではありません。

アプリのアンインストールやデータ削除、家族からの離脱だけでは、Appleのサブスクリプションは解約されません。購入した方がAppleのサブスクリプション設定で解約してください。相手がすでに受信した情報のスクリーンショットなど、Noccaが管理していない控えは削除できません。

情報の確認・訂正・利用停止・削除については、下記窓口でも相談できます。本人確認が必要な場合は、対象の特定に必要な最小限の方法を案内します。家族であることだけを理由に、ほかの利用者の情報を開示しません。法令に基づき対応し、応じられない部分がある場合は理由を説明します。

## 6. 外部サービスと安全管理

AWSを認証、データ保存、通知中継、運用ログに利用し、Appleをアプリの安全性確認、購入・復元、契約状態の通知、プッシュ通知に利用します。各社へは目的に必要な範囲の情報を送ります。委託先の選定とアクセス権の制限、通信・保存時の保護などにより情報を管理します。

お問い合わせメールにはGoogleのGmailを、公式ページの配信にはGitHub Pagesを利用しています。外部サービス自身が扱う情報については各社のポリシーもご確認ください。これらはアプリ内の広告・行動分析SDKではありません。

利用者が選んだ家族への通信、上記のサービス提供に必要な委託、法令に基づく場合を除き、情報を第三者に提供しません。広告のためのデータ販売や他社データとの照合は行いません。

## 7. 年齢について

Noccaは年齢や生年月日を取得せず、アプリ内で年齢の確認や法定代理人の同意確認を自動で行う仕組みはありません。「本人」「家族」は年齢を表す役割ではありません。未成年の方は、法令上同意が必要な利用や購入について、保護者などの法定代理人と確認してください。
