オトミルは、iPhone / iPadのマイクで拾った音声を、大きな日本語字幕で表示します。

> このガイドは最新の提出用素材と開発版で確認した画面に基づきます。現在App Storeで配信中のバージョンとは、画面や設定が異なる場合があります。字幕の画像は操作説明用のサンプルです。

## 利用前に確認すること {#1-利用前に確認すること}

iOS 26 / iPadOS 26以降で、Appleの日本語音声認識に対応した端末が必要です。初回はマイクの使用を許可し、必要な音声認識モデルを準備してください。

Apple Intelligenceの有効化は必須ではありません。音声や字幕本文は保存せず、その場で読むために使います。

{{< guide-anchor "2-表示モードを選ぶ" "シンプルモード高齢者" "3-字幕をはじめる" >}}
## 大きなボタンから字幕を始める {#start}

1. `テレビ`、`会話`、`グループ`から、使う場面のボタンをタップします。
2. 端末下側のマイクを、テレビのスピーカーや話す人の方へ向けます。

## 通常モードで場面を選ぶ {#standard-mode}

画面上部で用途を選び、下部の`字幕をはじめる`をタップします。右上の歯車から設定を開けます。

{{< guide-image src="images/guides/oto-miru/mode-and-settings.png" alt="通常モード上部のテレビ・会話・グループ・映画の切り替えと、右上の設定ボタン" mode="crop" >}}

{{< guide-image src="images/guides/oto-miru/start-caption.png" alt="通常モード下部の字幕をはじめるボタン" mode="crop" >}}

{{< guide-anchor "4-テレビで使う" "5-会話で使う" "6-グループ会話で使う" >}}
## 字幕を読む・向きを変える・終了する {#read-captions}

- **テレビ**：端末をスピーカーの近くへ置きます。横画面でも読めます。
- **会話・グループ**：端末下側のマイクを相手へ向けます。`戻す` / `反転`で字幕の向きを切り替えます。
- **終了**：`字幕を止める`をタップします。

{{< guide-image src="images/guides/oto-miru/caption-and-controls.png" alt="会話字幕のサンプルと、字幕を止める・反転ボタン" mode="screen" >}}

{{< guide-anchor "7-映画で使う" >}}
## 映画モードを使う {#movie}

通常モードで`映画`を選び、注意案内を確認します。`OK`で暗い字幕表示へ進み、`キャンセル`で戻ります。

> 映画館などでは施設のルールを確認してください。シンプルモードには映画ボタンを表示しません。

{{< guide-anchor "9-設定を変更する" >}}
## 文字の大きさと聞き取り環境を変える {#settings}

字幕を止めてから、右上の歯車をタップします。

- `表示 > 高齢者向け`：大きな開始ボタンのシンプルモードへ切り替えます。
- `表示 > 字幕の文字サイズ`：プレビューを見ながら小・中・大を選びます。
- `表示 > テーマ`：システム・ライト・ダークを切り替えます。
{{< guide-image src="images/guides/oto-miru/display-settings.png" alt="表示設定の字幕の文字サイズ、高齢者向けスイッチ、テーマの切り替え" mode="crop" >}}

`音声の聞き取り（感度調整） > 周囲の環境`では、まず`モードに合わせる（おすすめ）`を使い、必要なら家の中・静かな屋外・屋外・にぎやかな場所へ変更します。

{{< guide-image src="images/guides/oto-miru/listening-environment.png" alt="音声の聞き取り設定で周囲の環境を選ぶ項目" mode="crop" >}}

{{< guide-anchor "8-無料版とオトミル-plus" >}}
## 利用時間とPlusを確認する {#usage}

ホームに今日の残り時間が表示されます。無料版は基本1日15分で、`広告を見て5分追加`を使うと当日の時間を追加できます。追加は1日3回までです。

{{< guide-image src="images/guides/oto-miru/free-time-and-plus.png" alt="シンプルモード下部の今日の残り無料時間、広告を見て5分追加、Plusに加入するボタン" mode="crop" >}}

Plusは時間制限なし・広告なしで利用するプランです。購入画面で現在の価格と適用条件を確認してください。購入済みの場合は購入画面の`購入を復元`を使います。

{{< guide-anchor "10-うまく字幕が出ないとき" "音声が入らない" "端末非対応と表示される" "apple-intelligence-を有効にしてくださいと表示される" "字幕の精度が低い" >}}
## 字幕が出ないとき {#troubleshooting}

マイク権限、端末の対応状態、音源との距離を確認します。個別の原因は[よくある質問]({{< relref "/faq/oto-miru/" >}}#トラブルシューティング)をご覧ください。
