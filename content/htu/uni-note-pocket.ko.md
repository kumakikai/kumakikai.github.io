Uni:Note 백업을 iPhone에 가져와 노트·스티커·문제집을 복습합니다. Pocket에서는 노트를 만들거나 편집·동기화하지 않습니다. 이미지를 탭하면 확대됩니다.

{{< guide-anchor "1-처음-안내를-확인합니다" "2-홈-화면-오른쪽-아래의-가져오기-아이콘에서-백업을-선택합니다" >}}

## 1. 백업 가져오기 {#import}

1. iPad의 Uni:Note에서 백업 zip을 내보내 iPhone의 파일 앱에서 선택할 수 있는 곳에 저장합니다.
2. Pocket의 첫 안내를 닫고 홈 오른쪽 아래의 가져오기 아이콘을 탭합니다.
3. zip을 선택하고 검사·가져오기가 끝날 때까지 기다립니다.

{{< guide-image src="images/guides/uni-note-pocket/ko/import-backup.png" alt="Pocket 홈 아래의 가져오기 버튼과 노트 제목 검색창" mode="crop" >}}

zip을 풀지 말고 그대로 선택하세요. 원본 백업은 변경하지 않습니다. 가져오기에 실패해도 이전에 가져온 데이터는 유지됩니다.

{{< guide-anchor "4-홈에서-노트와-문제집을-전환합니다" "5-노트를-열고-페이지를-봅니다" "6-페이지-화면에서-확대해서-봅니다" >}}

## 2. 노트 열기와 제목 검색 {#read}

**노트**에서 과목을 선택하고 노트 목록에서 엽니다. 최근 사용한 노트에서는 바로 이어 볼 수 있습니다.

{{< guide-image src="images/guides/uni-note-pocket/ko/open-note.png" alt="노트·문제집·최근 노트·과목 목록" mode="crop" >}}

검색창에 제목 일부를 입력하면 모든 과목의 노트를 찾습니다. 손글씨·본문·PDF·과목 이름은 검색하지 않습니다.

{{< guide-image src="images/guides/uni-note-pocket/ko/search-notes.png" alt="Pocket의 노트 제목 검색창" mode="crop" >}}

보통 노트는 세로로 스크롤하고 핀치·두 번 탭으로 확대합니다. 세로 노트는 가로로 넘깁니다. 설정의 이전 위치에서 재개를 켜면 마지막으로 보던 페이지부터 이어 볼 수 있습니다.

{{< guide-image src="images/guides/uni-note-pocket/ko/page-review.png" alt="Pocket의 연속 페이지와 확대 화면" mode="screen" >}}

## 3. 스티커와 문제집 복습 {#review}

페이지의 스티커를 탭해 일반 표시와 흐린 표시를 전환하며 답을 확인합니다. 스티커를 만들거나 수정하려면 iPad의 Uni:Note를 사용하세요.

{{< guide-image src="images/guides/uni-note-pocket/ko/sticky-review.png" alt="가져온 노트의 스티커 복습 화면" mode="crop" >}}

백업에 문제집이 있다면 홈에서 문제집을 엽니다. 답을 숨기고 생각한 뒤 탭해 확인하고 이전·다음으로 넘깁니다. Pocket에서는 문제집을 생성하거나 편집하지 않습니다.

{{< guide-image src="images/guides/uni-note-pocket/ko/practice-answer.png" alt="문제·답과 이전·다음 버튼" mode="screen" >}}

## 4. 가져온 녹음 듣기 {#recordings}

1. 녹음 데이터가 있는 노트를 엽니다.
2. 페이지 화면에서 녹음 재생을 탭합니다. 여러 개라면 목록에서 고릅니다.
3. 재생·일시정지, 위치, 속도를 조정합니다.

백업에 오디오 파일이 포함되어 있어야 재생할 수 있습니다. 녹음·문자 변환·AI 요약은 iPad의 Uni:Note에서 합니다.

{{< guide-anchor "10-설정을-조정합니다" >}}

## 5. 읽기 설정 조정 {#settings}

홈 오른쪽 위의 톱니바퀴를 엽니다. 언어·테마·이전 위치 재개·가로 밀림 방지를 바꿀 수 있습니다. 최상위 이름은 과목·노트·그룹·카테고리에서 고릅니다.

가로 밀림 방지는 일반 세로 읽기 화면을 안정적으로 유지하는 설정입니다. 노트 내용은 변경하지 않습니다.

{{< guide-anchor "3-간편-백업을-사용합니다" "11-더-새로운-백업을-다시-읽습니다" >}}

## 6. 새 백업으로 갱신 {#refresh}

iPad에서 수정한 뒤 새 백업을 만들어 Pocket에서 다시 가져옵니다. 간편 백업이 있으면 **설정 → 간편 백업**을 엽니다.

1. 마지막 업데이트 오른쪽의 갱신 아이콘으로 iCloud 파일 상태를 다시 확인합니다.
2. 날짜를 확인하고 수동으로 읽기를 탭합니다.
3. 실행 때마다 읽으려면 실행 시 자동 읽기를 켭니다.

갱신 아이콘은 파일 상태를 확인합니다. 새 파일이 아직 도착하지 않으면 날짜는 바뀌지 않습니다. 실시간 동기화나 iPad에 다시 쓰기는 하지 않습니다.
