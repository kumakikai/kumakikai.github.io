記事を探す、読む、配信源を選ぶ操作を紹介します。ログインは不要です。

{{< guide-anchor "2-まずは-today-を見る" >}}
{{< guide-anchor "3-creators-と-news-を使い分ける" >}}

## 1. タブを選んで記事を探す {#browse}

1. 中央の **TODAY** で記事をまとめて確認します。
2. 個人発信を読むときは **CREATORS**、一般ニュースは **NEWS** をタップします。
3. 読みたい記事カードをタップします。

{{< guide-image src="images/guides/signal/tabs-and-article.png" alt="SIGNAL上部の3タブと、右上にグッド・バッドのボタンがある記事カード" mode="crop" >}}

一覧を下へ引くと再読み込みできます。カード右上の **グッド／バッド** は、次の読み込み時の表示傾向に反映されます。同じボタンをもう一度タップすると取り消せます。

{{< guide-anchor "4-記事を開く" >}}

## 2. 記事を読む・共有する {#read}

記事はアプリ内ブラウザで開きます。

1. 読み終えたら、左上の **×** で一覧へ戻ります。
2. 共有するときは右上の **⋮** をタップし、**共有** を選びます。

{{< guide-image src="images/guides/signal/article-menu.png" alt="SIGNALの記事画面上部にある閉じるボタンと右上のメニューボタン" mode="crop" >}}

同じメニューから **再読み込み**、**外部ブラウザで開く** も選べます。

{{< guide-anchor "5-設定-を調整する" >}}

## 3. 配信源を選ぶ {#sources}

1. 記事一覧の右上にある **歯車** をタップします。
2. **記事取得サイト設定** で、読みたい配信源のスイッチをオンにします。

{{< guide-image src="images/guides/signal/source-switches.png" alt="設定の「記事取得サイト設定」とnote・Zennの配信スイッチ" mode="crop" >}}

CREATORSではnote・Zenn・Qiita・Hatena・DevelopersIO、NEWSではYahooニュース・Google Newsを扱います。有効な配信源の記事はTODAYにも表示されます。

## 4. 文字サイズと配色を変える {#appearance}

**設定** の上部で、テーマと **文字サイズ（記事）** を選びます。記事を読む画面の文字を大きくしたいときは **Large** を選んでください。

{{< guide-image src="images/guides/signal/text-and-theme.png" alt="設定上部のテーマ選択とSmall・Normal・Largeの文字サイズ選択" mode="crop" >}}

{{< guide-anchor "1-初回はチュートリアルを見る" >}}

## 5. 案内を見直す・学習をリセットする {#settings-help}

初回の案内は、**設定 → チュートリアルを見る** から開き直せます。

表示傾向を最初から調整したい場合は、**設定 → 学習データをリセット → リセット** を選びます。

> リセットすると端末内の学習履歴が削除されます。表示が変わらない場合は、まず記事一覧を下へ引いて再読み込みしてください。

不具合の連絡は、設定下部の **要望・お問い合わせ** からメールを作成できます。
