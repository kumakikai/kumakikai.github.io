將 Uni:Note 備份匯入 iPhone，即可複習筆記、便利貼與題組。Pocket 不建立、編輯或同步筆記。點一下圖片可放大。

{{< guide-anchor "1-先閱讀第一次顯示的說明" "2-從首頁右下角的匯入圖示選擇備份" >}}

## 1. 匯入備份 {#import}

1. 在 iPad 的 Uni:Note 匯出備份 zip，儲存至 iPhone「檔案」App 可選取的位置。
2. 關閉 Pocket 首次使用說明，點首頁右下角的匯入圖示。
3. 選擇 zip，等待驗證與匯入完成。

{{< guide-image src="images/guides/uni-note-pocket/zh-hant/import-backup.png" alt="Pocket 首頁下方的匯入按鈕與筆記標題搜尋欄" mode="crop" >}}

不要解壓縮 zip，直接選取即可。原始備份不會被修改。若匯入失敗，仍會保留先前匯入的資料。

{{< guide-anchor "4-在首頁切換-筆記-與-題組" "5-開啟-筆記-並查看頁面" "6-在頁面畫面中放大閱讀" >}}

## 2. 開啟筆記、搜尋標題 {#read}

在 **筆記** 選擇科目，再從列表開啟筆記。也可從最近使用的筆記直接繼續閱讀。

{{< guide-image src="images/guides/uni-note-pocket/zh-hant/open-note.png" alt="筆記、題組、最近筆記及科目列表" mode="crop" >}}

在搜尋欄輸入部分標題，可搜尋所有科目的筆記。不會搜尋手寫、本文、PDF 或科目名稱。

{{< guide-image src="images/guides/uni-note-pocket/zh-hant/search-notes.png" alt="Pocket 的筆記標題搜尋欄" mode="crop" >}}

一般筆記以垂直捲動閱讀，雙指縮放或點兩下可放大。直式筆記以橫向翻頁。在設定開啟從上次位置繼續，即可從上次閱讀的頁面開始。

{{< guide-image src="images/guides/uni-note-pocket/zh-hant/page-review.png" alt="Pocket 的連續頁面與縮放畫面" mode="screen" >}}

{{< guide-anchor "8-複習-題組" "9-查看便利貼標記" >}}

## 3. 使用便利貼與題組複習 {#review}

點選頁面便利貼，在一般與淡化顯示間切換以確認答案。便利貼的建立、修改需使用 iPad 上的 Uni:Note。

{{< guide-image src="images/guides/uni-note-pocket/zh-hant/sticky-review.png" alt="匯入筆記的便利貼複習畫面" mode="crop" >}}

若備份包含題組，可從首頁題組開啟。先隱藏答案思考，再點一下顯示，使用上一題、下一題切換。Pocket 不生成或編輯題組。

{{< guide-image src="images/guides/uni-note-pocket/zh-hant/practice-answer.png" alt="題目、解答與上一題下一題按鈕" mode="screen" >}}

{{< guide-anchor "7-播放錄音" >}}

## 4. 聆聽匯入的錄音 {#recordings}

1. 開啟包含錄音資料的筆記。
2. 在頁面畫面點播放錄音；有多筆時從列表選取。
3. 操作播放、暫停、進度與速度。

只有備份包含音訊檔案時才能播放。錄音、轉錄和 AI 摘要請在 iPad 的 Uni:Note 操作。

{{< guide-anchor "10-調整設定" >}}

## 5. 調整閱讀設定 {#settings}

從首頁右上齒輪開啟設定，可調整語言、主題、從上次位置繼續及防止橫向偏移。最上層名稱可選科目、筆記、群組或分類。

防止橫向偏移可穩定一般垂直閱讀，不會修改筆記內容。

{{< guide-anchor "3-使用-簡單備份" "11-之後再讀取較新的備份" >}}

## 6. 更新至較新的備份 {#refresh}

iPad 修改筆記後，建立新備份並重新匯入 Pocket。若找到簡單備份，開啟 **設定 → 簡單備份**。

1. 點最後更新右側的更新圖示，重新確認 iCloud 檔案狀態。
2. 確認日期後，點手動讀取。
3. 若希望開啟 Pocket 時讀取，可開啟啟動時自動讀取。

更新圖示只確認檔案狀態。新檔案尚未送達時，日期不會變更。這不是即時同步，也不會寫回 iPad。
