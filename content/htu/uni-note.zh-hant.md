以下使用實際畫面說明 Uni:Note 3.4.0 的主要操作。點一下圖片可放大。使用 Apple Pencil 書寫，以手指捲動或移動貼附資料。

{{< guide-anchor "1-在首頁整理科目與資料夾" "2-開啟第一本筆記" >}}

## 1. 建立科目和第一本筆記 {#create}

1. 點首頁右下角的 **+**，再選擇 **新增科目**。

{{< guide-image src="images/guides/uni-note/zh-hant/create-menu.png" alt="首頁右下角 + 開啟的新增科目與建立資料夾選單" mode="crop" caption="點首頁右下角 + 後開啟的建立選單。" >}}

2. 選擇名稱、格線、紙張及封面顏色。
3. 開啟科目並輸入第一本筆記名稱；留白會使用今天的日期。

同一個 + 也能建立資料夾。把科目拖入即可整理；刪除資料夾後，科目會回到首頁。長按科目可修改名稱與紙張設定。

{{< guide-anchor "3-使用-apple-pencil-書寫" "4-用雙指縮放" "5-切換工具" "9-使用-尺" >}}

## 2. 選擇工具並書寫 {#write}

1. 在工具盤選擇筆、螢光筆或橡皮擦。
2. 使用 Apple Pencil 書寫，以雙指縮放。
3. 在最後一頁開始書寫時，會自動新增下一頁。

{{< guide-image src="images/guides/uni-note/common/writing-tools.png" alt="筆、螢光筆、橡皮擦、便利貼及復原工具盤" mode="crop" >}}

拖移工具盤可改變位置。從上方顯示尺，用手指移動、旋轉，再用 Pencil 沿著附近畫直線。範圍移動會選取完整手寫筆畫；照片、PDF、便利貼需分別操作。直式筆記以橫向翻頁，建立後無法更改方向。

{{< guide-anchor "6-使用-筆記列表-與-頁面列表" >}}

## 3. 切換筆記、搜尋標題 {#find}

在首頁搜尋欄輸入部分筆記標題，再點選結果。不會搜尋手寫內容、頁面本文、PDF 或科目名稱。

{{< guide-image src="images/guides/uni-note/zh-hant/home-search.png" alt="首頁的筆記標題搜尋欄" mode="crop" >}}

筆記內的 **筆記列表** 可開啟同科目的其他筆記或新增筆記。向左滑可重新命名、保護或刪除。**頁面列表** 可點縮圖跳轉，長按可刪除。

**3.5.0 發布前資訊：** 科目卡片的筆記列表捷徑，以及工具列、工具盤自訂屬於下一版本功能。目前公開的 3.4.0 請使用上述筆記畫面內的操作。

{{< guide-anchor "7-使用-其他" "8-使用照片與-pdf" >}}

## 4. 加入照片、PDF 與匯出 {#pdf}

1. 開啟筆記右上角的 **其他**。
2. 選擇照片、文件照片或 PDF 貼附。
3. 選擇要貼附的 PDF 頁面；跨頁資料可分割後貼入。

{{< guide-image src="images/guides/uni-note/zh-hant/attachment-menu.png" alt="照片、文件照片、PDF 貼附與匯出選單" mode="crop" >}}

{{< guide-image src="images/guides/uni-note/common/pdf-writing.png" alt="Uni:Note 中已加手寫註記的課程 PDF" mode="tablet" >}}

用手指選取附件以移動、縮放；點兩下可固定或解除固定，再用 Apple Pencil 寫在資料上。分享時選擇 **其他 → PDF 匯出**，匯出目前筆記或整個科目。背景可設為紙色或白色。

{{< guide-anchor "10-使用錄音轉錄與-ai-摘要" >}}

## 5. 錄下課程 {#recording}

1. 點一下筆記上方的麥克風。
2. 按紅色錄音鈕開始，必要時暫停、繼續。
3. 停止並儲存，再選擇錄音播放。

{{< guide-image src="images/guides/uni-note/common/record-button.png" alt="錄音面板的語言與紅色開始按鈕" mode="crop" caption="範例的轉錄語言為英文。" >}}

錄音、播放及檢視轉錄為 Premium 功能。每 30 分鐘分割一次，每本筆記最多 5 筆。返回首頁或讓 iPad 休眠前請停止並儲存。支援的 iPadOS 26 裝置可在錄音時轉錄。語言可在 **設定 → 學習支援 → 錄音支援** 選擇。AI 摘要使用轉錄文字及 AI 餘額，執行前請確認預估用量。

{{< guide-anchor "11-使用-記憶功能" "12-使用-問題解答助理" "13-使用-建立題組" >}}

## 6. 用便利貼與題組複習 {#review}

在學習支援設定開啟記憶功能。選擇便利貼標記，以 Apple Pencil 劃過要隱藏的文字，再用手指點標記切換透明與不透明。若要刪除便利貼標記，請長按後點選出現的刪除按鈕。

{{< guide-image src="images/guides/uni-note/common/sticky-marker.png" alt="遮住課程答案的便利貼標記" mode="crop" >}}

開啟問題解答助理後，選擇筆記上方的對應按鈕，以 Pencil 圈住問題、確認範圍，再要求解答。

若要把結果傳至其他 App，請在解答結果右上方點選複製（左）或分享（右）的按鈕。

{{< guide-image src="images/guides/uni-note/zh-hant/problem-answer.png" alt="解答結果右上方的複製與分享按鈕" mode="crop" >}}

在 **其他 → 建立題組** 選頁，保留或捨棄候選問題後儲存。從首頁題組進入複習。AI 解答與生成會使用 AI 餘額，請對照課程資料確認答案。

**3.5.0 發布前資訊：** 手動建立、儲存後編輯題組，以及隱藏首頁題組切換屬於下一版本。目前 3.4.0 可使用上述生成與複習流程。

{{< guide-anchor "14-保護筆記與使用-垃圾桶" >}}

## 7. 保護、刪除與還原 {#protect}

筆記列表中的保護功能可防止書寫。設定可要求解除保護時進行生物辨識。

已刪除的科目、筆記可從首頁垃圾桶還原。刪除資料夾不會刪除科目。頁面、題組及垃圾桶內永久刪除的項目無法還原。刪除筆記唯一的一頁時，會清除內容。

{{< guide-anchor "15-設定與備份" >}}

## 8. 保留備份 {#backup}

1. 從首頁齒輪開啟 **設定 → 備份**。
2. 若要在 Pocket 聽錄音，匯出前開啟包含錄音音訊。
3. 匯出備份並選擇儲存位置。

{{< guide-image src="images/guides/uni-note/common/backup-file-actions.png" alt="Uni:Note 備份設定中的匯出備份與從檔案還原" mode="crop" caption="畫面為日文介面：上方項目匯出備份，下方項目從已儲存的檔案還原。" >}}

簡單備份的更新與還原需 Premium。這是 iCloud 檔案儲存、讀取，不是筆記自動同步。從檔案還原時選擇 zip，完成後依提示關閉並重開 App。語言、左手操作及科目名稱也能在設定修改。

{{< guide-anchor "使用-split-viewslide-over-與雙窗格" >}}

## 在 iPad 使用兩個視窗 {#windows}

透過 iPad 視窗操作，將 Uni:Note 排在文件或影片旁邊，也可開啟兩個 Uni:Note 視窗。

Dock 操作及 Split View、Slide Over 等名稱，依 iPadOS 版本與視窗設定而異。
