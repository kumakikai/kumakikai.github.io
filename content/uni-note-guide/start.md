初めて使うときは、画面の仕組みを確認してから最初のノートを作ります。

{{< guide-anchor "目的から選ぶ" >}}

## 画面とノートの仕組み {#screens}

Uni:Noteは「教科 → ノート → ページ」の順に整理します。まずホームとノート画面の役割を知ると、資料の追加先や設定を探しやすくなります。

### 必要な条件 {#screens-必要な条件}

iPad／iPadOS 17.0以降。手書きには対応するApple Pencilを使います。

### ホームからノートへ {#ホームからノートへ}

1. ホームで教科を探します。「最近使ったノート」から続きのノートを開くこともできます。
2. 教科カード内の「ノート一覧」をタップします。
3. 一覧からノートを選びます。

ホームの「＋」は教科やフォルダを作る入口です。ノートを増やすときは、教科内のノート一覧を使います。ノートに含まれる紙1枚ずつがページです。

### ノート画面で使うもの {#ノート画面で使うもの}

- パレット：ペン・蛍光ペン・消しゴムなど、書く道具を選びます。
- ナビゲーションバー：ノート一覧、ページ一覧などを開きます。
- 「その他」：写真やPDF、問題集などの操作を探せます。

ボタンと道具の配置はカスタマイズできます。説明にあるボタンが見つからなければ、[配置設定](/htu/uni-note/customize/#toolbar)を確認してください。

### 初回案内を終える {#初回案内を終える}

初回の案内を読んだら「今すぐ始める」でホームへ進みます。「使い方を見る」からこのガイドを開くこともできます。あとから読み直すときは「設定 → サポート → 使い方」を開きます。

教科、ノート、ページのどこを開いているか分かれば、最初のノートを作る準備ができています。

## 最初の教科とノートを作る {#first-note}

授業ごとの教科を作り、その中で最初のノートを書き始めます。ここでは教科を「経済学」、ノートを「第8回 マクロ経済」とする例で進めます。

### 必要な条件 {#first-note-必要な条件}

手書きにはApple Pencil。

### 教科を作る {#教科を作る}

1. ホーム右下の「＋」をタップします。
2. 「教科を追加」を選びます。
3. 教科名を入力します。名前は1〜32文字です。
4. 罫線を選びます。
5. 紙色と表紙カラーを選びます。
6. 作成を確定します。

{{< uni-guide-image slot="start-first-note--n-m02" >}}

### 最初のノートを開く {#最初のノートを開く}

1. 作成した教科を開きます。
2. ノート名を入力します。空欄なら今日の日付が使われます。
3. ノートを作成します。
4. パレットでペンを選び、Apple Pencilで書きます。

### 続きから使う {#続きから使う}

ノートの内容は自動保存されます。作業を終えたらホームへ戻り、教科カードや「最近使ったノート」から開き直してください。前に見ていたページから続けられます。保存のためにアプリを強制終了する必要はありません。

{{< uni-guide-image slot="start-first-note--n-m01" >}}

{{< uni-guide-image slot="start-first-note--m-m14" >}}

### 完了の確認 {#first-note-完了の確認}

ホームに教科があり、そのノートを開き直すと書いた内容を確認できます。

### 注意事項 {#注意事項}

ノートの自動保存と、別の場所へ保管するバックアップは別です。大切な内容は定期的にバックアップしてください。
