## バックアップを保存する {#save}

ノートのデータをバックアップとして保管します。ファイルを書き出す方法と、Premiumのかんたんバックアップがあります。

### 必要な条件 {#save-必要な条件}

かんたんバックアップはPremiumとiCloudへの接続。保存先の空き容量。

### 保存方法と音声の扱いを決める {#保存方法と音声の扱いを決める}

1. 「設定 → バックアップ」を開きます。
2. 録音も保管したい場合は「録音音声もバックアップに含める」をオンにします。
3. ファイルへの書き出し、またはかんたんバックアップを選びます。

音声を含める設定は両方の保存方法に適用されます。容量が増えるため、表示される目安と保存先の空き容量を確認してください。

{{< uni-guide-image slot="backup-save--s-m08" >}}

### バックアップファイルを保存する {#バックアップファイルを保存する}

1. 「バックアップを書き出す」をタップします。
2. 音声を含める場合は容量の確認に進みます。
3. 書き出しが終わるまでアプリを開いたまま待ちます。
4. iPadOSのファイル保存画面で保存場所を選びます。
5. 保存を確定します。
6. 完了表示と保存したファイルを確認します。

### かんたんバックアップを更新する {#かんたんバックアップを更新する}

1. iCloudが利用できることを確認します。
2. 「かんたんバックアップを更新」を選びます。
3. 音声を含める場合は容量を確認します。
4. 完了まで待ちます。
5. 最終更新日時を確認します。

{{< uni-guide-image slot="backup-save--s-m10" >}}

### 完了の確認 {#save-完了の確認}

選んだ保存先にバックアップが残り、かんたんバックアップでは更新日時を確認できます。

### 注意事項 {#save-注意事項}

かんたんバックアップも手動のファイル保存・読み込みです。ノートの自動同期ではありません。復元前にも現在のデータを別途保存してください。

## バックアップから復元する {#restore}

保存済みのバックアップからデータを戻します。復元は現在のデータへの追加ではなく、置き換えです。

### 必要な条件 {#restore-必要な条件}

復元するバックアップ。かんたんバックアップはPremiumとiCloudへの接続。

### 復元前に現在のデータを残す {#復元前に現在のデータを残す}

必要な現在のデータは、先に別のバックアップファイルへ書き出します。戻したい時点と保存先を確かめてから復元します。

### ファイルから戻す {#ファイルから戻す}

1. 「設定 → バックアップ → ファイルから復元」を選びます。
2. 保存したバックアップZIPを選びます。
3. 検証・展開・適用が完了するまで、アプリを閉じずに待ちます。
4. 完了後、案内に従ってアプリを閉じます。
5. 開き直し、ホームの教科とノートを確認します。

### かんたんバックアップから戻す {#かんたんバックアップから戻す}

1. バックアップの最終更新日時を確認します。
2. 「かんたんバックアップから復元」を選びます。
3. 完了まで待ちます。
4. 案内に従って閉じ、開き直します。
5. 教科とノートの内容を確認します。

### 復元できないとき {#復元できないとき}

- iCloudに接続できない：iPad側のアカウント・接続状態を確認します。
- バックアップが見つからない：保存場所と更新日時を確認します。
- 容量が足りない：iPadや保存先の空き容量を確認します。
- ZIPが読み込めない：Uni:Noteで書き出したバックアップか確認します。

解決しない場合は、表示されたエラーとサポート情報を添えて問い合わせます。

### 完了の確認 {#restore-完了の確認}

再起動後のホームに、バックアップ時点のデータが表示されます。

### 注意事項 {#restore-注意事項}

現在のデータを残したいときは、復元を始める前に別ファイルへ保存してください。
