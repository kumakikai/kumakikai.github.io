バックアップを保管し、必要なときにデータを復元します。

{{< guide-anchor "目的から選ぶ" >}}

## バックアップを保存する {#save}

ノートのデータをバックアップとして保管します。Freeでも使えるファイルの書き出しと、PremiumまたはPremium Plusのかんたんバックアップがあります。

### 必要な条件 {#save-必要な条件}

かんたんバックアップはPremiumまたはPremium PlusとiCloudへの接続。保存先の空き容量。

### 保存方法と音声の扱いを決める {#保存方法と音声の扱いを決める}

1. 設定トップの「データ・バックアップ」にある「バックアップ」を開きます。
2. 録音も保管したい場合は「録音」の「録音音声もバックアップに含める」をONにします。
3. 「ファイル」の書き出し、または「かんたんバックアップ」を選びます。

画面は「かんたんバックアップ」（iCloudに保存）、「録音」、「ファイル」（手動で書き出し・復元）の3つに分かれています。Freeプランでは、かんたんバックアップに「Premiumで利用できます」と表示されます。

音声を含める設定は両方の保存方法に適用されます。音声を含めると「録音音声を含めて書き出す」の確認でバックアップの目安の大きさが表示されます。時間と空き容量が多く必要になるため、保存先の空き容量を確認してください。

4.0.0を新しくインストールした場合、「録音音声もバックアップに含める」の初期状態はONです。

### バックアップファイルを保存する {#バックアップファイルを保存する}

1. 「バックアップを書き出す」をタップします。
2. 音声を含める場合は容量の確認に進みます。
3. 「バックアップを準備中」から「バックアップを検証中」までの進み具合が表示されます。「処理中は閉じないでください」と表示されている間は、アプリを開いたまま待ちます。
4. iPadOSのファイル保存画面で保存場所を選びます。
5. 保存を確定します。
6. 「バックアップを保存しました」と保存したファイルを確認します。

### かんたんバックアップを更新する {#かんたんバックアップを更新する}

1. iCloudが利用できることを確認します。
2. 「かんたんバックアップを更新」を選びます。
3. 音声を含める場合は容量を確認します。
4. 完了まで待ちます。
5. 「最終更新」の日時を確認します。

かんたんバックアップの更新・復元には通信が必要です。iCloudに接続できない場合は「バックアップを利用できません。」と表示されます。

{{< uni-guide-image slot="backup-save--s-m10" >}}

### 完了の確認 {#save-完了の確認}

選んだ保存先にバックアップが残り、かんたんバックアップでは更新日時を確認できます。

### 注意事項 {#save-注意事項}

かんたんバックアップも手動のファイル保存・読み込みです。ノートの自動同期ではありません。復元前にも現在のデータを別途保存してください。

## バックアップから復元する {#restore}

保存済みのバックアップからデータを戻します。復元は現在のデータへの追加ではなく、置き換えです。

### 必要な条件 {#restore-必要な条件}

復元するバックアップ。かんたんバックアップはPremiumまたはPremium PlusとiCloudへの接続。

### 復元前に現在のデータを残す {#復元前に現在のデータを残す}

復元の操作を始めると、確認の画面は表示されずにすぐ復元が始まり、現在のデータはバックアップの内容に置き換わります。必要な現在のデータは、先に別のバックアップファイルへ書き出してください。戻したい時点と保存先を確かめてから復元します。

### ファイルから戻す {#ファイルから戻す}

1. 「設定 → バックアップ → ファイルから復元」を選びます。
2. 保存したバックアップZIPを選びます。
3. 「バックアップを確認中」「データを展開中」「データを検証中」「復元を適用中」と進む間、アプリを閉じずに待ちます。
4. 「復元が完了しました」と表示されたら、案内に従ってアプリを閉じます。
5. 開き直し、ホームの教科とノートを確認します。

### かんたんバックアップから戻す {#かんたんバックアップから戻す}

1. バックアップの最終更新日時を確認します。
2. 「かんたんバックアップから復元」を選びます。
3. 完了まで待ちます。
4. 案内に従って閉じ、開き直します。
5. 教科とノートの内容を確認します。

### 復元できないとき {#復元できないとき}

- iCloudに接続できない：iPad側のアカウント・接続状態を確認します。
- バックアップが見つからない：保存場所と更新日時を確認します。
- 容量が足りない：iPadや保存先の空き容量を確認します。
- ZIPが読み込めない：Uni:Noteで書き出したバックアップか確認します。

解決しない場合は、表示されたエラーとサポート情報を添えて問い合わせます。

### 完了の確認 {#restore-完了の確認}

再起動後のホームに、バックアップ時点のデータが表示されます。

### 注意事項 {#restore-注意事項}

現在のデータを残したいときは、復元を始める前に別ファイルへ保存してください。録音音声を含めずに作ったバックアップから復元すると、録音一覧に「音声なし」と表示されます。文字起こしは表示できます。

バックアップには問題集も含まれます。iPhone向けのUni:Note Pocketでバックアップを読み込む場合は、Pocketも最新版に更新してください。
