ノートからAIで問題の候補を作り、自分で内容を直してから復習します。授業で重視された言い回しや解説を反映できます。

{{< uni-guide-image slot="workflows-quiz-review--r-m14" >}}

## 必要な条件

AI生成時は通信環境とAI残量。手動編集と手動作成はAI残量を使いません。

## 候補を選んで保存する

1. ノートの「その他 → 問題集を作る」を開きます。
2. 「対象ページ」の行をタップし、出題に使うページを最大20ページまで選びます。
3. 「目安」の問題数と「予想消費量」を確認し、「問題集を作成」をタップします。
4. 「問題レビュー」で問題と解答を読み、残す候補を「追加」します。
5. 「問題集名」を入力し、「問題集として保存」をタップします。

## 手直しして復習する

1. ホームの問題集表示で、問題集のカードを長押しします。
2. 「問題集を編集」を選びます。
3. 授業資料と比べ、直したい問題を開いて問題文・解答・解説を直します。
4. 必要な問題を追加し、不要な問題を削除します。
5. 編集を終えます。
6. 問題集を開き、まず答えを考えます。
7. 解答を表示して確認します。

{{% uni-v4 %}}
4.0.0では、問題の追加・編集・削除はその場で保存されます。学習では、解答を確認したら右スワイプで「覚えた」、左スワイプで「覚えていない」を記録して次へ進みます。解答を表示したあと出典をタップすると、元のノートのページを横に開いて見直せます。1周終わったら、覚えていない問題だけをもう一周できます。詳しくは[覚えた・覚えていないで学習する](/htu/uni-note/problem-sets/#review)を参照してください。
{{% /uni-v4 %}}

{{% uni-pre-v4 %}}編集画面で直したら「保存」をタップします。学習では、カードをタップして解答を表示し、「次へ」で次の問題へ進みます。{{% /uni-pre-v4 %}}

## 完了の確認

確認・手修正した問題集で、答えを隠しながら復習できます。
