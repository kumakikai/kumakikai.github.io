## ノートからAI問題集を作る {#generate}

ノートの必要なページからAIで問題を作り、採用する候補だけを問題集として保存します。

### 必要な条件 {#generate-必要な条件}

通信環境とAI残量。問題の元になるノート。

### 対象を決めて生成する {#対象を決めて生成する}

1. 元にするノートを開きます。
2. 「その他 → 問題集を作る」を選びます。
3. 対象ページを1〜20ページ選びます。
4. 予定の問題数と予想消費量を確認します。
5. 生成を開始します。

処理をやめたい場合は生成中のキャンセルを選びます。生成完了後は、候補を確認してから保存します。

### 候補を採用・破棄する {#候補を採用破棄する}

1. 候補の問題と解答を読みます。
2. 残す候補は追加、不要な候補は破棄を選びます。
3. 次の候補も同じように確認します。

右スワイプで追加、左スワイプで破棄する方法もあります。

### 問題集として保存する {#問題集として保存する}

1. 採用する候補を確認します。
2. 「問題集として保存」を選びます。
3. 問題集の名前を入力します。
4. 保存を確定します。

### 完了の確認 {#generate-完了の確認}

採用した問題だけをまとめた問題集を、ホームやノートから開けます。

### 注意事項 {#generate-注意事項}

生成だけでは候補の選別は終わりません。解答の正しさを確認し、保存後も必要に応じて編集してください。

## 保存した問題集で復習する {#review}

保存した問題集をカード形式で開き、答えを隠した状態から復習できます。

### 必要な条件 {#review-必要な条件}

保存済みの問題集。

### 問題集を開く {#問題集を開く}

1. ホームの「問題集」を開きます。
2. 復習する問題集を選びます。

ノートからは「保存済み問題集」の一覧を開いて選ぶこともできます。ホームに入口がない場合は[表示設定](/htu/uni-note/problem-sets/#home)を確認してください。

### 答えを確認して次へ進む {#答えを確認して次へ進む}

1. 問題を読み、答えを考えます。
2. カードをタップして解答を表示します。
3. 自分の答えと比べます。
4. 前・次の操作、またはスワイプで別の問題へ移ります。

問題を切り替えると解答は隠れ、次の問題に取り組めます。

## 問題集を手動作成・編集する {#edit}

問題集を自分で作り、保存済みの問題文・解答・解説を直せます。手動作成と手動編集はAI残量を使いません。

### 手動で作成する {#手動で作成する}

1. ホームを「問題集」に切り替えます。
2. 「＋」をタップします。
3. 問題集のタイトルを入力します。
4. 問題文を入力します。
5. 解答を入力します。
6. 必要なら解説を入力します。
7. 保存します。

### 保存した問題集を編集する {#保存した問題集を編集する}

1. 問題集カードを長押しします。
2. 編集を選びます。
3. タイトル・問題文・解答・解説の必要な箇所を直します。
4. 保存します。

AIで作成した問題集も同じ方法で直せます。

### 問題を追加・削除する {#問題を追加削除する}

編集画面の追加操作から新しい問題を入力できます。不要な問題は編集画面で削除し、残った内容を確認して保存します。

保存できないときは、画面に表示された入力不足や条件を確認してください。変更を残さずやめる場合はキャンセルし、破棄の確認が表示されたら内容を確認します。

### 問題集全体を削除する {#問題集全体を削除する}

問題集カードを長押しして削除を選び、確認して確定します。これは個別問題の編集とは別の操作です。

## ホームの問題集表示を変える {#home}

ホームの問題集の入口を表示するか選べます。非表示にしても、保存した問題集を削除することにはなりません。

### 表示を切り替える {#表示を切り替える}

1. ホームの歯車から設定を開きます。
2. 「学習支援 → 問題集」で「ホームに問題集を表示」を確認します。
3. 非表示にするときはオフにします。
4. ホームへ戻って表示を確認します。

再びホームから使う場合は、同じ項目をオンに戻します。
