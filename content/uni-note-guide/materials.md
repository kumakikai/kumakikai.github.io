写真やPDFを貼り付け、配置・固定・書き込み・共有まで行います。

> **素材操作の前に**：「指で描画」がONの間は、1本指が手書きに使われます。写真・PDFなどの選択、移動、拡大・縮小、固定／固定解除、削除を行うときは、ホームの設定で「指で描画」をいったんOFFにしてから素材を操作してください。

## 写真・紙の資料を貼り付ける {#photos}

普通の写真はそのまま貼り付けられます。紙資料は書類として取り込み、四隅を合わせて読みやすく補正できます。

### 必要な条件 {#photos-必要な条件}

写真へのアクセス。カメラで撮る場合はカメラ権限。

### 写真をそのまま貼る {#写真をそのまま貼る}

1. 貼り付け先のノートページを開きます。
2. 「その他 → 写真貼付」を選びます。
3. 写真を1枚選びます。
4. 貼り付け後の位置と大きさを確認します。

### 紙資料を撮って貼る {#紙資料を撮って貼る}

1. 「その他 → 写真を書類として貼付」を選びます。
2. カメラから取り込む方法を選びます。
3. 紙全体が入るように撮影します。
4. 補正画面で四隅を紙の角に合わせます。
5. 補正を適用します。

### 保存済み写真を紙資料として使う {#保存済み写真を紙資料として使う}

同じ「写真を書類として貼付」で写真から取り込む方法を選び、写真を指定します。四隅を合わせて補正を適用してください。

書類として貼った写真は最初に固定されます。位置や大きさを変える場合は、「指で描画」をOFFにし、先にダブルタップで固定を解除します。

## PDFのページを選んで貼り付ける {#pdf}

PDFから必要なページだけを選んでノートに貼り付けます。複数ページや見開きの資料も扱えます。

### 必要な条件 {#pdf-必要な条件}

iPadのファイル選択画面から開けるPDF。

### 1ページを選んで貼る {#1ページを選んで貼る}

1. 貼り付けを始めたいノートページを開きます。
2. 「その他 → PDF貼付」を選びます。
3. ファイル選択画面でPDFを開きます。
4. 使いたいページのサムネイルを選びます。
5. 「貼り付け」をタップします。

### 複数ページ・全ページを選ぶ {#複数ページ全ページを選ぶ}

ページ選択画面で必要なサムネイルを選びます。全ページを使う場合は「すべて選択」を使います。選択済みの不要なページは選択を解除してください。

貼り付ける順番は、タップした順ではなくPDFのページ番号順です。現在のノート位置から後ろのページへ配置されます。

### 見開きを左右に分割する {#見開きを左右に分割する}

1. PDFのページを選びます。
2. 「見開きを分割」を有効にします。
3. 「貼り付け」をタップします。
4. 左半分、右半分の順にノートへ入ったことを確認します。

PDFの1ページが、ノートの2ページ分になります。[完成例と学習手順](/htu/uni-note/workflows/split-spread/)も参照してください。

### 完了の確認 {#pdf-完了の確認}

選んだPDFがノートに固定された状態で配置されます。Apple Pencilで上から書き込めます。

### 注意事項 {#pdf-注意事項}

位置や大きさを変えるときは、「指で描画」をOFFにしてから固定を解除します。元のPDFファイルそのものを編集する操作ではありません。

## 写真・PDFを動かして固定する {#arrange}

写真やPDFを移動・拡大縮小し、書き込みやすい位置で固定します。手書きの範囲移動とは操作対象が異なります。

### 必要な条件 {#arrange-必要な条件}

写真またはPDFを貼り付けたノート。注釈にはApple Pencil。

### 固定を解除して選ぶ {#固定を解除して選ぶ}

1. 「指で描画」がONの場合は、ホームの設定でOFFにします。
2. 貼り付けた資料をダブルタップして固定を解除します。
3. 資料を指でタップして選びます。
4. 選択されている対象を確認します。

PDFと書類写真は貼り付け直後に固定されます。動かない場合は、先に固定状態を確認してください。

### 移動・サイズ変更・回転 {#移動サイズ変更回転}

1. 選択した資料を指でドラッグして移動します。
2. 資料を選択した状態で、その上を2本指でピンチして大きさを変えます。
3. 書類写真・PDFの向きを変える場合は、選択対象付近の回転ボタンをタップします。1回で時計回りに90度回ります。

資料の選択を確かめてからピンチしてください。ノート全体の表示をズームする操作と、資料だけの大きさを変える操作を区別します。

### 固定して書く {#固定して書く}

1. 位置と大きさが決まった資料をダブルタップして固定します。
2. ペンを選びます。
3. Apple Pencilで資料の上や余白へ書き込みます。

同じページへ別のPDFを追加すると重なる場合があります。追加した資料を固定解除し、それぞれの位置を整えてから固定してください。

### 資料を削除する {#資料を削除する}

「指で描画」をOFFにし、固定を解除してから、対象を長押しして削除操作を選びます。必要な資料か確認してから実行してください。

### 注意事項 {#arrange-注意事項}

写真・PDFの削除は手書きの取り消し操作では戻せません。

## 縦ノートで資料の大きさを整える {#vertical}

縦ノートでは、PDFや書類写真を大きく配置して読めます。普通の写真は貼り付け後に手動で大きさを整えます。

### 必要な条件 {#vertical-必要な条件}

作成時に縦ノートを選んだノート。

### PDF・書類写真を大きく使う {#pdf書類写真を大きく使う}

1. 縦ノートの貼り付け先を開きます。
2. PDF貼付、または写真を書類として貼付を実行します。
3. ページ内に大きく配置された資料を確認します。
4. 調整が必要なら、「指で描画」をOFFにしてから固定を解除し、位置と大きさを整えます。
5. 資料を固定します。

資料の縦横比は保たれるため、形によって余白が残ります。

### 普通の写真を大きくする {#普通の写真を大きくする}

1. 「写真貼付」で写真を選びます。
2. 「指で描画」をOFFにし、写真を選択します。固定されている場合は先に解除します。
3. 写真の上で2本指を広げ、読みたい大きさにします。
4. ドラッグして位置を整えます。
5. ダブルタップで固定します。

### 注意事項 {#vertical-注意事項}

PDF・書類写真の初期配置と、普通の写真の初期配置は同じではありません。

## ノートをPDFにして保存・共有する {#export}

ノート単体または教科全体をPDFにして、ファイル保存や共有に使えます。印刷用には白背景も選べます。

### 必要な条件 {#export-必要な条件}

保存・共有先のアプリ。印刷はiPadOS側の対応環境が必要です。

### 背景を決める {#背景を決める}

1. ホームの設定を開きます。
2. 「表示設定 → PDF出力時の背景色」を開きます。
3. ノートの紙色を使う「紙」、または「白」を選びます。

### PDFを書き出す {#pdfを書き出す}

1. 対象のノートを開きます。
2. 「その他 → PDF出力」を選びます。
3. このノート、または教科全体を選びます。
4. 出力が終わるまで待ちます。
5. iPadOSの共有シートから保存先や共有先を選びます。

ファイルとして保管する場合は、共有シートのファイル保存操作からフォルダを指定します。印刷する場合は、表示される印刷操作とプリンタの案内に従ってください。

{{< uni-guide-image slot="materials-export--m-m21" >}}

### 完了の確認 {#export-完了の確認}

保存先でPDFを開き、ページ範囲・背景・手書きを確認できます。

### 注意事項 {#export-注意事項}

PDF出力は閲覧・共有用です。Uni:Noteへ戻すためのバックアップとは異なります。
