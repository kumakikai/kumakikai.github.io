写真やPDFを貼り付け、配置・固定・書き込み・共有まで行います。

> **素材の選択方法**：「指で描画」がOFFのときは、固定されていない写真・PDF・図形・テキストなどを指で1回タップして選択します。固定中の素材はダブルタップで固定を解除します（もう一度ダブルタップすると固定に戻ります）。「指で描画」がONのときは、ノート画面の「編集」ボタン（パレットと反対側にあるアイコン）を押します。ボタンが青くなっている間は素材を選ぶ状態です。素材を1回タップすると選択でき、そのまま移動・サイズ変更できます。空白をタップする、「編集」ボタンを再度押す、Apple Pencilで書き始める、のいずれかで通常の筆記に戻ります。

## 写真・紙の資料を貼り付ける {#photos}

普通の写真はそのまま貼り付けられます。紙資料は書類として取り込み、四隅を合わせて読みやすく補正できます。

### 必要な条件 {#photos-必要な条件}

写真から選ぶ場合は写真へのアクセス。カメラで撮る場合はカメラの使用許可。

### 写真をそのまま貼る {#写真をそのまま貼る}

1. 貼り付け先のノートページを開きます。
2. 「その他」から「写真貼付」を選びます。
3. 「カメラで撮影」または「写真から選択」を選びます。
4. 撮影するか、写真を1枚選びます。
5. 貼り付け後の位置と大きさを確認します。

{{< uni-guide-image slot="v4-materials-photo-source" >}}

### 紙資料を撮って貼る {#紙資料を撮って貼る}

1. 「その他」から「写真を書類として貼付」を選びます。
2. 「カメラで撮影」を選びます。
3. 紙全体が入るように撮影します。
4. 補正画面で四隅を紙の角に合わせます。
5. 補正を適用します。

### 保存済み写真を紙資料として使う {#保存済み写真を紙資料として使う}

同じ「写真を書類として貼付」で「写真から選択」を選び、写真を指定します。四隅を合わせて補正を適用してください。

書類として貼った写真は固定された状態で配置されます。位置や大きさを変える場合は、上の「素材の選択方法」で選択してから調整します。「指で描画」がONでもOFFへ切り替える必要はありません。

{{< uni-guide-image slot="materials-photos--m-m03" >}}

### 完了の確認 {#photos-完了の確認}

ノート上に写真、または四隅を補正した書類写真が表示されます。

## PDFのページを選んで貼り付ける {#pdf}

PDFから必要なページだけを選んでノートに貼り付けます。複数ページや見開きの資料も扱えます。

### 必要な条件 {#pdf-必要な条件}

iPadの「ファイル」から開けるPDF。

### 1ページを選んで貼る {#1ページを選んで貼る}

1. 貼り付けを始めたいノートページを開きます。
2. 「その他」から「PDF貼付」を選びます。
3. ファイル選択画面でPDFを開きます。
4. 「貼り付けるページを選択」で、使いたいページのサムネイルを選びます。
5. 「貼り付け」をタップします。

{{< uni-guide-image slot="materials-pdf--m-m07" >}}

{{< uni-guide-image slot="materials-pdf--m-m08" >}}

### 複数ページ・全ページを選ぶ {#複数ページ全ページを選ぶ}

ページ選択画面で必要なサムネイルを選びます。全ページを使う場合は「すべて選択」を使います。選択をやめるときは「すべて解除」を使います。

貼り付ける順番は、タップした順ではなくPDFのページ番号順です。現在のノート位置から後ろのページへ配置されます。貼り付け先にすでにPDFがある場合は「PDFを差し替えますか？」と表示されます。ノートの上限150ページを超える場合は貼り付けできません。

### 見開きを左右に分割する {#見開きを左右に分割する}

1. PDFのページを選びます。
2. 「見開きを分割」を有効にします。
3. 「貼り付け」をタップします。
4. 左半分、右半分の順にノートへ入ったことを確認します。

PDFの1ページが、ノートの2ページ分になります。[完成例と学習手順](/htu/uni-note/workflows/split-spread/)も参照してください。

### 完了の確認 {#pdf-完了の確認}

選んだPDFがノートに固定された状態で配置されます。Apple Pencilで上から書き込めます。

### 注意事項 {#pdf-注意事項}

位置や大きさを変えるときは、上の「素材の選択方法」でPDFを選択します。元のPDFファイルそのものを編集する操作ではありません。

## 写真・PDFを選択して配置する {#arrange}

写真やPDFを選択し、書き込みやすい位置と大きさに整えます。手書きの範囲移動とは操作対象が異なります。

### 必要な条件 {#arrange-必要な条件}

写真またはPDFを貼り付けたノート。注釈にはApple Pencil。

### 素材を選ぶ {#固定を解除して選ぶ}

1. 「指で描画」がOFFの場合は、固定中の資料をダブルタップして固定を解除し（「固定を解除」と表示されます）、1回タップして選択します。
2. 「指で描画」がONの場合は、「編集」ボタンを押して青い状態にし、資料を1回タップします。
3. 選択枠とハンドルが表示された対象を確認します。

「指で描画」がONでも、素材操作のためにOFFへ切り替える必要はありません。

{{< uni-guide-image slot="v4-materials-edit-button" >}}

### 移動・サイズ変更・回転 {#移動サイズ変更回転}

1. 選択した資料を指でドラッグして移動します。
2. 大きさを変えるには、「指で描画」がOFFの場合は選択した資料の上を2本指でピンチします。ONの場合は選択枠のサイズ変更ハンドルを指でドラッグします。確定したテキストは、OFFでも右下のハンドルで拡大・縮小できます。
3. 向きを変える場合は、選択枠右上の回転ハンドルを1本指でつかみ、素材の中心の周りを円を描くように動かします。回転は45°ごとに吸着し、角度が画面に表示されます。写真・書類写真・PDF・テキスト・図形を回転できます。

資料の選択枠を確かめてから操作してください。ノート全体は2本指のピンチでズームします。

### 配置して書く {#固定して書く}

1. 位置と大きさを整えます。
2. 書き込み中に資料が動かないようにするときは、ダブルタップして「固定」にします。
3. ペンを選び、Apple Pencilで資料の上や余白へ書き込みます。

同じページへ別のPDFを追加すると重なる場合があります。それぞれを選択し、位置を整えてください。

### 資料を削除する {#資料を削除する}

「指で描画」がOFFなら、固定を解除した資料を長押しします。ONなら「編集」ボタンを押した状態で資料を長押しし、「削除」を選びます。「この素材を削除しますか？」と表示されたら、必要な資料でないことを確認して「削除」をタップします。

### 完了の確認 {#arrange-完了の確認}

資料が意図した位置と大きさに配置され、手書きの注釈を追加できます。

### 注意事項 {#arrange-注意事項}

写真・PDFの削除は元に戻せません。手書きの「戻る」でも戻りません。

## 縦ノートで資料の大きさを整える {#vertical}

縦ノートでは、PDFや書類写真を大きく配置して読めます。普通の写真は貼り付け後に手動で大きさを整えます。

### 必要な条件 {#vertical-必要な条件}

作成時に縦ノートを選んだノート。

### PDF・書類写真を大きく使う {#pdf書類写真を大きく使う}

1. 縦ノートの貼り付け先を開きます。
2. 「PDF貼付」、または「写真を書類として貼付」を実行します。
3. ページ内に大きく配置された資料を確認します。
4. 調整が必要なら、「指で描画」の設定に合う方法で資料を選択し、位置と大きさを整えます。

資料の縦横比は保たれるため、形によって余白が残ります。

### 普通の写真を大きくする {#普通の写真を大きくする}

1. 「写真貼付」で写真を選びます。
2. 「指で描画」がOFFなら写真を1回タップします。ONなら「編集」ボタンを押して写真を1回タップします。
3. OFFの場合は写真上の2本指ピンチ、ONの場合はサイズ変更ハンドルで、読みたい大きさにします。
4. ドラッグして位置を整えます。

### 完了の確認 {#vertical-完了の確認}

ノート全体のズームに頼らず、資料自体を大きく配置できます。

### 注意事項 {#vertical-注意事項}

PDF・書類写真の初期配置と、普通の写真の初期配置は同じではありません。

## ノートをPDFにして保存・共有する {#export}

ノート単体または教科全体をPDFにして、ファイル保存や共有に使えます。印刷用に紙色を外すこともできます。

### 必要な条件 {#export-必要な条件}

保存・共有先のアプリ。印刷はiPadOS側の対応環境が必要です。

### 出力の設定を決める {#背景を決める}

1. ホームの歯車から設定を開きます。
2. 「表示設定」の「PDF出力設定」を開きます。
3. 印刷でインクを節約したい場合は「PDF出力時の紙色をなしにする」をONにします。

この設定はPDF出力にだけ反映されます。

{{% uni-v4 %}}
「PDF出力設定」に「付箋マーカーを含める」（初期状態はOFF）と「付箋を含める」（初期状態はON）が加わり、付箋マーカーや手書きできる付箋をPDFに入れるかどうかを選べます。
{{% /uni-v4 %}}

{{% uni-pre-v4 %}}手書きできる付箋は常にPDFに含まれ、付箋マーカーは含まれません。{{% /uni-pre-v4 %}}

{{< uni-guide-image slot="v4-materials-pdf-settings" >}}

### PDFを書き出す {#pdfを書き出す}

1. 対象のノートを開きます。
2. 「その他」から「PDF出力」を選びます。
3. 「出力範囲」で「このノートのみ」または「全体」（教科のノートすべて）を選びます。
4. 「出力」をタップし、書き出しが終わるまで待ちます。
5. iPadOSの共有シートから保存先や共有先を選びます。

ファイルとして保管する場合は、共有シートの「"ファイル"に保存」からフォルダを指定します。印刷する場合は、表示される印刷操作とプリンタの案内に従ってください。

{{< uni-guide-image slot="v4-materials-export-scope" >}}

### 完了の確認 {#export-完了の確認}

保存先でPDFを開き、ページ範囲・背景・手書きを確認できます。

### 注意事項 {#export-注意事項}

PDF出力は閲覧・共有用です。Uni:Noteへ戻すためのバックアップとは異なります。
