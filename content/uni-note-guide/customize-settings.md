ホームの歯車から設定を開きます。紙の初期値、画面の配置、学習支援、バックアップなどを目的別に探せます。

## 設定を開く

1. ノートからホームへ戻ります。
2. 歯車をタップします。
3. 変更したい内容に合うカテゴリを選びます。
4. 設定を終えたら戻る操作で設定トップへ戻ります。

| 目的 | 開くところ |
|---|---|
| 新しいノートの紙・左右の配置 | ノート設定 |
| 起動時の画面・ボタンとパレットの配置 | 表示設定 |
| 録音の言語・要約形式・ポモドーロ | 学習支援 |
| 保存・復元 | バックアップ |
| 使い方・問い合わせ | サポート |

設定トップでは現在のプランやAI残量、お知らせも確認できます。
