## 設定を開いて目的の項目を探す {#settings}

ホームの歯車から設定を開きます。紙の初期値、画面の配置、学習支援、バックアップなどを目的別に探せます。

### 設定を開く {#設定を開く}

1. ノートからホームへ戻ります。
2. 右上の歯車をタップします。
3. 変更したい内容に合う項目を選びます。
4. 設定を終えたら戻る操作で設定トップへ戻ります。

設定トップの上部には、現在のプランとAI残量、その下に「指で描画」のスイッチがあります。

| 目的 | 開くところ |
|---|---|
| 1本指で書く | 設定トップの「指で描画」 |
| 新しいノートの紙・左利き・ページの四隅の表示・スクロール・パレットの自動収納 | ノート設定 |
| 起動時の画面・ホームの表示・ボタンとパレットの配置・PDF出力・言語 | 表示設定 |
| AI回答言語・録音・問題集・時間割・ポモドーロ・定規 | 学習支援 |
| 保存・復元 | バックアップ |
| アプリの更新情報 | お知らせ |
| 使い方・問い合わせ・プライバシーポリシー | サポート |

### 完了の確認 {#settings-完了の確認}

変えたい項目へ進み、変更後にノートやホームで結果を確認できます。

## 紙・左右の配置・ページ情報を設定する {#paper}

新しいノートの紙と、左右の配置の初期値を選びます。教科名やページ番号を紙の四隅へ表示することもできます。

### 新規ノートの紙を決める {#新規ノートの紙を決める}

1. 「設定 → ノート設定」を開きます。
2. 「新規ノート」の「テンプレート」で横罫・縦罫・方眼・無地を選びます。
3. 「ベース色」を選びます。
4. プレビューを確認します。
5. 新しい教科の作成画面で、初期値を確認します。

縦罫を選ぶと「縦ノート（見開き表示）として使う」の既定値も選べます。新しく作るときの選択をそろえる設定です。

### 左利きモード・左右の個別設定 {#左利きモード左右の個別設定}

1. 「設定 → ノート設定」で「左利きモード」を切り替えます。
2. パレット、横罫の赤縦線、PDF貼付位置のプレビューを確認します。

個別に変える場合は「項目ごとの設定」で、「パレットの位置」「横罫線ノートの赤縦線の位置」「PDF貼付位置」をそれぞれ「左」「右」から選びます。PDF貼付位置は新しく資料を入れるときの配置に使われます。

### 四隅に教科名・ページ番号などを置く {#四隅に教科名ページ番号などを置く}

1. 「設定 → ノート設定」の「ヘッダー / フッター」で位置（「左上」「右上」「左下」「右下」）を選びます。
2. 「なし」「教科名」「ノート名」「ページ作成日」「ページ数」から表示する情報を選びます。
3. プレビューを確認します。
4. ノートに戻って表示を確認します。

## 起動・表示・言語を設定する {#display}

起動時の画面、ホームの表示、教科の並びや呼び方、スリープ、アプリの言語を選べます。

### 起動時に開く画面 {#起動時に開く画面}

1. 「設定 → 表示設定」を開きます。
2. 「起動時に開く画面」をタップします。
3. 次の5つから選びます。選んだ項目の説明が下に表示されます。

| 選択肢 | 起動したときの動き |
|---|---|
| ホームを開く | ホームを表示します |
| 前回のノートを開く | 最後に使ったノートを開き、続きから書けます |
| 時間割を開く | 時間割を表示します |
| 時間割からノートを開く | 今の授業の教科で最後に使ったノートを開きます |
| 時間割からノート一覧を開く | 時間割の上に、今の授業の教科のノート一覧を開きます |

時間割を使う選択肢の詳しい動きは[時間割からノートを開く](/htu/uni-note/timetable/#open)を参照してください。

{{< uni-guide-image slot="v4-customize-launch" >}}

### ホームの表示 {#起動とホームの表示}

「設定 → 表示設定」の「起動・表示設定」で、次の項目を選べます。

| 項目 | 内容 |
|---|---|
| 教科を最近開いた順で並べ替える | よく使う教科を上部に表示します。手動で並べたい場合はOFFにします |
| 教科の表記 | 「教科」「ノート」「グループ」「カテゴリ」から呼び方を選びます |
| 2ペイン表示をデフォルトにする | 起動したときのホームを2ペイン表示にします |

このガイドは標準の「教科」という呼び方で説明しています。表記を変えても整理の階層は同じです。

{{< uni-guide-image slot="v4-customize-display" >}}

### 筆記中の表示 {#筆記中の表示}

「ノートを開いている間はスリープしない」をONにすると、ノート表示中の自動スリープを防げます。録音中にも便利です。

パレットを自動でたたむ場合は「設定 → ノート設定 → パレットを自動収納」をONにします。書き始めると収納され、収納中のボタンをタップして開けます。

### 保護解除時の認証 {#保護解除時の認証}

表示設定の「ノートの保護解除時に生体認証を要求」で切り替えます。これは書き込み保護を解除するときの認証です。[ノートの保護](/htu/uni-note/data/#protect)も確認してください。

### 表示言語を変える {#表示言語を変える}

1. 「設定 → 表示設定 → 言語」を開きます。
2. 日本語・English・한국어・Deutsch・繁體中文・Françaisから選びます。
3. 再起動の案内に従ってアプリを閉じ、開き直します。

### 新しくインストールしたときの初期設定 {#新しくインストールしたときの初期設定}

4.0.0を新しくインストールした場合、主な設定は次の状態から始まります。以前から使っている場合は、それまでの設定が引き継がれます。

| 設定 | 初期状態 |
|---|---|
| 起動時に開く画面 | ホームを開く |
| 2ペイン表示をデフォルトにする | OFF |
| 教科を最近開いた順で並べ替える | OFF |
| ノートを開いている間はスリープしない | ON |
| ノートの保護解除時に生体認証を要求 | OFF |
| 端スワイプで戻る | OFF |
| 文字起こしの精度を優先 | OFF |
| 録音音声もバックアップに含める | ON |

### 完了の確認 {#display-完了の確認}

起動先やホームの表示、ノートを開いている間の動作が選んだ設定になります。

## ボタンとパレットの配置を変える {#toolbar}

ノート画面のボタンと、パレットに並ぶ道具をカスタマイズできます。よく使う操作を手元へ置き、ほかの操作を「その他」へまとめます。

### ナビゲーションバーを変える {#ナビゲーションバーを変える}

1. 「設定 → 表示設定 → ノート画面 → ナビゲーションバー」を開きます。
2. 移動したいボタンを押さえてドラッグします。
3. ナビゲーションバー内で順番を整えます。
4. 「その他」へまとめるボタンは「「…」メニュー内」の領域へ移します。
5. メニュー内でも順番を整えます。

非表示にする場合は、対象ボタンの「非表示にする」か、「利用できるボタン」の領域への移動を使います。再表示するときは「利用できるボタン」から戻します。ナビゲーションバーは左右それぞれ最大4枠です。「空白」を置くと、ボタンの間にスペースを作れます。

「録音」と「ポモドーロ」は「…」メニューには移動できません。

### ドラッグせずに移動する {#ドラッグせずに移動する}

対象のボタンをタップすると、移動のメニューを使えます。「前へ移動」「後ろへ移動」「左側へ移動」「右側へ移動」「「…」メニューへ移動」「非表示にする」「表示する」から選び、配置を確認します。

### パレットの道具を変える {#パレットの道具を変える}

1. 「設定 → 表示設定 → ノート画面 → パレット」を開きます。
2. 道具を押さえてドラッグし、順番を変えます。
3. 使わない道具を非表示にします。
4. 再表示したい道具を「利用できるツール」から戻します。
5. ノートを開いてパレットを確認します。

### 初期配置へ戻す {#初期配置へ戻す}

各カスタマイズ画面の「初期状態に戻す」を選び、確認して実行します。ノートへ戻り、ナビゲーションバー・その他・パレットの配置を確認してください。

### 注意事項 {#注意事項}

「付箋マーカー」はパレット、「囲って解答アシスタント」はナビゲーションバー側の配置で管理します。見つからないときは非表示になっていないか確認してください。
