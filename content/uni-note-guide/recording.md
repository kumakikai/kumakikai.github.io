授業の録音から再生、文字起こし、AI要約までを順に使えます。

{{< guide-anchor "目的から選ぶ" >}}

## 授業を録音して保存する {#capture}

ノートを取りながら授業を録音し、あとから同じノートで聴き直せます。録音を終えたら停止して保存します。

### 必要な条件 {#capture-必要な条件}

PremiumまたはPremium Plus。マイクの使用許可。

### 録音を始める {#録音を始める}

1. 保存先のノートを開きます。
2. ナビゲーションバーの「録音」で録音パネルを開きます。
3. 初回はマイクの使用を許可します。
4. 赤い録音ボタンをタップします。
5. 録音中の表示と経過時間を確認します。

{{< uni-guide-image slot="v4-recording-panel" >}}

### 一時停止・再開・保存 {#一時停止再開保存}

1. 中断するときは一時停止をタップします。
2. 続きを録るときは再開をタップします。
3. 終わったら停止します。
4. 保存された録音が一覧にあることを確認します。

1件は最大30分で自動分割され、続きは「（録音名） Part 2」のような名前で保存されます。1ノートに保存できる録音は5件までです。録音中に上限に達すると「このノートで保持できる録音数の上限に達したため、録音を停止しました。」と表示されて停止するため、長い授業では保存件数を確認してください。

Freeプランで録音しようとすると「録音はPremium限定です」と表示されます。

### ノートを離れる前に {#ノートを離れる前に}

録音中にノートからホームなどへ移動しようとすると「録音を終了しますか？」と表示され、「録音を保存して終了」を選ぶと録音を保存して移動します。

ホーム画面へ戻る、別のアプリを全画面で開く、iPadをスリープするなど、Uni:Noteがバックグラウンドに移ると、録音は自動で保存されて停止します。バックグラウンドで録り続けることはできません。授業中は「設定 → 表示設定」の「ノートを開いている間はスリープしない」をONにしておくと安心です。

録音一覧に保存された音声が表示され、再生できる状態になります。

## 録音を再生・整理・共有する {#play}

保存した授業音声を、再生位置や速さを変えながら聴き直せます。名前の変更や音声ファイルの共有もできます。

### 必要な条件 {#play-必要な条件}

PremiumまたはPremium Plus。保存済みの録音。

### 聴きたい箇所を再生する {#聴きたい箇所を再生する}

1. ノートの録音パネルを開きます。
2. 保存した録音を選び、行を展開します。
3. 再生ボタンをタップします。もう一度タップすると一時停止します。
4. 再生位置のバーを動かすか、15秒戻る・進む操作で位置を合わせます。
5. 再生速度を選びます。0.75・1・1.25・1.5・2倍から選べます。

### 名前を変える {#名前を変える}

録音の「録音名を変更」を選び、分かりやすい名前を入力して確定します。

### 音声を書き出す {#音声を書き出す}

録音の「音声を共有」を選び、iPadOSの共有シートで保存先やアプリを選びます。ファイルとして保存すれば、Uni:Noteの外でも音声を扱えます。

### 不要な録音を削除する {#不要な録音を削除する}

対象の録音で「録音を削除」を選び、確認してから実行します。削除後は一覧から消えます。必要な音声は先に共有で保存するか、音声を含むバックアップを作ってください。

{{< uni-guide-image slot="recording-play--m-m26" >}}

{{< uni-guide-image slot="recording-play--m-m28" >}}

### 完了の確認 {#play-完了の確認}

聴きたい録音を、指定した位置・速度から再生できます。

### 注意事項 {#play-注意事項}

録音の削除をゴミ箱で復元する手順はありません。音声共有と文字起こしテキストの共有は別です。

## 録音を文字起こしする {#transcribe}

録音の内容を文字で読み、保存後は音声と照らし合わせて復習できます。録音前に話される言語を選びます。

### 必要な条件 {#transcribe-必要な条件}

PremiumまたはPremium Plus。対応するiPadOS 26以降の端末・言語・音声認識環境。必要な権限と音声認識用データの準備。

### 文字起こしの言語を選ぶ {#文字起こしの言語を選ぶ}

1. 録音前に「設定 → 学習支援」の「録音サポート」を開きます。
2. 「録音の文字起こし言語」を選びます。
3. 日本語・英語・韓国語・ドイツ語・繁体字中国語・フランス語から、録音する内容に合う言語を指定します。

録音パネルの「言語：（言語名）」ボタンからも選べます。録音中は変更できません。

これは音声を認識する言語です。AI要約などの回答言語とは役割が異なります。

「設定 → 学習支援 → 録音サポート」の「文字起こしの精度を優先」は、ONでは精度を優先するため表示まで時間がかかる場合があり、OFFではより速く表示される一方で精度が下がる場合があります。設定の変更は次に開始する録音から反映されます。

{{% uni-v4 %}}
4.0.0を新しくインストールした場合、「文字起こしの精度を優先」の初期状態はOFFです。以前から使っている場合は、それまでの設定が引き継がれます。
{{% /uni-v4 %}}

{{< uni-guide-image slot="v4-recording-settings" >}}

### 録音しながら文字を見る {#録音しながら文字を見る}

1. ノートの録音パネルを開きます。
2. 言語と準備状態を確認します。
3. 録音を開始します。
4. 表示される文字起こしを確認します。
5. 手書きに集中するときはパネルをたたみます。録音は続きます。
6. 終わったら停止して保存します。

### 保存後に読む・共有する {#保存後に読む共有する}

1. 保存した録音を選びます。
2. 「リアルタイム」を選んで文字起こしを表示します。
3. 再生し、再生位置に合わせた文の強調を見ながら聴きます。
4. 「文字起こしを共有」から保存先を選びます。

共有するテキストにはタイトル・日時・時刻情報が含まれます。音声ファイルを共有する操作とは別です。

### 完了の確認 {#transcribe-完了の確認}

保存した音声と文字起こしを、同じ録音から見返せます。

### 注意事項 {#transcribe-注意事項}

文字起こしを利用できない環境では「リアルタイム文字起こしとAI要約は iPadOS 26 以降で利用できます。録音は通常通り保存されます。」と表示されます。iPadOS 26以降であっても、端末・言語・音声認識の準備状態によってはこの表示になります。音声認識の許可がない場合は「文字起こしの許可がないため、録音のみ行います。」と表示されます。どちらの場合も録音は保存されます。認識結果は音声と照合してください。

## 文字起こしからAI要約を作る {#summary}

保存した文字起こしをAIで要約します。勉強用と打ち合わせ用を選び、同じノートの複数録音をまとめることもできます。

### 必要な条件 {#summary-必要な条件}

PremiumまたはPremium Plusの録音機能で保存した文字起こし（文字起こしにはiPadOS 26以降の対応環境が必要です）。通信環境とAI残量。

### 対象と形式を選んで生成する {#対象と形式を選んで生成する}

1. ノートの録音パネルで対象の保存済み録音を選びます。
2. 「AI要約」をタップすると「録音要約アシスタント」が開きます。
3. 「録音」で要約する録音を選びます。複数をまとめる場合も同じノート内から選びます。
4. 「要約形式」で「勉強用」または「打ち合わせ用」を選びます。
5. 「文字数」「予想消費量」「現在のAI残量」を確認します。
6. 「AI要約を作成」をタップし、結果を待ちます。

複数の録音は時系列に沿ってまとめられます。AIへ送信されるのは端末で作成済みの文字起こしテキストだけで、音声ファイルは送信されません。要約が保存された録音には「AI要約あり」と表示されます。

### 保存した結果を読む・共有する {#保存した結果を読む共有する}

対象の録音を開き、「リアルタイム」（文字起こし）と「AI要約」を切り替えて読みます。保存済み要約の再表示は、新しく生成する操作とは別です。

要約の共有で「テキストとして共有」または「JSONとして共有」を選び、共有先へ渡せます。通常の読み返しにはテキスト、他の処理で構造を利用する場合はJSONを選びます。

### いつも使う形式を決める {#いつも使う形式を決める}

「設定 → 学習支援 → 録音サポート」で「AI要約の既定形式」を開き、勉強用か打ち合わせ用を選びます。次回の開始時の選択に使われ、その回だけ別の形式に変えることもできます。

### 完了の確認 {#summary-完了の確認}

録音に対応するAI要約が保存され、文字起こしと切り替えて読めます。

### 注意事項 {#summary-注意事項}

要約は授業資料や文字起こしと照合してください。生成にはAI残量を使います。

## AI要約を現在のノートへ貼る {#paste}

生成したAI要約を、現在開いているノートへ画像として貼り付けます。要点の横へ手書きで補足できます。

### 必要な条件 {#paste-必要な条件}

保存済みのAI要約。追記にはApple Pencil。

### 貼り付け先を決める {#貼り付け先を決める}

1. 要約を置きたいノートを開きます。
2. 貼り付けを始めたいページへ移動します。
3. 録音パネルから保存済みのAI要約を開きます。

### 要約を貼って追記する {#要約を貼って追記する}

1. 要約の「ノートに貼る」を選びます。
2. 現在のページと、その後ろのページを確認します。
3. パレットでペンを選びます。
4. 要約の上や余白へ、自分の補足を書き込みます。

要約は固定された画像として、開いているページから貼り付けられます。内容が長い場合は後ろにページが自動で追加されます。完了すると「AI要約をノートに貼り付けました」と表示されます。新しいノートを自動作成する操作ではありません。ノートの上限150ページを超える場合は貼り付けできません。貼った要約を動かすときは、写真と同じように固定を解除してから操作します。

### 完了の確認 {#paste-完了の確認}

開いているノートに要約と手書きの補足が残ります。
