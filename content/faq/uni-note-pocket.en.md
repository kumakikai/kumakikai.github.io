## Before you start {#help-1}

Requires an iPhone running iOS 17.0 or later.

Pocket is an iPhone reader requiring a backup created in Uni:Note on iPad. It cannot create a new note by itself. No separate app account is required.

Create, edit, delete and reorder notes, pages, folders or question sets on iPad.

## A backup fails or does not update {#help-2}

Damaged zips and backups missing required files are rejected. Failed import keeps prior data and never edits the original zip. Export a fresh zip from Uni:Note and select it without unpacking.

The Easy Backup refresh icon checks the iCloud file state. Its date stays unchanged if the newer file has not arrived. Load Manually imports after that check. Auto-load on launch runs only when an available backup exists; it is not realtime sync.

[Load the latest backup]({{< relref "/htu/uni-note-pocket/" >}}#refresh) →

## Notes, recordings or markers are missing {#help-3}

Search covers explicit imported note titles, not handwriting, body text, PDFs or subject names. Question sets and markers appear only if included in the backup. Tapping a marker changes its display without editing it.

A backup without audio cannot play recordings. Export with audio enabled on iPad and import again. Pocket cannot record, transcribe or generate AI summaries.

## Reading position or appearance differs {#help-4}

Resume from Last Position must be on to resume the last page. Change language, theme or subject label using the Home gear. Pinch or double-tap to zoom. Normal notes scroll vertically; vertical notebooks move sideways.

Detailed operations are in the visual guide, also available through Settings → Support → How to Use inside the app.
