## 기본

### Uni:Note Pocket은 어떤 앱인가요?
Uni:Note Pocket은 iPad 전용 앱 **Uni:Note**의 보조 앱입니다.  
Uni:Note에서 만든 백업 데이터를 iPhone으로 `가져오기` 해서 노트, 페이지, `문제집` (준비 중 / v1.1.0 대응 예정)을 읽기 전용으로 다시 볼 수 있습니다.

### Uni:Note Pocket만으로 사용할 수 있나요?
아니요.  
Uni:Note에서 만든 백업 파일이 필요합니다.

### 지원 기기는 무엇인가요?
iPhone 전용입니다.

### 로그인이나 계정 등록이 필요한가요?
필요하지 않습니다.

## 가져오기와 백업

### 처음에 무엇을 하면 되나요?
오른쪽 위의 **가져오기**에서 Uni:Note 백업을 선택하면 됩니다.  
이 iPhone에 Uni:Note의 `간편 백업` (준비 중 / v1.1.0 대응 예정)이 있으면, 바로 불러올지 묻는 안내가 표시될 수도 있습니다.

### 무엇을 가져올 수 있나요?
다음을 가져올 수 있습니다.

- Uni:Note에서 만든 백업 zip 파일
- 이 iPhone에서 찾은 Uni:Note `간편 백업` (준비 중 / v1.1.0 대응 예정)

### 가져오기 중 원본 백업 파일이 변경되나요?
아니요.  
선택한 zip을 검증한 뒤 앱 안에서 펼쳐서 읽기 때문에 원본 파일은 수정되지 않습니다.

### 가져오기에 실패하면 어떻게 되나요?
손상되었거나 잘못된 백업은 안전하게 중단됩니다.  
이미 이전에 가져온 데이터가 있으면 그 데이터는 유지한 채 오류만 표시합니다.

### 자동 동기화가 있나요?
현재는 없습니다.  
Uni:Note Pocket은 백업 데이터를 다시 보는 방식으로 설계되어 있습니다.

### `실행 시 자동 불러오기`는 무엇인가요? (준비 중 / v1.1.0 대응 예정)
이 기능은 준비 중이며 v1.1.0에서 대응 예정입니다.  
`설정 > 간편 백업` (준비 중 / v1.1.0 대응 예정)에 있는 항목입니다.  
이 iPhone에 사용할 수 있는 Uni:Note `간편 백업` (준비 중 / v1.1.0 대응 예정)이 있을 때만, 실행 시 자동으로 불러옵니다.

### `수동으로 불러오기`는 무엇인가요? (준비 중 / v1.1.0 대응 예정)
이 기능은 준비 중이며 v1.1.0에서 대응 예정입니다.  
`설정 > 간편 백업 > 수동으로 불러오기` (준비 중 / v1.1.0 대응 예정)에서 실행하는 항목입니다.  
현재 이 iPhone에서 찾은 Uni:Note `간편 백업` (준비 중 / v1.1.0 대응 예정)을 원하는 시점에 읽어올 수 있습니다.

## 열람

### 가져온 뒤에 무엇을 할 수 있나요?
주요 기능은 다음과 같습니다.

- **최근 사용한 노트**에서 다시 시작
- 최상위 목록 확인
- **노트** 목록 열기
- 페이지 보기
- `문제집` 열기 (준비 중 / v1.1.0 대응 예정)
- 암기 레이어 표시 / 숨기기

### 노트나 페이지를 편집할 수 있나요?
없습니다.  
Uni:Note Pocket은 읽기 전용입니다.

### 노트를 만들거나 삭제하거나 순서를 바꿀 수 있나요?
없습니다.  
생성과 편집은 Uni:Note에서 하는 것을 전제로 합니다.

### `문제집`을 볼 수 있나요? (준비 중 / v1.1.0 대응 예정)
이 기능은 준비 중이며 v1.1.0에서 대응 예정입니다.  
네.  
가져온 백업에 Uni:Note에서 저장한 `문제집` (준비 중 / v1.1.0 대응 예정)이 포함되어 있으면 홈의 **문제집** (준비 중 / v1.1.0 대응 예정)에서 열어 복습할 수 있습니다.

### 암기 레이어는 무엇인가요?
복습할 때 페이지 단위로 켜고 끌 수 있는 레이어입니다.  
오른쪽 눈 버튼으로 **암기 레이어 표시** / **암기 레이어 숨기기**를 전환합니다.

### 페이지를 확대할 수 있나요?
네.  
핀치 제스처나 더블탭으로 확대할 수 있습니다.

### 마지막으로 보던 위치에서 다시 시작할 수 있나요?
네.  
설정의 **마지막 위치에서 다시 열기**에서 켜고 끌 수 있습니다.

## 설정

### 어떤 설정이 있나요?
주요 설정은 다음과 같습니다.

- **언어**
- **테마**
- **마지막 위치에서 다시 열기**
- **가로 흔들림 방지**
- **과목 이름**
- **간편 백업** (준비 중 / v1.1.0 대응 예정)

### `과목 이름`에서는 무엇을 바꿀 수 있나요?
최상위 이름을 **과목 / 노트 / 그룹 / 카테고리** 중에서 고를 수 있습니다.

### `사용 방법`과 개인정보 처리방침 페이지가 있나요?
네.  
앱 안에서는 `설정 > 지원 > 사용 방법`에서도 열 수 있습니다.
