## はじめに

Uni:Noteは、iPadで手書きノートやPDFをまとめ、録音・付箋・問題集などの学習支援を使って見返すためのアプリです。

{{< guide-anchor "基本" "uninoteはどんなアプリですか" "対応端末は" "対応言語は" "apple-pencilは必要ですか" "ログインやアカウント登録は必要ですか" >}}

### 対応端末・対応OSは？ {#help-1}

iPadOS 17.0以降のiPadに対応しています。

Apple Pencilで手書きできます。「指で描画」をONにすると1本指でも書けます。ONではノートのスクロールに2本指を使います。OFFでは1本指でスクロールします（「設定 → ノート設定」の「2本指でスクロール」がONなら2本指）。アプリ独自のアカウント登録は不要です。日本語・英語・韓国語・ドイツ語・繁体字中国語・フランス語に対応しています。

### ノートが増えない・探せない場合は？ {#help-2}

1ノートは最大150ページです。上限に達したら、同じ教科に新しいノートを作成してください。名前を空欄で確定したノートには日付が使われます。検索対象は入力したノートタイトルで、本文・手書き・PDF・教科名は含みません。

ノートの名前変更・保護・削除は、ノート一覧でノートを長押しして表示されるメニューから行います。縦ノートにするかどうかは教科を作るときに選び、あとから切り替えることはできません。フォルダを削除しても中の教科は残ります。教科・ノートはゴミ箱から復元できますが、ページ・問題集の削除や完全削除は元に戻せません。保護中のノートには書き込めず、削除もできません。

ゴミ箱に移した教科・ノートは30日経過後の整理で完全に削除されます。必要なものは期限内に復元してください。

### ズームや手書きの範囲移動はできますか？ {#zoom-handwriting}

2本指のピンチで拡大・縮小できます。「範囲移動」は手書きの線を囲んで移す操作です。写真・PDF・付箋はそれぞれ個別に動かします。

[ズームと手書きの操作]({{< relref "/htu/uni-note/" >}}#write) →

### 追加したテキストや表は後から編集できますか？

キーボードで入力した文字は、確定後に位置と大きさを変えられますが、文字の内容は再編集できません。表は図形として行数・列数を選んで配置します。セルに文字を直接入力したり、配置後に行数・列数を変更したりすることはできません。

[テキストと図形・表の操作](/htu/uni-note/writing/#text-shapes) →

{{< guide-anchor "写真pdf" "写真は貼れますか" "写真を書類として貼付できますか" "pdfは貼れますか" "pdfを書き出せますか" >}}

### 写真・PDFを動かせない場合は？ {#help-3}

「指で描画」がOFFなら、固定中の資料をダブルタップして固定を解除し、タップして選択します。ONならノート画面の「編集」ボタンを押して青い状態にし、資料をタップします。手書きの範囲移動と、写真・PDFの移動は別の操作です。資料を消さず手書きだけ消す場合は、消しゴムの「ページをクリア」を使います。写真貼付では「カメラで撮影」と「写真から選択」を選べます。ほかのアプリからのドラッグ＆ドロップでは取り込めません。

PDF貼付でもノートの150ページ上限は変わりません。必要に応じて別のノートに分けて貼り付けてください。写真、書類写真、PDF貼付・出力の手順は画像付きガイドへまとめています。

[写真・PDFの操作]({{< relref "/htu/uni-note/" >}}#pdf) →

## 学習支援について

{{< guide-anchor "録音文字起こし" "録音機能は使えますか" "文字起こしとai要約は使えますか" "録音はバックアップに含まれますか" >}}

### 録音・文字起こしを使えない場合は？ {#help-4}

録音、再生、文字起こし閲覧はPremiumまたはPremium Plusで使えます。録音時にはマイクへのアクセスを許可してください。文字起こしはiPadOS 26以降に加え、対応するAppleの音声モデルと言語が必要です。利用できない環境では「リアルタイム文字起こしとAI要約は iPadOS 26 以降で利用できます。」と表示されますが、録音・再生は引き続き利用できます。Uni:Noteがバックグラウンドに移ると、録音は自動で保存・停止します。

録音は30分ごとに自動分割され、1ノート5件までです。「設定 → 学習支援 → 録音サポート」の「文字起こしの精度を優先」は、ONで精度、OFFで表示速度を優先し、変更は次の録音から反映されます。AI要約は作成済みの文字起こしテキストを使い、音声ファイルを要約用に送信しません。録音音声を復元・Pocket再生したい場合は、バックアップ時に音声を含める設定をオンにしてください。

[録音の操作]({{< relref "/htu/uni-note/" >}}#recording) →

### 付箋・AI学習支援が見つからない場合は？ {#help-5}

付箋マーカーはパレット、囲って解答アシスタントはナビゲーションバーにあります。見つからない場合は「設定 → 表示設定 → ノート画面」の「パレット」「ナビゲーションバー」で非表示になっていないか確認してください。付箋マーカーは1本ずつタップして表示を切り替えます。メモを書き込める「付箋」は、付箋マーカーの詳細で「付箋」に切り替えて貼ります。

囲って解答、問題集のAI生成、AI要約はAI残量を使います。残量と追加購入は設定・プラン画面で確認できます。問題集の手動作成・編集・学習にはAI残量を使いません。長文読解・自由記述・図表中心など、解答できない問題もあります。結果は授業資料などと照らしてください。

[付箋・問題集で復習する]({{< relref "/htu/uni-note/" >}}#review) →

### 問題集はどのように作り、学習しますか？ {#problem-sets}

ノートを開いて「その他」の「問題集を作る」を選ぶと、ノートのページからAIで問題集を作れます（AI残量を使います）。保存した問題集は、ホーム左上の「問題集」ボタンで表示を切り替えて開きます。

{{% uni-v4 %}}
4.0.0では、問題集表示の「＋」から「1問ずつ作成」（手書き・キーボード）、「貼り付けて作成」「ファイルから作成」（TSV・CSV、最大300問、PremiumまたはPremium Plus）で作れるようになります。学習では、右スワイプで「覚えた」、左スワイプで「覚えていない」を記録し、1周終わると覚えていない問題だけをもう一周できます。途中で閉じても続きから再開できます。iPhone版のUni:Note Pocketでも、バックアップから読み込んだ問題集を同じ方法で学習できます（Pocketを最新版に更新してください）。
{{% /uni-v4 %}}

[問題集の使い方](/htu/uni-note/problem-sets/) →

### 授業のノートをすぐに開くには？ {#timetable}

ホーム左上のカレンダーのボタンから時間割を作り、曜日・時限に教科を置きます。教科のマスをタップすると、その教科のノート一覧が開きます。「設定 → 表示設定 → 起動時に開く画面」で「時間割からノートを開く」を選ぶと、アプリを起動したときに今の授業のノートが開きます。

[時間割の使い方](/htu/uni-note/timetable/) →

### 手書きできる付箋の大きさは変えられますか？ {#sticky-note}

貼ったあとに大きさや角度は変えられません。付箋マーカーの詳細で「付箋」に切り替え、9種類の形・大きさから選んで貼り直してください。付箋は上端の糊の部分をドラッグして動かし、糊の部分を長押しすると削除できます。付箋の追加・移動・削除は「戻る」で取り消せます。

[付箋の使い方](/htu/uni-note/study/#sticky-note) →

## データについて

{{< guide-anchor "データと保存" "データはどこに保存されますか" "診断データやクラッシュ情報は送信されますか" "自動同期はありますか" "バックアップはありますか" "かんたんバックアップ-は誰でも使えますか" "復元後はすぐ使えますか" >}}

### バックアップ・保存・診断情報はどう扱われますか？ {#help-6}

ノートはアプリ内に保存されます。PremiumまたはPremium Plusで使えるiCloudのかんたんバックアップはファイルの保存・復元であり、自動同期ではありません。Freeでもzipの書き出しとファイルからの復元はできます。復元は確認なしで始まり、現在のデータが置き換わるため、先に現在のデータを書き出しておいてください。復元後はアプリの案内に従って開き直してください。問題集もバックアップに含まれます。

不具合調査のためFirebase Crashlyticsの技術的な診断情報を、利用状況の把握のためGoogle Analytics for Firebaseの情報を送信する場合があります。強制終了の調査のため、手書きデータの線の数などの統計値を診断に含める場合がありますが、手書きの内容やノート名は含みません。ノート本文・手書きの内容・画像・PDF・録音内容を診断ログには含めません。詳しい扱いは、このページ下部のプライバシーポリシーで確認できます。

## 購入について

{{< guide-anchor "無料版に制限はありますか" >}}

### Free・Premium・Premium Plusの違いは？

Freeは教科10件・1教科あたりノート6冊までです。買い切りPremiumと月額Premium Plusはこの制限を解除し、録音やかんたんバックアップなどを利用できます。買い切りPremiumには月初に500 AI残量、Premium Plusには加入・更新期間ごとに10,000 AI残量が付与され、未使用の期間分は繰り越されません。**範囲移動とノートタイトル検索はFreeでも使えます。** 料金・購入状態はアプリ内のプラン画面で確認してください。

{{% uni-v4 %}}
問題集の一括作成（貼り付け・ファイルの読み込み）はPremiumまたはPremium Plusで利用できます。1問ずつの作成と問題集での学習はFreeでも使えます。
{{% /uni-v4 %}}

### AI残量はどのように購入しますか？

プラン画面で追加するAI残量と購入条件を確認して購入します。AI残量は囲って解答、問題集のAI生成、AI要約で使用します。追加購入分はプランの期間付与分とは別に保持され、有効期限はありません。購入後の付与に時間がかかる場合は、「購入状態を更新」を使い、アプリの表示に従って残量を確認してください。
