はじめに

毎日届くビザで行き先の国を選び、名所の景色を指先で歩いて、旅券にスタンプを集める操作を紹介します。アカウント登録は不要です。

iOS 18以降のiPhoneと、iPadOS 18以降のiPadに対応しています。表示は日本語と英語で、端末の言語設定に合わせて切り替わります。iPhoneでは画面下のタブが 旅・スタンプ帳・外交官・設定 の4つで、外交官パスポートの購入後は「外交官」が パスポート になります。iPadと開いたiPhone Duoでは、同じ項目が画面右端の操作列に並びます。

はじめて起動したとき

はじめて起動すると、アプリの遊び方を3枚で紹介します。次へ か左右のスワイプで進み、最後の 最初のビザを受け取る をタップすると、最初のビザの画面が開きます。右上の スキップ でも同じです。紹介は、あとから 設定 → 操作説明をもう一度見る で見直せます。

ビザを受け取る

今日のビザ

  1. 「最初のビザが届きました」または「今日のビザが届きました」の画面で、行き先の国をひとつ選びます。
  2. （国名）のビザを申請する をタップします。ビザのカードが査証ページに貼られます。
  3. ページをタップすると、その国のスタンプが押されます。
  4. （国名）へ出発する で名所の一覧へ、あとで で国の一覧へ進みます。

ビザは1日にひとつ届き、好きな国を選べます。はじめて使う日は、3か国分のビザを続けて受け取れます。受け取らずに閉じた日は、その日のうちなら国の一覧の「ビザ未取得」のカードから申請できます。その日の分を受け取ったあとは「明日また新しいビザが届きます」と表示されます。

ビザのお知らせ

3枚目のビザを受け取ったあとに、次のビザのお知らせを受け取るかを尋ねます。お知らせする を選ぶと、通知の許可を求めたうえで、ビザを受け取った翌朝9時に、次のビザが届いたことを通知します。設定 → ビザのお知らせ でいつでも切り替えられます。

国を選ぶ

旅 タブの「どの国へ行く？」には、アジア、西ヨーロッパ、南ヨーロッパ、北ヨーロッパ、中央ヨーロッパ、北米、オセアニア、中東の8つの地域に分けて、39の国と地域のカードが並びます。カードには日本語名と英語名、その国を象徴する絵が入ります。

  • ビザのある国のカードをタップすると、名所の一覧が開きます。
  • ビザのない国は薄く表示され、鍵のマークと「ビザ未取得」が付きます。タップすると、今日のビザの申請、または明日のビザの案内に進みます。
  • 名所をすべてめぐった国のカードには、右上にCOMPLETEのスタンプが付きます。

名所を選んで歩く

名所のカード

名所の一覧には、世界遺産と各国の定番の名所がカードで並びます。カードには名所の名前と、場所の見当がつく地域名（例：東京都・浅草）があり、世界遺産には「世界遺産」の印が付きます。カードをタップすると説明文が開き、もう一度タップすると閉じます。探索 をタップすると、その名所の景色へ向かいます。

景色の歩き方

はじめて 探索 を押したときは「景色の歩き方」を表示します。散策をはじめる で景色が全画面で開きます。

  • スワイプで見渡す：画面を左右・上下になぞると、周りを見回せます。
  • 道をタップして進む：行きたい方向の道路をタップすると、その場所まで移動します。
  • 右上の × で散策を終える：× を押すと散策を終えて、旅券にスタンプが押されます。

景色はAppleのマップのデータを使って表示するため、インターネット接続が必要です。取得できないときは短いメッセージが表示され、× で一覧に戻れます。

スタンプを集める

訪問スタンプ

景色を開いて散策し、× で終えると、その名所の訪問スタンプが押される演出が流れ、一覧へ戻る で名所の一覧に戻ります。スタンプを押した名所のカードには、右上にスタンプが表示されます。同じ名所をもう一度歩いても、最初の日付のまま変わりません。

COMPLETEとお祝い

その国の名所をすべてめぐると、最後のスタンプのあとにお祝いの画面が開き、COMPLETEの印が押されます。共有する で、その国の訪問スタンプを並べた1枚の画像を共有できます。一覧へ戻る で戻ります。すべての国をめぐると、世界一周の修了証が届きます。お祝いを見逃したときは、次にスタンプ帳を開いたときに表示します。

スタンプ帳

スタンプ帳 タブでは、上部の ビザ と 訪問 を切り替えて、集めた記録を見返せます。ビザでは国ごとの取得済みのビザと取得日を、訪問では国ごとの訪問数と名所ごとのスタンプを表示します。スタンプをタップすると拡大できます。

外交官パスポート

外交官 タブで、買い切りのApp内課金「外交官パスポート」を購入できます。購入すると、旅券の 表紙・査証ページ・限定スタンプ・入国のスタンプ・アプリのアイコン が外交官仕様になり、広告なし になります。特典として、ビザなしですべての国へ入国できます（今後追加される国も含みます）。価格は、購入画面の （価格）で発行する ボタンに表示されます。

購入後は、タブの名前が パスポート に変わり、発行済みの旅券を表示します。機種変更やアプリの入れ直しのあとは、同じApple Accountで 設定 → 購入を復元 をタップします。

ビザを取得していない国でも、その国の名所を訪問していれば、スタンプ帳のビザのページから外交官の入国スタンプを押せます。

設定

設定 タブには、次の項目があります。

  • ビザのお知らせ：次のビザが届いたことを通知するかを切り替えます。
  • 購入：外交官パスポートの発行状況と 購入を復元。広告の同意が必要な地域では 広告のプライバシー設定 も表示します。
  • 操作説明をもう一度見る：はじめての紹介をもう一度表示します。
  • スタンプの記録をリセット：訪問の記録とスタンプを消します。ビザ、外交官パスポート、入国のスタンプは消えません。元に戻せません。
  • プライバシーポリシー・お問い合わせ：プライバシーポリシーの確認と、お問い合わせの窓口です。

iPadとiPhone Duoで使う

横向きのiPadと開いたiPhone Duoでは、名所の一覧が見開きになります。左のページに名所の一覧、右のページに選んだ名所の写真・説明文・探索 ボタンが並び、景色は見開き全体に表示されます。閉じたiPhone Duoでは旅券の表紙が表示され、開くと旅がはじまります。閉じたまま見る を選ぶと、通常のiPhoneと同じ画面で使えます。
