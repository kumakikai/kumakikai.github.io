How to Use

アプリ別の使い方

このページでは、各アプリの使い方を案内しています。

対象アプリ:

  • すわなび - 禁煙カウンターアプリ
  • ギャンカレ（Balance Calendar）
  • SIGNAL
  • 大学ノート - Uni:Note

How to Use (すわなび)

すわなびは、喫煙 と 我慢 をすばやく記録し、あとから数字で振り返るためのアプリです。 禁煙補助として使うことも、今の喫煙状況を把握するための記録アプリとして使うこともできます。 1. 最初の設定をする 初回起動時は、チュートリアルのあとに以下を設定します。 1箱の本数 1箱の金額 この設定をしておくと、喫煙本数や我慢回数を金額換算で確認できます。 2. 「記録」タブで喫煙 / 我慢を記録する 中央の 記録 タブでは、緑の 我慢 と赤の 喫煙 を大きなボタンで記録できます。 我慢 は「吸いたいと思ったが吸わずに済んだ記録」です 喫煙 は実際に吸った記録です 当日の件数や節約額、前回記録からの経過時間もこの画面で確認できます。 3. 履歴を確認して、削除や取消しをする 記録 タブ右上の 履歴 から、その日の記録一覧を確認できます。 不要な記録は削除できます 削除直後は 取消し で元に戻せます 4. 過去の日付の記録を見直す 記録画面では日付を切り替えて、過去日の記録確認や追加入力ができます。 「今日だけでなく、あとからまとめて残したい」という使い方にも対応しています。 5. 「カレンダー」タブで日別 / 月別 / 年別に振り返る 左下の カレンダー タブでは、次の単位で記録を確認できます。 日別 月別 年別 各期間の合計や内訳を、一覧で静かに見返せます。 6. 「グラフ」タブで変化を見る グラフ タブでは、以下の期間で推移を確認できます。 週 月 3か月 喫煙、我慢、喫煙平均を見ながら、最近の変化を確認できます。 7. ホームウィジェットを使う ホームウィジェットを追加すると、当日の 喫煙 / 我慢 件数をホーム画面から確認できます。 ウィジェットから記録導線を開くこともできます。 ...
