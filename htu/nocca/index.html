使い方 (Nocca)

Nocca の使い方

Nocca は、必要なときだけ静かにつながるための家族通信アプリです。

現在開発中のため、以下はプロトタイプ 0.0.1 の UI に基づく案内です。正式公開時に、一部の画面や動作が変更される場合があります。

1. 最初に役割を選ぶ#

初回起動時に、端末をどちらとして使うか選びます。

  • 本人として使う: 家族との通信や接続を管理します。
  • 家族として使う: 本人からの通知を受け取れます。本人が承認すると接続できます。

この画面から このアプリについて も確認できます。

2. 本人として使う#

本人側には、下部に 意思表示 / 会話 / つながり / 設定 のタブがあります。

意思表示#

意思表示 では、文章を書かずにワンタップで家族へ必要なことを送れます。

初期状態では、次のようなカテゴリの意思表示が用意されています。

  • 食事: ご飯ほしい、飲み物ほしい、片付けお願い
  • 生活: お風呂入る、洗濯お願い、着替えほしい
  • 体調・気分: 今は話せない、少ししんどい、休みたい
  • その他: 少し話せる、ありがとう、確認してほしい

右上の + から、家族に伝える言葉とアイコンを追加できます。カードを長押しすると、編集、並び替え、削除を選べます。

通信を休止している間は、意思表示を送れません。送るには通信を再開してください。

会話#

会話 は、必要なときだけ一時的に開く短い会話です。

閉じているときは入力欄を表示せず、今だけ話す から本人側が会話を開きます。会話中は短いメッセージを送れ、本人側からいつでも閉じられます。

家族から会話リクエストが届いた場合は、本人側に 家族が少し話したいようです と表示されます。今だけ話す または 今は閉じたまま を選べます。

つながり#

つながり では、接続中の家族、通信の状態、会話の状態、最近送った意思表示の最新 1 件だけを確認できます。

履歴一覧、既読、未読、返信待ち、最終ログイン、入力中表示はありません。

設定#

設定 では、主に次の項目を管理できます。

  • ミュート設定
  • 会話リクエスト
  • 返信テンプレート
  • 家族を招待
  • 家族の管理
  • 通信を休止する / 通信を再開する
  • アプリについて

3. 家族を招待する#

本人側の 設定 > 家族を招待 から、招待コードまたは招待リンクを共有できます。

招待リンクや招待コードだけで接続が完了するわけではありません。接続には、本人側または相手側での確認が必要です。

家族側から本人へ招待リンクを送ることもできます。その場合も、本人が 接続する を選ぶまで接続は成立しません。

4. 通信を休止する#

本人側の 設定 > 通信を休止する から、一時的に通知や会話を休めます。

休止中は、家族からの通知、返信、会話リクエストを受け取りません。あとから 通信を再開する で戻せます。

5. 家族として使う#

家族側には、下部に 受信 / 会話 / 設定 のタブがあります。

未接続のとき#

家族側は、招待コードがなくても未接続状態で開始できます。

未接続画面では、次の操作ができます。

  • 本人に招待リンクを送る
  • 本人から共有された招待コードを入力する

接続には本人の承認が必要です。

受信#

受信 では、本人から届いた最新の意思表示を確認できます。

家族側は、了解、少し待ってね、大丈夫だよ などの短い定型返信を返せます。返信後は 返信しました と選んだ返信だけが控えめに表示されます。

本人からの意思表示がない場合、催促導線は表示されません。

会話#

会話 では、本人が会話を開いている間だけ短いメッセージを送れます。

本人側が許可している場合のみ、家族側から 会話リクエストを送る ことができます。リクエストには間隔制限があり、本人が開くまで会話は始まりません。

設定#

家族側の 設定 では、接続、返信テンプレートの並び替え、アプリ情報だけを確認できます。

本人側のミュート、通信休止、家族管理、返信文言の編集などは、家族側から変更できません。

6. Nocca でしないこと#

Nocca は、家庭内の摩擦や返信圧力を減らすためのアプリです。

次のような機能は、初期設計には含めていません。

  • 既読表示
  • 最終ログイン表示
  • 入力中表示
  • GPS
  • 生存監視
  • 行動ログ
  • 感情分析
  • 常時自由チャット
  • SNS 要素
  • 支援者向けダッシュボード
  • 広告

7. うまく使えないとき#

家族と接続できない#

招待コードが正しいか確認してください。家族側から招待リンクを送った場合は、本人側で承認するまで接続は完了しません。

意思表示を送れない#

通信休止中は意思表示を送れません。本人側の 設定 > 通信を再開する から再開してください。

家族側から会話リクエストを送れない#

本人側が会話リクエストを受け取らない設定にしている場合や、間隔制限中の場合は送れません。

通知や同期が期待通りに動かない#

現在のプロトタイプでは、正式なアカウント、端末間同期、Push 通知は未実装です。正式公開時の仕様が確定した段階で、このページを更新します。
