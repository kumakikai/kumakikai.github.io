ギャンカレ/使い方

使い方 (ギャンカレ)

ギャンカレは、収入 / 支出 を短い操作で記録し、あとから 日別 / 月別 / カテゴリ別 で振り返るためのアプリです。

ギャンブル収支だけでなく、家計簿、推し活貯金、おこづかい帳などにも使えます。

1. 最初に用途に合うタグを選ぶ

初回起動時は、用途に合わせた初期タグを選べます。

  • ギャンブル
  • 家計簿
  • 推し活貯金
  • おこづかい帳

タグ名やアイコンはあとから 設定 > タグ で変更できます。

2. 登録 画面で収入 / 支出を記録する

中央の 登録 画面では、+ 収入 と − 支出 から金額を入力します。

  • 金額はテンキーで入力します
  • タグを選んで分類できます
  • 日付を変えて過去日の記録もできます
  • 未来日は選べません

画面上部では、その日の合計と前月比も確認できます。

3. 履歴 を見直して削除や取消しをする

履歴 から、その日の記録一覧を確認できます。

  • 不要な記録は削除できます
  • 削除直後は 取消し で元に戻せます

4. 収支 画面で振り返る

収支 画面では、次の3つの見方で振り返れます。

  • 日別: 選択した月の日ごとの収支
  • 月別: 選択した年の月ごとの収支
  • カテゴリ別: 選択した月のタグごとの合計

空日表示 を切り替えながら見返せます。 各行を開くと詳細も確認できます。

5. ホームウィジェットを使う

ホームウィジェットを追加すると、ホーム画面からすぐ 収入 / 支出 を記録できます。

設定 > タグ で、ウィジェットから使うデフォルトタグを指定できます。

6. 設定 を調整する

設定 では主に以下を変更できます。

  • テーマ
  • 言語
  • 通貨
  • 空日表示の初期値
  • タグ表示形式
  • タグ名 / アイコン
  • 初期タグセットのやり直し
  • チュートリアルのやり直し
  • アプリ内購入
  • 要望・お問い合わせ

7. 追加購入を使う

設定 > アプリ内購入 から、以下の追加機能を利用できます。

  • 広告削除
  • タグ拡張
  • アプリロック
