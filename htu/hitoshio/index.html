はじめに

ポイントを探してお気に入りにする、自分のポイントを登録する、今日の潮・天気・釣れやすさを確認する、釣行を日記に残して画像で共有する操作を紹介します。アカウント登録は不要です。

iOS 26以降のiPhoneに対応しています。画面下のタブは 日記・今日・ポイント・地図 の4つです。設定で表記をEnglishにすると、タブや見出しの一部がDIARY・TODAY・POINT・MAPなどの英語表記になります。

最初の設定

初めて起動したときに、見た目（シンプル・カラフル・ハイライト）と表記（日本語・English）を選び、はじめる をタップします。見た目と表記は、あとから 設定 → デザイン で変えられます。ハイライトは文字が大きく太くなります。

設定は、日記タブ右上の歯車から開きます。

ポイントを探す

地図でポイントを見る

  1. 地図 タブを開きます。灰色の小さな点が漁港などの公開ポイント、濃い点と名前が自分のポイントです。
  2. 地図を動かすと、下の一覧に見ている範囲の近くのポイントが並びます。一覧は上下にドラッグして大きさを変えられます。
  3. ピンか一覧の行をタップすると、そのポイントのカードが開き、地域名、釣れやすさの週間、今日の天気などを確認できます。

上部左の虫眼鏡から、ポイント名や地名で検索できます。候補は自分のポイントと公開ポイント、Apple Mapsの施設の2段で表示されます。

お気に入りにする

カードやポイント詳細の右上の ⭐ をタップすると、お気に入りになります。お気に入りのポイントは ポイント タブに並び、今日の情報をまとめて確認できます。もう一度タップすると外れます。

お気に入りにできる数は、無料版で10件、ひとしお Plusで30件です。上限に達したときは、ポイントタブで行を左へスワイプして 外す か、ひとしお Plusを利用します。

自分のポイントを登録する

  1. 地図 タブで、登録したい場所が画面の中央に来るように地図を動かします。
  2. 右側の ここを登録（ピンとプラスのボタン）をタップします。地図の中央に照準が表示されます。
  3. 照準を登録したい場所に合わせ、✓ をタップします。やめるときは ✕ をタップします。
  4. 名前を入力し、この場所を登録 をタップします。

登録したポイントは自動でお気に入りになり、公開ポイントと同じように潮・天気・釣れやすさを確認できます。名前の変更と削除は、ポイント詳細の右上の … から行えます。

現在地をポイントにしたいときは、先に右側の現在地ボタンで地図を現在地へ移動してから ここを登録 をタップします。

今日の潮・天気・釣れやすさを見る

ポイントの一覧

ポイント タブには、お気に入りのポイントが並びます。位置情報を許可していると近い順、許可していないときは最近使った順です。

ポイントごとに、天気と気温、降水確率、風向きと風速、UV、その日の総合点とチャンスタイム、1週間の点数を表示します。上部の日付をタップすると、今日を含む7日間から日を選べます。

釣れやすさと潮は、無料版では今日から3日分、ひとしお Plusでは7日分を表示します。無料版の4日目以降は鍵のマークになります。

ポイント詳細

ポイントの行やカードをタップすると、詳細が開きます。

  • 週間：1週間の点数と、いちばん高い日を おすすめの日 として表示します。日付をタップすると、下の情報がその日のものに切り替わります。
  • 釣れやすさ：0時から23時までの時間ごとの目安を棒グラフで表示します。点線が今の時刻、黄色い印はこのポイントで過去に釣れた時刻（日記の釣果の時刻）です。
  • 天気：3時間ごとの天気、降水確率、雨量、気温、風、UVの表です。
  • 太陽：日の出・日の入りの時刻と、朝まずめ・夕まずめの時間帯です。
  • 潮：潮名と、満潮・干潮の時刻つきの潮位の波線グラフです。

経路 をタップすると、AppleマップまたはGoogleマップで経路を開きます。開くアプリは 設定 → 地図 → 経路の案内 で選べます。周辺 は、Apple Mapsの周辺画像（Look Around）が用意されている場所で使えます。

釣れやすさは、潮の動き、朝夕のまずめ、潮回り、風、雨、日中の光などから計算した目安です。計算の考え方と出典は 設定 → このアプリについて → データの出典 で確認できます。

警報・注意報

ポイントの地域に気象庁の警報・注意報が発表されていると、地域名の横に ⚠ が表示されます。タップすると、警報・注意報の名前、対象地域、発表時刻を確認できます。

暴風・波浪・大雨・高潮などの警報が発表されているときは、その日の点数を表示せず、棒グラフを薄くします。表示がなくても安全とは限りません。無理な釣行は控えてください。

釣行中は「今日」で見る

ポイントを今日に登録する

  1. ポイント タブで、行を左から右へスワイプします。または、ポイント詳細の右上の … から登録します。
  2. 「TODAYに登録しました」と表示されたら、今日 タブを開きます。

今日に登録できるのは1か所です。別のポイントを登録すると置き換わります。今日タブの上部のポイント名をタップすると、お気に入りの中から切り替えられます。

今とこの後を確認する

今日タブには、現在時刻と今の天気・風・UV、今の釣れやすさの点数とチャンスタイム、時間ごとの線グラフ、朝まずめ・夕まずめ、潮、気圧を表示します。線グラフの黄色い点線は、このポイントで過去に釣れた時刻と魚種です。

下の 1時間ごと には、今の時刻から23時までの天気、降水確率、気温、風、潮位、点数が並びます。見出しをタップすると、過去の時間も表示できます。

さらに下の 自分の記録 には、このポイントの前回の釣行と釣行回数、魚種ごとの釣果の合計を表示します。

日記を書く

記録をつくる

  1. 日記 タブ右下の ＋ をタップします。
  2. カバー写真、日付、タイトル、ポイント、狙う魚を決めます。ポイントは、自分のポイントと公開ポイントから選びます。地図に戻って登録するときは MAPで登録する をタップします。
  3. 写真や動画をまとめて選びます。撮影時刻の順にタイムラインへ並びます。
  4. 本文、各場面のひとこと、自分用メモを書きます。釣果は ＋ 釣果を追加 で魚種・匹数・サイズを入力し、タイムラインの場面の HIT で釣れた時刻を指定します。
  5. 右下の ✓ で保存します。

写真と動画の枚数に上限はありません。動画は1本60秒までです。釣れなかった日も、釣果なしで保存できます。

記録を見返す

日記の一覧でカードをタップすると、記録の詳細が開きます。カバーの下に、保存時の天気・風・潮と狙う魚、釣果の表、ルアー・仕掛け、本文、タイムライン、自分用メモの順に表示します。天気と潮は、保存時に自動で入ります。

編集と削除は、詳細の右上の …、または一覧のカードを横にスワイプして行います。釣れた時刻（HIT）がある記録は、そのポイントの釣れやすさのグラフに黄色い印で表示されます。

画像で共有する

  1. 記録の詳細で、右上の共有アイコンをタップします。
  2. 上部で形（縦長・カード）と、場所の表示（なし・地域）を選びます。「地域」ではポイント名と都道府県・市区町村名が入ります。
  3. プレビューを確認し、右下の共有ボタンから、LINEなどの送り先を選びます。

縦長の画像は、カバー、天気・潮・釣果、本文、タイムラインを1枚にまとめます。長い記録は複数枚に分かれます。自分用メモ、座標の数値、写真の位置情報は画像に入りません。受け取る側にアプリは不要です。

設定とプラン

設定は日記タブ右上の歯車から開きます。

  • プラン：今のプランと、お気に入りの件数を表示します。ひとしお Plusでは、広告が消え、釣れやすさ・潮の表示が7日分、お気に入りが30件になり、アプリのアイコンを選べます。価格は購入画面で確認してください。解約と登録状況の確認は プランを管理、またはiPhoneの設定の「サブスクリプション」から行えます。
  • デザイン：見た目、表記、アプリのアイコンを変えます。
  • 地図：経路を開くアプリ（Appleマップ・Googleマップ）を選びます。
  • サポート：お問い合わせ・ご意見のフォームを開きます。
  • このアプリについて：潮位・天気・警報・公開ポイントの出典と、プライバシーポリシーです。
