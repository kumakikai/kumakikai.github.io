使い方 (Nocca)

Nocca は、必要なときだけ静かにつながるための家族通信アプリです。 現在開発中のため、以下はプロトタイプ 0.0.1 の UI に基づく案内です。正式公開時に、一部の画面や動作が変更される場合があります。 1. 最初に役割を選ぶ 初回起動時に、端末をどちらとして使うか選びます。 本人として使う: 家族との通信や接続を管理します。 家族として使う: 本人からの通知を受け取れます。本人が承認すると接続できます。 この画面から このアプリについて も確認できます。 2. 本人として使う 本人側には、下部に 意思表示 / 会話 / つながり / 設定 のタブがあります。 意思表示 意思表示 では、文章を書かずにワンタップで家族へ必要なことを送れます。 初期状態では、次のようなカテゴリの意思表示が用意されています。 食事: ご飯ほしい、飲み物ほしい、片付けお願い 生活: お風呂入る、洗濯お願い、着替えほしい 体調・気分: 今は話せない、少ししんどい、休みたい その他: 少し話せる、ありがとう、確認してほしい 右上の + から、家族に伝える言葉とアイコンを追加できます。カードを長押しすると、編集、並び替え、削除を選べます。 通信を休止している間は、意思表示を送れません。送るには通信を再開してください。 会話 会話 は、必要なときだけ一時的に開く短い会話です。 閉じているときは入力欄を表示せず、今だけ話す から本人側が会話を開きます。会話中は短いメッセージを送れ、本人側からいつでも閉じられます。 家族から会話リクエストが届いた場合は、本人側に 家族が少し話したいようです と表示されます。今だけ話す または 今は閉じたまま を選べます。 つながり つながり では、接続中の家族、通信の状態、会話の状態、最近送った意思表示の最新 1 件だけを確認できます。 履歴一覧、既読、未読、返信待ち、最終ログイン、入力中表示はありません。 設定 設定 では、主に次の項目を管理できます。 ミュート設定 会話リクエスト 返信テンプレート 家族を招待 家族の管理 通信を休止する / 通信を再開する アプリについて 3. 家族を招待する 本人側の 設定 > 家族を招待 から、招待コードまたは招待リンクを共有できます。 ...

使い方 (SIGNAL)

SIGNALは、表示したい配信源を選びながら、CREATORS / TODAY / NEWS の3タブで記事を追うニュースフィードアプリです。 ログインなしで使え、GOOD / BAD や記事の閲覧傾向をもとに、表示順が端末内で少しずつ調整されます。 1. 初回はチュートリアルを見る 初回起動時はチュートリアルが表示されます。 迷ったときは 設定 の チュートリアルを見る からいつでも開き直せます。 2. まずは TODAY を見る 中央の TODAY タブが起点です。 有効にしている配信源の記事がまとめて表示されます。 下に引くと再読み込みできます 下までスクロールすると続きを読み込めます 記事カードの GOOD / BAD で表示傾向の調整に使うフィードバックを残せます 3.
