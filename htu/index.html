How to Use

アプリ別の使い方

このページでは、各アプリの使い方を案内しています。

対象アプリ:

  • すわなび - 禁煙カウンターアプリ
  • ギャンカレ（Balance Calendar）
  • SIGNAL
  • 大学ノート - Uni:Note

How to Use (Balance Calendar)

1. 収支を記録する トップ画面で ↑ / ↓ を選び、金額を入力します。 入力は最小限で、迷う要素はありません。 2. 日付を変更する 過去の日付を選択して記録・修正が可能です。 ※未来日は選択できません。 3. タグを付ける 最大4つまでタグを設定できます。 カテゴリ分けは任意です。 4. 履歴の削除とUndo 誤って登録した場合でも、削除後すぐに取り消せます。 5. カレンダーで振り返る 日別 月別 カテゴリ別 数字を並べて見ることだけに集中できます。 6. 設定 テーマ（ライト / ダーク） 言語（日本語 / 英語） タグ表示形式 ※ バックアップや同期機能は現在提供していません。

How to Use (SIGNAL)

SIGNALは、個人発信を静かに追うためのシンプルなニュースフィードアプリです。 使い方もできるだけ迷わないよう、シンプルに設計しています。 基本的な流れは、アプリ内のチュートリアルをご確認ください。 初回利用時や使い方を見直したいときは、まずチュートリアルをご覧いただくのがおすすめです。 このページでは、補足としてごく簡単に案内します。 SIGNALの使い方 アプリ内チュートリアルを確認する まずはアプリ内の案内に沿って、基本的な使い方をご確認ください。 表示したいソースをオンにする 設定画面で、用意されているソースのオン・オフを切り替えられます。表示したいソースをオンにすると、対応する更新を一覧で確認できるようになります。 一覧から更新を確認する ホームで新着をまとめて見られます。必要なものだけを自分のペースで確認してください。 気になる記事を開く 一覧から選択して、記事の内容を確認します。 補足 SIGNALは、多機能さよりも、静かに追えることと分かりやすさを重視しています。 そのため、使い方の中心はアプリ内チュートリアルの確認と、必要な発信者を登録して一覧を見ることです。 ご不明点がある場合は、FAQページもあわせてご確認ください。

How to Use (Uni:Note)

Uni:Note（大学ノート）は、Apple Pencilで手書きするための iPad ノートアプリです。 教科ごとに分けて、ノートごとに講義を整理しながら使えます。 対応環境: iPad専用 Apple Pencilでの手書きが中心 指はスクロールや写真操作に使います 1. ホームで教科を作る ホーム右下の ＋ から新しい教科を作成します。 教科名 罫線（横罫 / 方眼 / 無地） 表紙カラー 作成した教科はホームに追加されます。 タップすると、その教科のノートを開けます。 2. 最初のノートを開く 新しく作った教科を最初に開くと、最初のノート名を入力できます。 入力は任意 入力しない場合は、その日付がノート名になります 2回目以降は、その教科の最後に書いていたノートの続きから開きます。 3.
