アプリ別の使い方

このページでは、各アプリの使い方を案内しています。

対象アプリ:

  • すわなび - 禁煙カウンターアプリ
  • ギャンカレ（Balance Calendar）
  • SIGNAL
  • 大学ノート - Uni:Note

How to Use (SIGNAL)

SIGNALは、表示したい配信源を選びながら、CREATORS / TODAY / NEWS の3タブで記事を追うニュースフィードアプリです。 ログインなしで使え、GOOD / BAD や記事の閲覧傾向をもとに、表示順が端末内で少しずつ調整されます。 1. 初回はチュートリアルを見る 初回起動時はチュートリアルが表示されます。 迷ったときは 設定 の チュートリアルを見る からいつでも開き直せます。 2. まずは TODAY を見る 中央の TODAY タブが起点です。 有効にしている配信源の記事がまとめて表示されます。 下に引くと再読み込みできます 下までスクロールすると続きを読み込めます 記事カードの GOOD / BAD で表示傾向の調整に使うフィードバックを残せます 3. CREATORS と NEWS を使い分ける CREATORS では note / Zenn / Qiita / Hatena / DevelopersIO を確認できます NEWS では Yahooニュース / Google News を確認できます TODAY でまとめて見る使い方も、棚ごとに見る使い方もできます。 4. 記事を開く 記事カードをタップすると、通常はアプリ内ブラウザで記事を開けます。 アプリ内ブラウザでは、次の操作に対応しています。 共有 再読み込み 外部ブラウザで開く 5. 設定 を調整する 設定 では主に以下を変更できます。 ...

How to Use (Uni:Note)

Uni:Note（大学ノート）は、Apple Pencilで手書きするための iPad ノートアプリです。 教科ごとに分けて、ノートごとに講義を整理しながら使えます。 対応環境: iPad専用 Apple Pencilでの手書きが中心 指はスクロールや写真操作に使います 1. ホームで教科を作る ホーム右下の ＋ から新しい教科を作成します。 教科名 罫線（横罫 / 方眼 / 無地） 表紙カラー 作成した教科はホームに追加されます。 タップすると、その教科のノートを開けます。 2. 最初のノートを開く 新しく作った教科を最初に開くと、最初のノートタイトル入力が表示されます。 OK または このまま書く で開始 入力は任意 空欄のまま確定すると、今日の日付がノート名になります 何も確定せずに戻ると、作成途中の最初のノートは残りません 2回目以降は、その教科の最後に書いていたノートの続きから開きます。 3. Apple Pencilで書く 手書きは Apple Pencil 前提です ページは縦に連続表示されます 最後のページに書き始めると、次のページが自動で追加されます すぐ開いて、そのまま書き始める使い方を優先した設計です。 4. ツールを切り替える フローティングツールバーから、以下を切り替えます。 ペン 蛍光ペン 消しゴム 戻る やり直し 補足: ツールバーはドラッグで移動できます ペンはボールペン / シャーペン、色、太さを調整できます 消しゴムは線消しとピクセル消しを切り替えられます 左利き設定で、ツールバーの初期位置を変更できます 5. ノートを切り替える 左上の 一覧 ボタンから、同じ教科内のノート一覧を開けます。 新規ノート で同じ教科に新しいノートを追加できます 新規ノートのタイトル入力も任意で、空欄ならその日付がタイトルになります ノート一覧で左にスワイプすると、タイトル変更 / 保護 / 削除ができます 6. ページ一覧で移動する 上部の ページ一覧 ボタンから、現在のノート内のページをサムネイルで確認できます。 ...

How to Use (ギャンカレ / Balance Calendar)

ギャンカレは、収入 / 支出 を短い操作で記録し、あとから 日別 / 月別 / カテゴリ別 で振り返るためのアプリです。 ギャンブル収支だけでなく、家計簿、推し活貯金、おこづかい帳などにも使えます。 1. 最初に用途に合うタグを選ぶ 初回起動時は、用途に合わせた初期タグを選べます。 ギャンブル 家計簿 推し活貯金 おこづかい帳 タグ名やアイコンはあとから 設定 > タグ で変更できます。 2. 登録 画面で収入 / 支出を記録する 中央の 登録 画面では、+ 収入 と − 支出 から金額を入力します。 金額はテンキーで入力します タグを選んで分類できます 日付を変えて過去日の記録もできます 未来日は選べません 画面上部では、その日の合計と前月比も確認できます。 3. 履歴 を見直して削除や取消しをする 履歴 から、その日の記録一覧を確認できます。 不要な記録は削除できます 削除直後は 取消し で元に戻せます 4. 収支 画面で振り返る 収支 画面では、次の3つの見方で振り返れます。 日別: 選択した月の日ごとの収支 月別: 選択した年の月ごとの収支 カテゴリ別: 選択した月のタグごとの合計 空日表示 を切り替えながら見返せます。 各行を開くと詳細も確認できます。 5. ホームウィジェットを使う ホームウィジェットを追加すると、ホーム画面からすぐ 収入 / 支出 を記録できます。 ...
