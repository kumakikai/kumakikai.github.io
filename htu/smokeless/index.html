すわなび/使い方

使い方 (すわなび)

すわなびは、喫煙 と 我慢 をすばやく記録し、あとから数字で振り返るためのアプリです。

禁煙補助として使うことも、今の喫煙状況を把握するための記録アプリとして使うこともできます。

1. 初回チュートリアルと本数設定を確認する

初回起動時はチュートリアルのあとに、以下を設定します。

  • 1箱の本数
  • 1箱の金額

この設定をしておくと、喫煙本数や我慢回数を金額換算で確認できます。

2. 記録 画面で喫煙 / 我慢を記録する

中央の 記録 画面では、緑の 我慢 と赤の 喫煙 を1タップで記録できます。

  • 我慢 は「吸いたいと思ったが吸わずに済んだ記録」です
  • 喫煙 は実際に吸った記録です
  • 銘柄を追加している場合は、記録する銘柄を切り替えられます
  • 画面上部では当日の件数、金額換算、前回記録からの経過時間を確認できます

3. 履歴 から当日の記録を見直す

右上の 履歴 から、その日の記録一覧を確認できます。

  • 不要な記録は削除できます
  • 削除直後は 取消し で元に戻せます

4. カレンダー で日別 / 月別 / 年別に振り返る

左下の カレンダー では、記録を次の単位で確認できます。

  • 日別
  • 月別
  • 年別

各期間の件数や金額換算を、数字中心で見返せます。

5. グラフ で最近の変化を見る

グラフ では、以下の期間で推移を確認できます。

  • 週
  • 月
  • 3か月

喫煙、我慢、喫煙平均を見ながら最近の変化を確認できます。

6. ホームウィジェットを使う

ホームウィジェットを追加すると、当日の 喫煙 / 我慢 件数をホーム画面から確認できます。

ウィジェットからそのまま記録することもできます。

7. 設定 を調整する

設定 では主に以下を変更できます。

  • テーマ
  • 言語
  • 節約額の通貨
  • 1箱の本数
  • 1箱の金額
  • 銘柄設定（最大4つまで）
  • 吸いすぎアラート
  • 広告削除の購入 / 購入復元
  • サポート

Apple Watchで記録する

Apple Watch対応版1.2.0は審査中です。以下は公開後に利用できる機能です。

Apple Watch機能は、広告削除または銘柄追加パックの購入特典です。購入・復元はiPhoneアプリで行います。

watchOS 9以降のApple Watchと、ペアリング済みの対応iPhoneが必要です。両方に対応版をインストールしてください。

  1. 使う前の準備

    対応版をiPhoneとApple Watchにインストールします。iPhoneのすわなびを起動して、広告削除または銘柄追加パックの購入権利を確認した後、Watchアプリを開きます。購入済みなのにロック画面が出る場合は、iPhoneの「設定」で購入を復元してください。

  2. 我慢・喫煙を1件記録

    左の緑ボタンをタップすると「我慢」、右の赤ボタンをタップすると「喫煙」を記録します。「我慢」は吸いたいと思ったが吸わなかった記録です。確認画面を挟まず、その場で件数が増えます。

  3. 今日の件数を見る

    左右のボタンに、それぞれ当日の件数を表示します。過去の履歴やグラフを見たいとき、記録を削除したいときは、iPhoneのすわなびを使ってください。

  4. iPhoneと同期する

    最初に購入権利を確認した後は、iPhoneが未接続でもWatchで記録できます。記録はWatchに一時保存され、再接続後にiPhoneへ同期します。反映されない場合は、接続を確認して両方のアプリを開いてください。記録日時はWatchでタップした時刻のままです。
