使い方 (すわなび)

更新日 2026.09.07

このページの内容
  • 1. 初回チュートリアルと本数設定を確認する
  • 2. 記録 画面で喫煙 / 我慢を記録する
  • 3. 履歴 から当日の記録を見直す
  • 4. カレンダー で日別 / 月別 / 年別に振り返る
  • 5. グラフ で最近の変化を見る
  • 6. ホームウィジェットを使う
  • 7. 設定 を調整する

緑のボタンで「我慢」、赤のボタンで「喫煙」を記録します。画面のアイコンと数字を見ながら、記録・振り返り・設定の操作を確認できます。

1. 初回チュートリアルと本数設定を確認する

初回チュートリアルのあとに「1箱の本数」と「1箱の金額」を入力します。金額換算にはこの設定を使います。あとから変更する場合は、設定の手順をご覧ください。

2. 記録 画面で喫煙 / 我慢を記録する

  1. 中央の「記録」を開きます。
  2. 吸いたいと思ったけれど吸わずに済んだときは、緑の斜線付きたばこアイコンをタップします。
  3. 実際に吸ったときは、赤のたばこアイコンをタップします。

1タップで1回記録し、ボタン内の当日回数が増えます。銘柄を複数設定している場合は、記録する前に銘柄を選びます。

3. 履歴 から当日の記録を見直す

  1. 「記録」右上のレシート型アイコンをタップします。
  2. 不要な記録を左へスワイプして削除します。
  3. 間違えた場合は、削除直後の「取消し」をタップします。

4. カレンダー で日別 / 月別 / 年別に振り返る

  1. 左下の「カレンダー」を開きます。
  2. 「日別」「月別」「年別」を切り替えます。
  3. 日付の行をタップすると、その日の記録を確認できます。

5. グラフ で最近の変化を見る

右下の「グラフ」を開き、上部で「週」「月」「3か月」を選びます。期間表示の左右の矢印で、表示期間を切り替えられます。

6. ホームウィジェットを使う

iPhoneのホーム画面に、すわなびのウィジェットを追加します。緑の「我慢」または赤の「喫煙」をタップすると、当日分を記録できます。

ウィジェットでは銘柄を切り替えません。使用する銘柄は「設定 → 全般 → 銘柄」で「ウィジェットの既定銘柄にする」を設定します。

7. 設定 を調整する

  1. 「記録」左上の歯車をタップします。
  2. 「全般」を開き、変更したい項目を選びます。

本数や価格は「銘柄」で変更します。通常は1銘柄、銘柄追加パックの購入後は合計4銘柄まで設定できます。購入済み機能の復元は「設定 → アプリ内購入」から行います。

Apple Watchで記録する

Apple Watch対応版1.2.0は審査中です。以下は公開後に利用できる機能です。

Apple Watch機能は、広告削除または銘柄追加パックの購入特典です。購入・復元はiPhoneアプリで行います。

watchOS 9以降のApple Watchと、ペアリング済みの対応iPhoneが必要です。両方に対応版をインストールしてください。

  1. 使う前の準備

    対応版をiPhoneとApple Watchにインストールします。iPhoneのすわなびを起動して、広告削除または銘柄追加パックの購入権利を確認した後、Watchアプリを開きます。購入済みなのにロック画面が出る場合は、iPhoneの「設定」で購入を復元してください。

  2. 我慢・喫煙を1件記録

    左の緑ボタンをタップすると「我慢」、右の赤ボタンをタップすると「喫煙」を記録します。「我慢」は吸いたいと思ったが吸わなかった記録です。確認画面を挟まず、その場で件数が増えます。

  3. 今日の件数を見る

    左右のボタンに、それぞれ当日の件数を表示します。過去の履歴やグラフを見たいとき、記録を削除したいときは、iPhoneのすわなびを使ってください。

  4. iPhoneと同期する

    最初に購入権利を確認した後は、iPhoneが未接続でもWatchで記録できます。記録はWatchに一時保存され、再接続後にiPhoneへ同期します。反映されない場合は、接続を確認して両方のアプリを開いてください。記録日時はWatchでタップした時刻のままです。
