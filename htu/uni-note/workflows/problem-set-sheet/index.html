表計算アプリで単語帳を作って問題集にする

更新日 2026-10-06

このページの内容
  • 必要な条件
  • 一覧を作る
  • 取り込んで学習する
  • 完了の確認
  • 注意事項

Excel・Numbers・Googleスプレッドシートで作った単語や用語の一覧を、まとめて問題集に取り込んで学習します。授業ごとの用語集や資格試験の暗記に使えます。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 公開中の3.8.3ではまだ利用できません。

必要な条件

PremiumまたはPremium Plus。表計算アプリ、またはテキストを編集できるアプリ。

一覧を作る

  1. 表計算アプリで、1列目に問題（例：用語）、2列目に解答（例：意味）を書きます。補足したい場合は3列目に解説を書きます。
  2. 1行に1問ずつ並べます。1行目を「問題」「解答」のような見出しにしても、自動で除外されます。
  3. 一度に取り込めるのは最大300問です。それより多い場合はファイルを分けます。

取り込んで学習する

  1. 表計算アプリでセルを選んでコピーします。CSVで書き出してもかまいません。
  2. Uni:Noteのホームで「問題集」に切り替え、「＋」から「貼り付けて作成」（CSVファイルの場合は「ファイルから作成」）を選びます。
  3. 「一括作成」画面で内容とタイトルを確認し、教科を選んで「問題集を作成」をタップします。
  4. 作成した問題集を開き、Apple Pencilで解答を書いてから指でタップして答え合わせします。
  5. 右スワイプで「覚えた」、左スワイプで「覚えていない」を記録します。
  6. 1周終わったら「覚えていない ○問をもう一周」で、覚えていない問題だけを繰り返します。

形式に迷ったら、問題集表示の「?」で表の書き方を確認できます。「サンプルをコピー」で取り込める例を試すこともできます。

完了の確認

表計算アプリの一覧が問題集になり、覚えていない問題を減らしながら学習できます。

注意事項

文字コードはUTF-8だけに対応しています。問題か解答が空の行は取り込まれません。
