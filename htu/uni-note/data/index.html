保護・データ管理

更新日 2026-10-06

このページの内容
  • ノートを書き込みから保護する
  • ゴミ箱から教科・ノートを復元する

書き込みの保護と、削除した教科・ノートの復元を扱います。

ノートを書き込みから保護する

ノートを保護すると、誤って書き込むことを防げます。資料として見返すノートに使えます。

必要な条件

保護解除時の認証を使う場合は、iPad側のFace ID／Touch ID、またはパスコードの設定。

書き込みから保護する

  1. ノート一覧を開きます。
  2. 対象のノートを長押しします。
  3. メニューから「保護」を選びます。
  4. ノートにロックのアイコンが付いたことを確認します。

保護中のノートを開くと「保護中・閲覧専用」と表示されます。書き込もうとすると「このノートは保護されているため編集できません」と表示されます。

編集できる状態へ戻す

  1. 対象のノートを長押しします。
  2. 「解除」を選びます。
  3. 認証を求められた場合は、Face ID／Touch IDまたはパスコードで認証します。
  4. ノートを開いて編集します。

認証の有無は「設定 → 表示設定 → ノートの保護解除時に生体認証を要求」で選びます。

完了の確認

資料を読むときは保護し、編集するときは解除して使えます。

注意事項

この保護は編集防止です。ノートの閲覧をロックする機能ではありません。保護中のノートは削除できず、保護中のノートを含む教科も削除できません。

ゴミ箱から教科・ノートを復元する

削除した教科とノートをゴミ箱から戻せます。ページや問題集の削除とは、復元できる範囲が異なります。

削除したノートを探す

  1. ホーム左上のゴミ箱をタップします。
  2. 教科名の行をタップして展開します。
  3. ノート名と削除日を確認します。

何もない場合は「ゴミ箱は空です。」と表示されます。問題集の一覧を表示している間は、ゴミ箱のボタンは表示されません。

ノート・教科を復元する

  1. 戻したいノート、または教科の行で「復元」をタップします。
  2. ホームやノート一覧へ戻り、内容を確認します。

完全に削除する

  1. ゴミ箱で不要な対象を確認します。
  2. その行の「削除」をタップします。
  3. 「このノートを完全に削除しますか？」（教科の場合は「この教科を完全に削除しますか？」）と表示されたら、元に戻せないことを確認して「完全に削除」をタップします。残す場合はキャンセルします。

教科・ノートは30日経過後の整理で完全に削除されます。必要なものは期限を待たずに復元してください。

削除したものゴミ箱からの復元
教科・ノート保管されている間は復元可能
ノート内のページ復元不可
問題集復元不可
ゴミ箱で完全削除したもの復元不可

完了の確認

必要なノートや教科がホームへ戻り、開いて内容を確認できます。
