カスタマイズ

更新日 2026-09-19

このページの内容
  • 設定を開いて目的の項目を探す
  • 紙・左右の配置・ページ情報を設定する
  • 起動・表示・言語を設定する
  • ボタンとパレットの配置を変える

紙・左右の配置・表示・道具を、自分の使い方に合わせます。

設定を開いて目的の項目を探す

ホームの歯車から設定を開きます。紙の初期値、画面の配置、学習支援、バックアップなどを目的別に探せます。

設定を開く

  1. ノートからホームへ戻ります。
  2. 歯車をタップします。
  3. 変更したい内容に合うカテゴリを選びます。
  4. 設定を終えたら戻る操作で設定トップへ戻ります。
目的開くところ
新しいノートの紙・左右の配置ノート設定
起動時の画面・ボタンとパレットの配置表示設定
録音の言語・要約形式・ポモドーロ学習支援
保存・復元バックアップ
使い方・問い合わせサポート

設定トップでは現在のプランやAI残量、お知らせも確認できます。

完了の確認

変えたい項目へ進み、変更後にノートやホームで結果を確認できます。

紙・左右の配置・ページ情報を設定する

新しいノートの紙と、左右の配置の初期値を選びます。教科名やページ番号を紙の四隅へ表示することもできます。

新規ノートの紙を決める

  1. 「設定 → ノート設定」を開きます。
  2. 新規ノートのテンプレートで横罫・縦罫・方眼・無地を選びます。
  3. ベース色を選びます。
  4. プレビューを確認します。
  5. 新しい教科の作成画面で、初期値を確認します。

縦罫を選ぶと「縦ノート（見開き表示）として使う」の既定値も選べます。新しく作るときの選択をそろえる設定です。

左利きモード・左右の個別設定

  1. ノート設定で左利きモードを切り替えます。
  2. パレット、横罫の赤縦線、PDF貼付位置のプレビューを確認します。

個別に変える場合は「項目ごとの設定」を開き、パレットの位置、横罫線ノートの赤縦線の位置、PDF貼付位置をそれぞれ左／右から選びます。PDF貼付位置は新しく資料を入れるときの配置に使われます。

四隅に教科名・ページ番号などを置く

  1. ノート設定のヘッダー／フッターを開きます。
  2. 左上・右上・左下・右下から位置を選びます。
  3. なし・教科名・ノート名・ページ作成日・ページ番号から表示する情報を選びます。
  4. プレビューを確認します。
  5. ノートに戻って表示を確認します。

完了の確認

新規作成時の紙と、ノート上の情報・左右配置を用途に合わせられます。

起動・表示・言語を設定する

起動時の画面、教科の並びや呼び方、スリープ、アプリの言語を選べます。

起動とホームの表示

  1. 「設定 → 表示設定」を開きます。
  2. 「起動時に開く画面」でホームか前回のノートを選びます。
  3. 最近使った教科を先頭にする場合は「教科を最近開いた順で並べ替える」をオンにします。
  4. 「教科の表記」で教科・ノート・グループ・カテゴリから呼び方を選びます。

このガイドは標準の「教科」という呼び方で説明しています。表記を変えても整理の階層は同じです。

筆記中の表示

「ノートを開いている間はスリープしない」をオンにすると、ノート表示中の自動スリープを防げます。

パレットを自動でたたむ場合は「設定 → ノート設定 → パレットを自動収納」をオンにします。書き始めると収納され、収納中のパレットをタップして開けます。

保護解除時の認証

表示設定の「ノートの保護解除時に生体認証を要求」で切り替えます。これは書き込み保護を解除するときの認証です。ノートの保護も確認してください。

表示言語を変える

  1. 「設定 → 表示設定 → 言語」を開きます。
  2. 日本語・English・한국어・Deutsch・繁體中文・Françaisから選びます。
  3. 再起動の案内に従ってアプリを閉じ、開き直します。

完了の確認

起動先やホームの表示、ノートを開いている間の動作が選んだ設定になります。

ボタンとパレットの配置を変える

ノート画面のボタンと、パレットに並ぶ道具をカスタマイズできます。よく使う操作を手元へ置き、ほかの操作を「その他」へまとめます。

ナビゲーションバーを変える

  1. 「設定 → 表示設定 → ノート画面 → ナビゲーションバー」を開きます。
  2. 移動したいボタンを押さえてドラッグします。
  3. ナビゲーションバー内で順番を整えます。
  4. 「その他」へまとめるボタンは「…」メニューの領域へ移します。
  5. メニュー内でも順番を整えます。

非表示にする場合は、対象ボタンの操作メニューか、利用できるボタンの領域への移動を使います。再表示するときは利用できるボタンから戻します。

ドラッグせずに移動する

対象のボタンをタップすると、移動のメニューを使えます。前へ・後ろへ・「…」メニューへ移動する操作などから選び、配置を確認します。

パレットの道具を変える

  1. 「設定 → 表示設定 → ノート画面 → パレット」を開きます。
  2. 道具を押さえてドラッグし、順番を変えます。
  3. 使わない道具を非表示にします。
  4. 再表示したい道具を利用できるツールから戻します。
  5. ノートを開いてパレットを確認します。

初期配置へ戻す

各カスタマイズ画面の「初期状態に戻す」を選び、確認して実行します。ノートへ戻り、ナビゲーションバー・その他・パレットの配置を確認してください。

完了の確認

よく使うボタンと道具が、選んだ位置に表示されます。

注意事項

「付箋マーカー」はパレット、「囲って解答アシスタント」はナビゲーションバー側の配置で管理します。見つからないときは非表示になっていないか確認してください。
