写真・PDF

更新日 2026-09-26

このページの内容
  • 写真・紙の資料を貼り付ける
  • PDFのページを選んで貼り付ける
  • 写真・PDFを選択して配置する
  • 縦ノートで資料の大きさを整える
  • ノートをPDFにして保存・共有する

写真やPDFを貼り付け、配置・固定・書き込み・共有まで行います。

素材の選択方法：「指で描画」がOFFのときは、固定されていない写真・PDFなどを指で1回タップします。固定中の素材はダブルタップで固定を解除します。ONのときはノート画面の「編集」を押して「素材選択中」にし、素材を1回タップします。ONのまま移動・サイズ変更でき、空白をタップするか「編集」を再度押すと通常の指での筆記へ戻ります。

写真・紙の資料を貼り付ける

普通の写真はそのまま貼り付けられます。紙資料は書類として取り込み、四隅を合わせて読みやすく補正できます。

必要な条件

写真へのアクセス。カメラで撮る場合はカメラ権限。

写真をそのまま貼る

  1. 貼り付け先のノートページを開きます。
  2. 「その他 → 写真貼付」を選びます。
  3. 写真を1枚選びます。
  4. 貼り付け後の位置と大きさを確認します。

紙資料を撮って貼る

  1. 「その他 → 写真を書類として貼付」を選びます。
  2. カメラから取り込む方法を選びます。
  3. 紙全体が入るように撮影します。
  4. 補正画面で四隅を紙の角に合わせます。
  5. 補正を適用します。

保存済み写真を紙資料として使う

同じ「写真を書類として貼付」で写真から取り込む方法を選び、写真を指定します。四隅を合わせて補正を適用してください。

書類として貼った写真の位置や大きさを変える場合は、上の「素材の選択方法」で選択してから調整します。「指で描画」がONでもOFFへ切り替える必要はありません。

完了の確認

ノート上に写真、または四隅を補正した書類写真が表示されます。

PDFのページを選んで貼り付ける

PDFから必要なページだけを選んでノートに貼り付けます。複数ページや見開きの資料も扱えます。

必要な条件

iPadのファイル選択画面から開けるPDF。

1ページを選んで貼る

  1. 貼り付けを始めたいノートページを開きます。
  2. 「その他 → PDF貼付」を選びます。
  3. ファイル選択画面でPDFを開きます。
  4. 使いたいページのサムネイルを選びます。
  5. 「貼り付け」をタップします。

複数ページ・全ページを選ぶ

ページ選択画面で必要なサムネイルを選びます。全ページを使う場合は「すべて選択」を使います。選択済みの不要なページは選択を解除してください。

貼り付ける順番は、タップした順ではなくPDFのページ番号順です。現在のノート位置から後ろのページへ配置されます。

見開きを左右に分割する

  1. PDFのページを選びます。
  2. 「見開きを分割」を有効にします。
  3. 「貼り付け」をタップします。
  4. 左半分、右半分の順にノートへ入ったことを確認します。

PDFの1ページが、ノートの2ページ分になります。完成例と学習手順も参照してください。

完了の確認

選んだPDFがノートに固定された状態で配置されます。Apple Pencilで上から書き込めます。

注意事項

位置や大きさを変えるときは、上の「素材の選択方法」でPDFを選択します。元のPDFファイルそのものを編集する操作ではありません。

写真・PDFを選択して配置する

写真やPDFを選択し、書き込みやすい位置と大きさに整えます。手書きの範囲移動とは操作対象が異なります。

必要な条件

写真またはPDFを貼り付けたノート。注釈にはApple Pencil。

素材を選ぶ

  1. 「指で描画」がOFFの場合は、固定中の資料をダブルタップして固定を解除し、1回タップして選択します。
  2. 「指で描画」がONの場合は、「編集」を押して「素材選択中」にし、資料を1回タップします。
  3. 選択枠と操作ボタンが表示された対象を確認します。

「指で描画」がONでも、素材操作のためにOFFへ切り替える必要はありません。

移動・サイズ変更・回転

  1. 選択した資料を指でドラッグして移動します。
  2. 「指で描画」がOFFの場合は、選択した資料の上を2本指でピンチして大きさを変えます。ONの場合は、選択枠のサイズ変更ハンドルを指でドラッグします。
  3. 書類写真・PDFの向きを変える場合は、選択枠右上の回転ハンドルを1本指でつかみ、素材の中心の周りを円を描くように動かします。

資料の選択枠を確かめてから操作してください。ノート全体は2本指のピンチでズームします。選択した素材自体の拡大縮小は、OFFでは素材上のピンチ、ONではサイズ変更ハンドルを使います。

配置して書く

  1. 位置と大きさを整えます。
  2. ペンを選びます。
  3. Apple Pencilで資料の上や余白へ書き込みます。

同じページへ別のPDFを追加すると重なる場合があります。それぞれを選択し、位置を整えてください。

資料を削除する

「指で描画」がOFFなら対象を長押しし、表示されるメニューから削除を選びます。ONなら「編集」で素材選択モードに入り、対象を選んで操作メニューから削除します。必要な資料か確認してから実行してください。

完了の確認

資料が意図した位置と大きさに配置され、手書きの注釈を追加できます。

注意事項

写真・PDFの削除は手書きの取り消し操作では戻せません。

縦ノートで資料の大きさを整える

縦ノートでは、PDFや書類写真を大きく配置して読めます。普通の写真は貼り付け後に手動で大きさを整えます。

必要な条件

作成時に縦ノートを選んだノート。

PDF・書類写真を大きく使う

  1. 縦ノートの貼り付け先を開きます。
  2. PDF貼付、または写真を書類として貼付を実行します。
  3. ページ内に大きく配置された資料を確認します。
  4. 調整が必要なら、「指で描画」の設定に合う方法で資料を選択し、位置と大きさを整えます。

資料の縦横比は保たれるため、形によって余白が残ります。

普通の写真を大きくする

  1. 「写真貼付」で写真を選びます。
  2. 「指で描画」がOFFなら写真を1回タップします。ONなら「編集」を押して写真を1回タップします。
  3. OFFの場合は写真上の2本指ピンチ、ONの場合はサイズ変更ハンドルで、読みたい大きさにします。
  4. ドラッグして位置を整えます。

完了の確認

ノート全体のズームに頼らず、資料自体を大きく配置できます。

注意事項

PDF・書類写真の初期配置と、普通の写真の初期配置は同じではありません。

ノートをPDFにして保存・共有する

ノート単体または教科全体をPDFにして、ファイル保存や共有に使えます。印刷用には白背景も選べます。

必要な条件

保存・共有先のアプリ。印刷はiPadOS側の対応環境が必要です。

背景を決める

  1. ホームの設定を開きます。
  2. 「表示設定 → PDF出力時の背景色」を開きます。
  3. ノートの紙色を使う「紙」、または「白」を選びます。

PDFを書き出す

  1. 対象のノートを開きます。
  2. 「その他 → PDF出力」を選びます。
  3. このノート、または教科全体を選びます。
  4. 出力が終わるまで待ちます。
  5. iPadOSの共有シートから保存先や共有先を選びます。

ファイルとして保管する場合は、共有シートのファイル保存操作からフォルダを指定します。印刷する場合は、表示される印刷操作とプリンタの案内に従ってください。

完了の確認

保存先でPDFを開き、ページ範囲・背景・手書きを確認できます。

注意事項

PDF出力は閲覧・共有用です。Uni:Noteへ戻すためのバックアップとは異なります。
