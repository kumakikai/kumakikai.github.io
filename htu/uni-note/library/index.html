教科・フォルダ

更新日 2026-10-06

このページの内容
  • 教科を編集・並べ替え・削除する
  • 教科をフォルダで整理する
  • 2ペイン表示で整理する
  • ノートをタイトルで探す

教科を名前やフォルダで整理し、必要なノートを探します。ホームを2ペイン表示にして、教科とノートを左右に並べることもできます。

教科を編集・並べ替え・削除する

教科名や紙の設定を整え、ホームの教科カードを使いやすい順番に並べます。削除した教科はゴミ箱で管理します。

名前・紙・表紙を編集する

  1. ホームで対象の教科カードを長押しします。
  2. 「編集」を選びます。
  3. 名前、「罫線」、「紙色」、「表紙カラー」の必要な項目を変更します。
  4. 変更を保存します。

教科の編集では、縦ノート（見開き表示）への切り替えは表示されません。縦ノートは教科を作るときに選びます。

カードを並べ替える

  1. 教科カードの並べ替え用ハンドルを押さえます。
  2. 移動先までドラッグします。
  3. 指を離して順番を確認します。

「教科を最近開いた順で並べ替える」がONだと、ノートを開くことで順番が変わります。手動の順序を使いたい場合はOFFにします（起動・表示を設定する）。

教科を削除する

  1. 対象の教科カードを長押しします。
  2. 「削除」を選びます。
  3. 「「（教科名）」を削除しますか？」と表示されたら、「削除」をタップします。教科と中のノートはゴミ箱へ移動します。

保護中のノートを含む教科は削除できません。「保護されたノートがあるため削除できません。」と表示された場合は、先にノートの保護を解除してください。削除した教科はホームのゴミ箱から復元できます。必要なデータは30日を待たずに戻してください。

完了の確認

ホームの教科名・表紙・並び順が変わります。削除した教科はホームからゴミ箱へ移ります。

教科をフォルダで整理する

学期や授業の種類ごとに教科をまとめます。フォルダを削除しても、中の教科はホームに戻ります。

フォルダを作る

  1. ホームの「＋」をタップします。
  2. 「フォルダを作成」を選びます。
  3. 名前と色を指定します。
  4. 入れたい教科を選びます。空のフォルダでも作成できます。
  5. 作成を確定します。

教科を入れる・並べる

  1. ホームの教科カードの並べ替え用ハンドルを押さえ、フォルダへドラッグします。
  2. フォルダをタップして開きます。
  3. 教科の並べ替え用ハンドルをドラッグして順番を整えます。
  4. 教科を開くか、教科の「ノート一覧」からノートを選びます。

フォルダを閉じるには「×」か外側をタップします。

内容を編集する・教科を外へ出す

フォルダを長押しして「編集」を選ぶと、名前・色・含める教科を変更できます。

教科を外へ出すには、フォルダ内で教科を長押しし、「フォルダから出す」を選びます。教科をドラッグして「本棚へ戻す」の位置で離す方法も使えます。

フォルダだけを削除する

  1. フォルダを長押しします。
  2. 「フォルダを削除」を選びます。
  3. 「フォルダを削除しますか？」の確認で内容を確かめ、削除を確定します。

「教科は削除されず、本棚へ戻ります。」と案内されるとおり、中の教科とノートは削除されません。ホームに戻った教科を確認してください。

完了の確認

ホーム直下とフォルダ内で、教科を目的に合わせて整理できます。

2ペイン表示で整理する

ホームを左右2つに分け、左で教科やフォルダを選び、右でノートを選びます。教科をたくさん使う場合や、ノートを次々に切り替えたい場合に便利です。

表示を切り替える

  1. ホーム左上の、ゴミ箱の右にある切り替えボタン（「2ペイン表示に切り替える」）をタップします。
  2. 左に「最近使ったノート」「フォルダ」と教科、右にノートが表示されます。
  3. 従来表示に戻すときは、同じ位置のボタン（「従来表示に切り替える」）をタップします。

ホームでの切り替えはその場だけの表示です。アプリを起動したときに2ペイン表示で始めたい場合は、「設定 → 表示設定」の「2ペイン表示をデフォルトにする」をONにします。

ノートを選ぶ・作る

  1. 左側で教科をタップします。フォルダの行をタップすると、中の教科を展開・折りたたみできます。
  2. 右側にその教科のノートが表示されます。タップすると開きます。
  3. ノートを追加するときは、右上の「新規ノート」をタップします。
  4. 右上の切り替えボタンで、ノートを「カード表示」と「一覧表示」から選べます。

左側の「最近使ったノート」を選ぶと、最近更新したノートが新しい順に表示されます。ノートの長押しメニュー（「編集」「保護」「削除」）は従来表示と同じです。

教科・フォルダを整理する

  1. 左上の「編集」をタップします。
  2. 各行の左にある並べ替え用ハンドルをドラッグして、順番を変えたり、教科をフォルダへ出し入れしたりします。
  3. 教科やフォルダを作るときは、「フォルダ」の見出しや教科の見出しの右にある「＋」をタップします。
  4. 行を長押しすると、教科では「編集」「削除」「フォルダへ移動」（フォルダ内の教科は「フォルダから出す」）、フォルダでは「編集」「フォルダを削除」を選べます。
  5. 終わったら「完了」をタップします。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 公開中の3.8.3ではまだ利用できません。

「編集」中は、右側のノートの行・カードに保護（鍵）・編集（鉛筆）・削除（ゴミ箱）のボタンが直接表示されます。長押しせずにノートを管理できます。

狭いウインドウで使う

Split Viewなどでウインドウの幅が狭いときは、左側の一覧が「ナビゲーション」ボタンで開閉する形に変わります。ボタンをタップして教科を選ぶと、右側にノートが表示されます。

完了の確認

左側で教科を選び、右側からノートを開いたり作ったりできます。

ノートをタイトルで探す

タイトルの一部からノートを探せます。授業名や回数などをノート名に入れておくと見つけやすくなります。

タイトルで探す

  1. ホーム右上の「ノートタイトルを検索」をタップします。
  2. ノート名の一部を入力します。
  3. 「検索結果」で目的のノートをタップします。

2ペイン表示で検索すると、検索している間は結果が一覧で表示されます。該当するノートがない場合は「該当するノートはありません」と表示されます。

通常のホームへ戻す

検索欄の入力を消すと、通常のホーム表示に戻ります。

完了の確認

検索結果から目的のノートを開けます。

注意事項

検索対象はノートのタイトルです。手書き本文・PDFの内容・教科名は検索しません。英字の大文字・小文字や全角・半角は区別されません。
