教科・フォルダ

更新日 2026-09-19

このページの内容
  • 教科を編集・並べ替え・削除する
  • 教科をフォルダで整理する
  • ノートをタイトルで探す

教科を名前やフォルダで整理し、必要なノートを探します。

教科を編集・並べ替え・削除する

教科名や紙の設定を整え、ホームの教科カードを使いやすい順番に並べます。削除した教科はゴミ箱で管理します。

名前・紙・表紙を編集する

  1. ホームで対象の教科カードを長押しします。
  2. 編集を選びます。
  3. 名前、罫線、紙色、表紙カラーの必要な項目を変更します。
  4. 変更を保存します。

カードを並べ替える

  1. 教科カードの並べ替え用ハンドルを押さえます。
  2. 移動先までドラッグします。
  3. 指を離して順番を確認します。

「教科を最近開いた順で並べ替える」が有効だと、ノートを開くことで順番が変わります。手動の順序を使いたい場合は表示設定を確認します。

教科を削除する

  1. 対象の教科カードを長押しします。
  2. 削除を選びます。
  3. 教科と中のノートを確認し、削除を確定します。

削除した教科はホームのゴミ箱から復元できます。必要なデータは30日を待たずに戻してください。

完了の確認

ホームの教科名・表紙・並び順が変わります。削除した教科はホームからゴミ箱へ移ります。

関連する使い方

  • 教科をフォルダで整理する
  • ゴミ箱から教科・ノートを復元する
  • 紙・左右の配置・ページ情報を設定する

教科をフォルダで整理する

学期や授業の種類ごとに教科をまとめます。フォルダを削除しても、中の教科はホームに戻ります。

フォルダを作る

  1. ホームの「＋」をタップします。
  2. 「フォルダを作成」を選びます。
  3. 名前と色を指定します。
  4. 入れたい教科を選びます。空のフォルダでも作成できます。
  5. 作成を確定します。

教科を入れる・並べる

  1. ホームの教科カードをフォルダへドラッグします。
  2. フォルダを開きます。
  3. 教科の並べ替え用ハンドルをドラッグして順番を整えます。
  4. 教科を開くか、教科内の「ノート一覧」からノートを選びます。

フォルダを閉じるには「×」か外側をタップします。

内容を編集する・教科を外へ出す

フォルダの長押しメニューから編集を選び、名前・色・含める教科を変更できます。

教科を外へ出すには、フォルダ内で教科を長押しし、フォルダから出す操作を選びます。教科をフォルダの外へドラッグしてホームへ戻す方法も使えます。

フォルダだけを削除する

  1. フォルダを長押しします。
  2. 削除を選びます。
  3. 確認画面を読んで確定します。

中の教科とノートは削除されません。ホームに戻った教科を確認してください。

完了の確認

ホーム直下とフォルダ内で、教科を目的に合わせて整理できます。

関連する使い方

  • 教科を編集・並べ替え・削除する
  • ノートを開く・増やす・整理する

ノートをタイトルで探す

タイトルの一部からノートを探せます。授業名や回数などをノート名に入れておくと見つけやすくなります。

タイトルで探す

  1. ホームの「ノートタイトルを検索」をタップします。
  2. ノート名の一部を入力します。
  3. 検索結果で目的のノートをタップします。

通常のホームへ戻す

検索欄の入力を消すと、通常のホーム表示に戻ります。

完了の確認

検索結果から目的のノートを開けます。

注意事項

検索対象はノートのタイトルです。手書き本文・PDFの内容・教科名は検索しません。
