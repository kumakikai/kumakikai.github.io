How to Use (Uni:Note)

Uni:Note（大学ノート）は、紙の大学ノートをそのまま iPad に持ち込む ための手書きノートアプリです。

対応環境:

  • iPad専用
  • Apple Pencilでの手書きが基本
  • 指は主に画面操作用

1. 最初の教科を作る#

ホーム画面で ＋ をタップし、以下を設定します。

  • 教科名
  • 罫線（横罫 / 方眼 / 無地）
  • 教科カラー

作成後は、そのまま教科のノート一覧へ進めます。

2. ノートを書き始める#

  • ノート画面では Apple Pencil でそのまま書けます。
  • 最初のノートだけ、必要ならタイトルを付けられます。
  • タイトルを入力しない場合は、その日付がタイトルになります。

本文をキーボードで整えるより、すぐ書き始めることを優先した設計です。

3. ツールを切り替える#

画面上のフローティングツールバーから、以下を切り替えます。

  • ペン
  • 蛍光ペン
  • 消しゴム
  • 戻る
  • 進む

ツールバーはドラッグで移動できます。
設定から左利きモードを有効にすると、初期位置を反転できます。

4. ページを増やす・移動する#

  • 画面下の左右ボタンで前後のページへ移動できます。
  • 何か書いたページでは、次のページへ進むと新しいページが自動で作られます。
  • 上部の ページ一覧 ボタンから、サムネイルでページを見渡せます。

5. ノート（講義）ごとに分ける#

上部の この教科のノート ボタンから、同じ教科内のノート一覧を開けます。

  • ＋ ノート追加 で、同じ日でも新しいノートを追加できます。
  • 日付が変わったあとに書き始めると、その日のノートが自動で作られます。
  • ノート一覧で対象を左にスワイプすると、タイトル変更 / 保護 / 削除ができます。

6. 写真を貼る#

右上の … メニューから 写真貼付 を選ぶと、画像をページに追加できます。 操作は指で行います。

  • 写真ライブラリから1枚選択
  • 配置後は移動 / 拡大縮小が可能
  • 必要に応じて90度回転
  • 固定して誤操作を防止

7. PDFを書き出す#

右上の … メニューから PDF出力 を選びます。

出力範囲:

  • このノートのみ
  • この教科

書き出したPDFは、そのまま共有または保存できます。

8. 保護・削除・ゴミ箱#

  • ノート一覧で 保護 すると、そのノートは閲覧専用になります。
  • 保護を解除するときは、設定に応じて端末認証を要求できます。
  • 削除した教科やノートは、ホーム画面の ゴミ箱 から復元できます。
  • ゴミ箱で完全に削除した項目は元に戻せません。

9. 設定とバックアップ#

ホーム画面の 設定 では、主に以下を変更できます。

  • 新規ノートテンプレート
  • 起動時に開く画面
  • 保護解除時の認証要求
  • 左利きモード
  • 言語

バックアップでは、アプリデータの 作成 と 復元 ができます。
復元後は、案内に従ってアプリを閉じて再度開いてください。
