問題集

更新日 2026-10-06

このページの内容
  • 問題集ホームを開く
  • ノートからAI問題集を作る
  • 1問ずつ作る
  • 表計算アプリのデータからまとめて作る
  • 覚えた・覚えていないで学習する
  • 問題集を編集・管理する
  • ホームの問題集表示を変える

ノートからのAI生成、1問ずつ・まとめての作成、覚えた・覚えていないでの学習まで扱います。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 問題集はこのバージョンで大きく変わります。 公開中の3.8.3ではまだ利用できません。

4.0.0では、問題集を手書きやキーボードで1問ずつ作ったり、表計算アプリのデータからまとめて作ったりできるようになります。学習は「覚えた」「覚えていない」を記録する形式になり、出典のノートを横に表示しながら復習できます。

問題集ホームを開く

問題集はホームの問題集表示にまとまっています。ここから作成・学習・管理を始めます。

問題集表示に切り替える

  1. ホーム左上の「問題集」ボタンをタップします。
  2. 見出しが「あなたの問題集」に変わり、保存した問題集がカードで表示されます。
  3. 教科とノートの表示に戻るときは、同じ位置のボタンをもう一度タップします。

問題集がまだない場合は「問題集はまだありません。」と表示されます。ボタンが見つからない場合はホームの問題集表示を確認してください。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 公開中の3.8.3ではまだ利用できません。

問題集は教科ごとに分かれて表示されます。教科に属さない問題集は最後の「未分類」にまとまります。カードには問題数と学習状況（例「12問 · 覚えていない 3」「12問 · すべて覚えた」）、ノートから作った問題集では出典（例「経済学 › 第8回 › p.2–6」）が表示されます。

右上には「シャッフル」と「?」（使い方）のボタンがあります。「?」をタップすると、まずこの画面のボタンの説明が表示されます。中央の「詳しい使い方ガイドを見る」をタップすると、作り方・まとめて作るときの形式・学習の方法を4ページで確認できるガイドが開きます。

完了の確認

問題集の一覧を表示し、作成や学習を始められます。

ノートからAI問題集を作る

ノートの必要なページからAIで問題を作り、採用する候補だけを問題集として保存します。

必要な条件

通信環境とAI残量。問題の元になるノート。

対象を決めて生成する

  1. 元にするノートを開きます。
  2. 「その他」から「問題集を作る」を選びます。
  3. 「対象ページ」の行（例「1ページ選択中（p1）」）をタップし、対象ページを最大20ページまで選びます。ページが多いと精度が下がることがあります。
  4. 「目安: 約○問」と「予想消費量」を確認します。
  5. 「問題集を作成」をタップします。

生成中は「ノートを読み取っています」「問題候補を作成しています」などの段階が表示されます。完了するまでアプリを開いたまま待ちます。

候補を採用・破棄する

  1. 「問題レビュー」で候補の問題と解答を読みます。
  2. 残す候補は「追加」、不要な候補は「破棄」を選びます。右スワイプで追加、左スワイプで破棄することもできます。
  3. 次の候補も同じように確認します。すべて確認すると保存の画面へ進み、採用した数が「採用数」に表示されます。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 公開中の3.8.3ではまだ利用できません。

問題レビューは学習画面と同じカードの形で表示されます。上部の進捗バーと「3 / 10」のような表示で、何問目かを確認できます。カードには問題文と解答が最初から表示され、解説がある場合はその下に、元にしたノートのページ番号と抜き出した文が一番下に表示されます。下の「破棄」「追加」のボタンの下には「左にスワイプ: 破棄 ／ 右にスワイプ: 追加」が常に表示されます。判定するとカードに「追加」「破棄」のスタンプが付き、次の候補へ進みます。

問題集として保存する

  1. 採用する候補を確認します。
  2. 「問題集名」を入力します。
  3. 「問題集として保存」をタップします。
  4. 「保存しました」と表示されたら、「閉じる」または「今すぐ復習」を選びます。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 公開中の3.8.3ではまだ利用できません。

ノートから作った問題集は元のノートの教科に分類され、問題ごとにノートのページが記録されます。学習中に出典のページを横に開いて見直せます。

完了の確認

採用した問題だけをまとめた問題集を、ホームの問題集表示から開けます。

注意事項

生成だけでは候補の選別は終わりません。解答の正しさを確認し、保存後も必要に応じて編集してください。

1問ずつ作る

自分で問題と解答を入力して問題集を作ります。AI残量は使いません。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 公開中の3.8.3ではまだ利用できません。

手書きやキーボードで作る

  1. 問題集表示の右下の「＋」をタップし、「1問ずつ作成」を選びます。
  2. 「問題を追加」画面の上部で、問題集のタイトル（初期は「新しい問題集」）を入力します。
  3. 教科のボタン（初期は「未分類」）で教科を選びます。続けて参照するノートを選ぶか、「ノートを指定しない」を選びます。
  4. 入力方法を「手書き」または「キーボード」から選びます。
  5. 「問題文」と「解答」を入力します。
  6. 「保存して次へ」をタップします。1問が保存され、次の問題を入力できる状態になります。
  7. 作り終えたら左上の「閉じる」をタップします。

手書きでは「ペン」「消しゴム」「取り消す」「やり直す」を使えます。最後にApple Pencilで触れた欄（濃い色の枠）に対して働きます。キーボードでは、Tabキーで解答欄へ移動し、Command＋Returnで「保存して次へ」を実行できます。

入力途中で閉じると「変更を破棄しますか？」と確認され、「変更を破棄」で閉じます。それまでに保存した問題は残ります。

公開中の3.8.3では： 問題集表示の「＋」をタップすると編集画面が開きます。タイトル、問題文、解答、必要なら解説を入力し、「保存」をタップします。

完了の確認

作った問題集が問題集表示に追加されます。

表計算アプリのデータからまとめて作る

Excel・Numbers・Googleスプレッドシートなどで作った問題の一覧を、まとめて問題集にします。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 公開中の3.8.3ではまだ利用できません。

必要な条件

PremiumまたはPremium Plus。UTF-8のTSV（タブ区切り）またはCSV（カンマ区切り）のテキスト。

データを用意する

1列目2列目3列目
問題解答解説（任意）
  • 1行に1問を書きます。4列目以降は無視されます。
  • 1行目が「問題」「解答」のような見出しなら、自動で除外されます。
  • 一度に取り込めるのは最大300問です。問題か解答が空の行は取り込まれません。
  • CSVでセルにカンマや改行を含める場合は、セルを「"」で囲みます。

形式の例は、問題集表示の「?」→「詳しい使い方ガイドを見る」の2〜3ページ目で確認できます。「サンプルをコピー」「サンプルを保存」で、そのまま使えるサンプルを入手できます。

取り込む

  1. 表計算アプリでセルをコピーするか、CSVで書き出します。
  2. 問題集表示の「＋」をタップし、「貼り付けて作成」または「ファイルから作成」を選びます。
  3. 「一括作成」画面で、取り込まれた内容を確認します。「問題集タイトル」（ファイルから作成した場合はファイル名が入ります）と教科を確認・変更します。
  4. 必要に応じて各行を直したり、削除したり、「行を追加」で追加したりします。
  5. 「問題集を作成」をタップします。

取り込めなかった行がある場合は「取り込めなかった行: ○件」と表示されます。300問を超える場合は先頭300問だけが取り込まれ、残りは別の問題集として作成するよう案内されます。読み込めない場合は「形式の説明を見る」から形式を確認してください。

完了の確認

用意した問題がまとめて1つの問題集になります。

覚えた・覚えていないで学習する

問題集を開き、解答を確認しながら「覚えた」「覚えていない」を記録します。覚えていない問題だけを繰り返して、少しずつ減らしていきます。

必要な条件

保存済みの問題集。解答欄に書く場合はApple Pencil。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 公開中の3.8.3ではまだ利用できません。

学習を始める

  1. 問題集表示で問題集のカードをタップします。
  2. 初めて開く問題集は、すぐに1問目から始まります。
  3. 学習の記録がある問題集では「前回の記録」が表示されます。左に「覚えていない」、右に「覚えた」の数が表示されます。
  4. 「続きから（残り○問）」「覚えていない問題 ○問」「最初から」から始め方を選びます。やめるときは「終了する」を選びます。

解答を書いて確認する

  1. 問題を読みます。
  2. 解答欄に、Apple Pencilで答えを書きます（指では書けません）。書き直すときは「全消去」をタップします。
  3. 指で画面をタップすると解答が表示されます。書いた答えは上部に小さく残るので、解答と見比べられます。

解答欄に書いた内容は保存されません。次の問題へ進むと消えます。

覚えた・覚えていないを記録する

  • 右にスワイプ、または「覚えた」をタップ：覚えた問題として記録します。
  • 左にスワイプ、または「覚えていない」をタップ：覚えていない問題として記録します。

記録すると次の問題へ進みます。解答を表示する前に記録することもできます。前の問題へ戻る操作はありません。上部のバーと「3 / 12」のような表示で進み具合を確認できます。

右上の「シャッフル」をONにすると、問題がランダムな順番で出題されます。シャッフルの設定はアプリ全体で共通で、初期状態はOFFです。

出典のノートを横に開く

  1. 解答を表示すると、出典（例「経済学 › 第8回 › p.3」）が表示されます。
  2. 出典をタップすると、画面の左側に元のノートのページが表示されます。ピンチで拡大して読めます。
  3. ノート自体を開くときは「ノートで開く」、閉じるときは「×」をタップします。

ノートを指定せずに作った問題集では「（教科）› ノートを選ぶ」と表示されます。タップしてノートを選ぶと、そのノート全体を参照できます。

1周の結果を確認する

  1. すべての問題を記録すると「○周目 おつかれさま」と結果が表示されます。
  2. その周の「覚えていない」「覚えた」の数と、覚えていない問題の一覧を確認します。
  3. 「覚えていない ○問をもう一周」で、覚えていない問題だけを繰り返します。「最初からもう一周」ですべての問題を解き直します。「終了する」で学習を終えます。

すべて覚えた場合は「すべて覚えました」と表示されます。周回の数は問題集ごとに積み重なり、「最初から」を選んでも0には戻りません。途中で閉じても記録は1問ずつ保存されているので、次回は「続きから」再開できます。

公開中の3.8.3では： 問題集を開くとカード形式で表示されます。カードをタップして解答を表示し、「前へ」「次へ」またはスワイプで別の問題へ移ります。

完了の確認

問題ごとに自分で答えてから解答を確認し、覚えていない問題を繰り返し学習できます。

問題集を編集・管理する

保存済みの問題を直したり、問題を追加・削除したりします。手動での編集はAI残量を使いません。

Uni:Note 4.0.0（2026年10月30日公開予定）の内容です。 公開中の3.8.3ではまだ利用できません。

長押しメニューを使う

問題集のカードを長押しすると、次の操作を選べます。

項目できること
問題を追加「1問ずつ作成」と同じ画面で、問題を追加します
問題集を編集タイトルの変更と、問題ごとの編集・削除を行います
教科を設定自分で作った問題集の教科と参照ノートを変更します
削除問題集全体を削除します

「教科を設定」は、自分で作った問題集とまとめて作った問題集に表示されます。ノートからAIで作った問題集は、元のノートの教科に分類されます。

問題を直す・削除する

  1. 「問題集を編集」を選びます。
  2. 問題がカードで一覧表示されます。直したい問題のカードをタップし、内容を直して「保存」をタップします。
  3. 問題を削除するときは、カード右端のゴミ箱をタップし、「問題を削除」の確認で「削除」をタップします。
  4. 問題を追加するときは、下部の「問題を追加」をタップします。
  5. タイトルを変えた場合は、右上の「保存」をタップします。

問題の追加・編集・削除は、その時点で保存されます。問題が1問だけの場合、その問題は削除できません。

問題集全体を削除する

  1. 問題集のカードを長押しし、「削除」を選びます。
  2. 「この問題集を削除しますか？」と表示されたら、問題と学習の記録も削除されることを確認して「削除」をタップします。

公開中の3.8.3では： 問題集のカードを長押しすると「問題集を編集」「削除」を選べます。編集画面ではタイトル・問題文・解答・解説を直し、「保存」をタップします。「削除」を選ぶと確認なしで問題集が削除されます。

完了の確認

直した内容が学習画面へ反映されます。

注意事項

問題集の削除はゴミ箱から復元できません。

ホームの問題集表示を変える

ホームの問題集のボタンを表示するか選べます。非表示にしても、保存した問題集を削除することにはなりません。

表示を切り替える

  1. ホームの歯車から設定を開きます。
  2. 「学習支援」の「問題集」で「ホームに問題集を表示」を確認します。
  3. 非表示にするときはOFFにします。
  4. ホームへ戻って表示を確認します。

再びホームから使う場合は、同じ項目をONに戻します。

完了の確認

ホームの問題集ボタンを使い方に合わせて表示・非表示にできます。
