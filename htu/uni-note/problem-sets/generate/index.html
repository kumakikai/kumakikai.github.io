ノートからAI問題集を作る

更新日 2026-09-19

ノートの必要なページからAIで問題を作り、採用する候補だけを問題集として保存します。

必要な条件

通信環境とAI残量。問題の元になるノート。

対象を決めて生成する

  1. 元にするノートを開きます。
  2. 「その他 → 問題集を作る」を選びます。
  3. 対象ページを1〜20ページ選びます。
  4. 予定の問題数と予想消費量を確認します。
  5. 生成を開始します。

処理をやめたい場合は生成中のキャンセルを選びます。生成完了後は、候補を確認してから保存します。

候補を採用・破棄する

  1. 候補の問題と解答を読みます。
  2. 残す候補は追加、不要な候補は破棄を選びます。
  3. 次の候補も同じように確認します。

右スワイプで追加、左スワイプで破棄する方法もあります。

問題集として保存する

  1. 採用する候補を確認します。
  2. 「問題集として保存」を選びます。
  3. 問題集の名前を入力します。
  4. 保存を確定します。

完了の確認

採用した問題だけをまとめた問題集を、ホームやノートから開けます。

注意事項

生成だけでは候補の選別は終わりません。解答の正しさを確認し、保存後も必要に応じて編集してください。

関連する使い方

  • 保存した問題集で復習する
  • 問題集を手動作成・編集する
  • AI問題集を手修正して復習する

便利な使い方
