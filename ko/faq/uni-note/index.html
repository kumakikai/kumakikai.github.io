기본#

Uni:Note는 어떤 앱인가요?#

iPad용 손글씨 노트 앱입니다.
Apple Pencil로 쓰는 흐름을 중심으로 설계되어 있고, 과목별로 노트를 정리해서 사용할 수 있습니다.

어떤 기기를 지원하나요?#

iPad 전용입니다.

무료 플랜에 제한이 있나요?#

있습니다.
현재 앱 기준으로 무료 플랜은 과목 최대 10개 / 과목당 노트 최대 6권까지 사용할 수 있습니다.

프리미엄에서는 과목 수와 노트 수 제한이 해제되고, 범위 이동, 녹음, 간편 백업을 사용할 수 있습니다.

어떤 언어를 지원하나요?#

현재 다음 언어를 지원합니다.

  • 일본어
  • English
  • 한국어
  • Deutsch
  • 繁體中文
  • Français

v3.0.0의 주요 변경 사항은 무엇인가요?#

v3.0.0에서는 학습 지원과 노트 보조 기능이 크게 업데이트되었습니다.

  • 문제 풀이 어시스턴트가 다시 제공되며 노트 화면 위쪽에서 열 수 있습니다
  • 자 기능이 추가되었습니다
  • 범위 이동 기능이 추가되었습니다
  • 암기 기능이 붙임쪽지 방식의 마커로 전면 개편되었습니다
  • 녹음, 실시간 문자 변환, AI 요약이 추가되었습니다
  • 홈 화면의 과목 순서 변경과 노트 목록의 노트 순서 변경이 추가되었습니다
  • Firebase Crashlytics를 사용한 진단 및 크래시 분석이 도입되었습니다

진단 및 크래시 분석으로 전송되는 데이터에는 노트 내용, 손글씨 내용, 과목 이름, 첨부 파일, 이미지, PDF, 녹음 내용 등이 포함되지 않습니다.

Split View나 Slide Over에서 사용할 수 있나요?#

네.
Uni:Note는 iPad의 멀티윈도우 표시(Split View / Slide Over)를 지원합니다.

일반적으로는 먼저 Uni:Note를 열고 Dock을 표시한 뒤, Dock에서 다른 앱이나 Uni:Note를 화면 가장자리로 드래그하면 Split View, 겹쳐 놓으면 Slide Over로 사용할 수 있습니다.

세부 UI나 표시 이름은 iPadOS 버전에 따라 조금 다를 수 있습니다.

Uni:Note를 두 개 동시에 열 수 있나요?#

네.
Uni:Note는 여러 창을 지원합니다.

먼저 Uni:Note 하나를 연 상태에서 Dock을 표시하고, Dock의 Uni:Note 아이콘을 길게 눌러 새 윈도우를 여는 항목을 선택하면 됩니다.

두 번째 창을 연 뒤에는 나란히 두어 Split View, 겹쳐 띄워 Slide Over로 사용할 수 있습니다.

Apple Pencil이 꼭 필요한가요?#

손글씨 기능은 Apple Pencil을 기준으로 설계되어 있습니다.
손가락 입력은 주로 스크롤과 사진, 문서 사진, PDF 조작에 사용합니다.

로그인이나 계정 등록이 필요한가요?#

아니요.

노트와 페이지#

노트 제목은 필수인가요?#

아니요.
제목을 비운 채로 만들면 오늘 날짜가 노트 제목이 됩니다.

새 과목을 처음 열 때 나오는 제목 입력은 무엇인가요?#

첫 번째 노트의 제목입니다.
비운 채로 OK 또는 바로 쓰기를 선택하면 오늘 날짜가 제목이 됩니다.

아무것도 확정하지 않고 돌아가면 첫 번째 노트는 남지 않습니다.

과목을 만들 때 어떤 항목을 고를 수 있나요?#

다음을 선택할 수 있습니다.

  • 과목 이름
  • 용지 종류: 줄 / 세로 줄 / 격자 / 무지
  • 종이 색
  • 표지 색상
  • 세로 노트처럼 사용 (세로 줄 선택 시만)

세로 노트는 무엇인가요?#

세로 줄을 선택한 과목에서 사용할 수 있는 표시 방식입니다.
새 과목을 만들 때 세로 노트처럼 사용을 켜면, 가로 화면에서는 펼침면처럼, 세로 화면에서는 1페이지씩 표시되며 가로로 스크롤합니다.

노트 방향은 만든 뒤에는 바꿀 수 없습니다.

같은 과목 안에서 노트를 나눌 수 있나요?#

네.
노트 목록의 새 노트에서 추가할 수 있습니다.

노트 목록 안의 노트는 순서를 바꿀 수도 있습니다.

새 페이지는 어떻게 늘어나나요?#

마지막 페이지에서 쓰기 시작하면 다음 페이지가 자동으로 추가됩니다.

노트의 최대 페이지 수는 몇 장인가요?#

한 노트는 최대 150페이지까지입니다.
150페이지에 도달하면 더 이상 페이지를 추가할 수 없습니다. PDF 붙이기로도 이 한도를 넘겨 페이지를 늘릴 수 없습니다. 필요하면 같은 과목 안에 새 노트를 추가해 주세요.

확대 / 축소할 수 있나요?#

네.
노트 화면에서는 두 손가락 핀치로 확대 / 축소할 수 있습니다.

손글씨 범위를 둘러싸서 이동할 수 있나요?#

네. 노트 화면 위쪽의 범위 이동에서 손글씨 선을 한꺼번에 선택해 이동할 수 있습니다.

기본 흐름:

  • 범위 이동을 선택합니다
  • Apple Pencil로 이동할 손글씨 범위를 둘러쌉니다
  • 선택된 손글씨를 드래그해서 이동합니다

둘러싼 범위에 조금이라도 포함된 선은 전체가 선택됩니다. 대상은 손글씨 선이며 사진, PDF, 붙임쪽지 마커는 개별적으로 조작합니다. 범위 이동은 Premium 기능입니다.

페이지를 삭제할 수 있나요?#

네.
페이지 목록에서 해당 페이지를 길게 눌러 삭제할 수 있습니다.

다만 노트에 페이지가 1장만 있으면 페이지 자체는 남고 내용만 지워집니다.

노트를 보호할 수 있나요?#

네.
노트 목록에서 보호를 선택하면 해당 노트가 읽기 전용이 됩니다. 설정에서 보호 해제 시 생체 인증을 요구하도록 할 수도 있습니다.

과목을 편집할 수 있나요?#

네.
홈에서 해당 과목을 길게 누르고 편집을 열면 다음을 바꿀 수 있습니다.

  • 과목 이름
  • 용지 종류
  • 종이 색
  • 표지 색상

다만 노트 방향은 만든 뒤에는 바꿀 수 없습니다.
노트 제목은 노트 목록에서 변경할 수 있습니다.

홈 화면에서는 과목 순서도 바꿀 수 있습니다.

휴지통에서 무엇을 복원할 수 있나요?#

과목과 노트 목록에 있는 노트를 복원할 수 있습니다.
휴지통에서는 삭제 항목이 과목별로 묶여 표시되고, 과목을 탭하면 그 안의 노트를 볼 수 있습니다.

과목 전체를 복원할 수도 있고, 노트만 따로 복원할 수도 있습니다.
페이지 삭제는 휴지통으로 가지 않고 바로 삭제됩니다.

사진과 PDF#

사진을 붙일 수 있나요?#

네.
기타 > 사진 붙이기에서 사진을 한 장씩 추가할 수 있습니다. 붙인 뒤에는 이동 / 확대 축소가 가능하고, 더블탭으로 고정 / 해제를 전환할 수 있습니다.

사진을 문서처럼 붙일 수 있나요?#

네.
기타 > 사진을 문서로 붙이기에서 카메라 또는 보관함 사진을 보정한 뒤 페이지에 문서처럼 붙일 수 있습니다.

붙인 뒤에는 더블탭으로 고정 / 해제하고, 손가락으로 위치와 크기를 조정할 수 있습니다.

PDF를 붙일 수 있나요?#

네.
기타 > PDF 붙이기에서 PDF 파일을 선택해 붙일 수 있습니다.

  • PDF 파일에서 한 페이지 이상을 선택할 수 있습니다
  • 양면 펼침 분할을 켜면 펼침 PDF를 가운데에서 나눌 수 있습니다
  • 여러 PDF 페이지를 한 번에 붙일 수도 있습니다

붙인 뒤에는 더블탭으로 고정 / 해제하고, 손가락으로 위치와 크기를 조정할 수 있습니다.

PDF를 내보낼 수 있나요?#

네.
기타 > PDF 내보내기에서 이 노트만 또는 과목 전체를 PDF로 내보낼 수 있습니다.

녹음과 문자 변환#

녹음 기능을 사용할 수 있나요?#

네. 노트 화면 위쪽의 녹음 버튼에서 녹음 패널을 열 수 있습니다.

  • 녹음 시작 / 일시 정지 / 정지
  • 재생 / 탐색 / 재생 속도 변경
  • 녹음 이름 변경
  • 녹음 잠금 / 잠금 해제
  • 녹음 삭제
  • 녹음 오디오 공유

녹음, 재생, 문자 변환 보기 기능은 Premium 기능입니다. 한 노트에 보관할 수 있는 녹음은 최대 5개입니다. 녹음 파일 1개는 최대 30분입니다. 녹음이 30분에 도달하면 Uni:Note가 해당 녹음을 자동으로 저장하고 이어지는 다음 녹음을 시작합니다. 자동으로 분할된 녹음도 노트당 5개 제한에 포함됩니다. 녹음 중 Uni:Note 홈으로 돌아가거나 iPad가 잠자기 상태가 되면, 그 시점에 녹음이 종료되고 저장됩니다. 녹음 중 이러한 동작을 하면 녹음 데이터가 손상될 수 있습니다. 노트를 떠나거나 iPad를 잠자기 상태로 만들기 전에 녹음을 중지하고 저장하세요.

문자 변환과 AI 요약을 사용할 수 있나요?#

지원되는 환경에서는 녹음 중 실시간 문자 변환을 표시할 수 있습니다. Apple의 문자 변환 지원 모델 기준으로, 실시간 문자 변환과 AI 요약은 iPadOS 26 이상을 실행하는 iPad mini(6세대 이후), iPad(10세대 이후), iPad Air(4세대 이후), 11형 iPad Pro(3세대 이후), 12.9형 iPad Pro(5세대 이후), 13형 iPad Pro(M4 이후)에서 사용할 수 있습니다.

AI 요약은 기기에서 이미 만들어진 문자 변환 텍스트를 바탕으로 생성됩니다. AI 요약을 위해 오디오 파일을 전송하지 않습니다.

AI 요약은 선택한 녹음의 문자 변환 텍스트를 바탕으로 공부용 또는 회의용 재구성 노트를 만들 수 있습니다. 여러 녹음을 선택한 경우에는 녹음별 구분을 유지합니다. 실행하기 전에 대상 녹음 수, 글자 수, 예상 AI 사용량을 확인할 수 있습니다.

AI 요약에는 AI 잔량이 필요합니다.

녹음도 백업에 포함되나요?#

기본 백업에는 녹음 정보와 문자 변환이 포함됩니다. 녹음 오디오 파일(m4a)은 백업 내보내기와 간편 백업 모두에서 녹음 음성도 백업에 포함을 켠 경우에만 포함됩니다.

학습 지원#

암기 기능은 무엇인가요?#

설정 > 학습 지원에서 암기 기능을 켜면 노트 화면에서 붙임쪽지 마커를 사용할 수 있습니다.

  • 붙임쪽지 마커로 가리고 싶은 부분을 표시합니다
  • 한 번의 스트로크가 하나의 독립된 붙임쪽지로 저장됩니다
  • 붙임쪽지를 손가락으로 탭해 투명 / 불투명을 전환합니다
  • 붙임쪽지를 손가락으로 길게 누른 뒤 표시되는 삭제 버튼으로 삭제합니다

붙임쪽지 마커를 페이지 전체에서 한 번에 표시 / 숨길 수 있나요?#

아니요.
v3.0.0에서는 기존의 페이지 전체 열기 / 닫기 방식이 아니라, 붙임쪽지마다 투명 / 불투명을 전환하는 방식으로 바뀌었습니다.

이전 버전의 암기 마커가 남아 있는 페이지는 열 때 붙임쪽지 마커로 이전됩니다.

학습 지원 기능은 현재 어떤 상태인가요?#

현재는 문제 풀이 어시스턴트와 문제집 만들기를 사용할 수 있습니다. 둘 다 AI 기능이므로 AI 잔량이 필요합니다.

문제 풀이 어시스턴트는 어떻게 사용하나요?#

설정 > 학습 지원에서 문제 풀이 어시스턴트를 켜면 노트 화면 위쪽에 표시됩니다.

기본 흐름:

  • 노트 화면 위쪽의 문제 풀이 어시스턴트를 선택합니다
  • 풀고 싶은 문제를 Apple Pencil로 닫힌 모양으로 둘러쌉니다
  • 범위를 확인하고 풀이하기를 선택합니다
  • 해답과 설명을 확인합니다

결과 화면에서 해답과 설명을 복사하거나 공유할 수 있습니다.

주로 수식, 계산 문제, 짧은 설문에 대응합니다. 긴 독해, 자유 서술, 도표 중심 문제는 지원되지 않을 수 있습니다.

사용하려면 AI 잔량이 필요합니다. AI 잔량이 부족하면 앱 안에서 추가할 수 있습니다.

문제집 만들기는 어떻게 사용하나요?#

기타 > 문제집 만들기에서 시작합니다.

사용하려면 AI 잔량이 필요합니다.

기본 흐름:

  • 페이지 선택으로 대상 페이지를 정합니다
  • 문제집 만들기를 실행합니다
  • 후보를 추가 / 버리기로 고릅니다
  • 문제집으로 저장으로 저장합니다

저장 후에는 지금 복습에서 이어서 볼 수 있습니다.
나중에 다시 보려면 홈 상단에서 문제집으로 전환한 뒤 목록에서 열 수 있습니다.

문제집은 홈에서 삭제할 수 있지만 휴지통으로 가지 않으므로 복구할 수 없습니다.

AI 잔량은 무엇인가요?#

문제 풀이, 문제집 생성, AI 요약에서 공통으로 사용하는 이용 잔량입니다. 부족해지면 앱 안의 플랜 화면에서 AI 잔량을 추가할 수 있습니다.

AI 잔량 관리는 구매와 잔량을 확인하기 위한 식별 ID를 사용합니다. 이 ID에는 이름, 이메일 주소, Apple ID, 노트 내용 등 개인을 직접 식별할 수 있는 정보가 포함되지 않습니다.

데이터와 저장#

데이터는 어디에 저장되나요?#

앱 내부에 저장됩니다.

진단 데이터나 크래시 정보가 전송되나요?#

네. 앱 안정성 개선과 문제 조사를 위해 Firebase Crashlytics로 진단 데이터와 크래시 정보를 전송할 수 있습니다.

전송되는 정보는 앱 버전, OS 버전, 대략적인 기기 분류, 화면 크기 분류, 조작 종류, 대략적인 개수 구간, 오류 분류 같은 기술 정보입니다.

노트 본문, 손글씨 내용, 이미지 내용, PDF 내용, 녹음 내용, OCR 결과, 노트 이름, 과목 이름, 파일 이름, 사용자 이름, 이메일 주소 등은 전송되지 않습니다.

Google Analytics for Firebase를 통한 사용 이벤트 수집은 하지 않습니다.

자동 동기화가 있나요?#

현재는 없습니다.
필요하면 설정 > 백업을 이용해 주세요.

백업 기능이 있나요?#

네.
설정 > 백업에서는 다음을 사용할 수 있습니다.

  • 간편 백업 업데이트
  • 간편 백업에서 복원
  • 백업 내보내기
  • 파일에서 복원

간편 백업은 iCloud를 사용한 저장 / 복원 기능입니다. 파일 기반 백업도 계속 사용할 수 있습니다.

간편 백업은 누구나 사용할 수 있나요?#

아니요.
간편 백업은 프리미엄에서 사용할 수 있습니다.

프리미엄이 없어도 백업 내보내기와 파일에서 복원은 사용할 수 있습니다.

복원 후 바로 사용할 수 있나요?#

복원 후에는 앱을 한 번 닫았다가 다시 열어 주세요.
다음 실행 시에는 홈이 표시됩니다.

설정#

어떤 설정이 있나요?#

주로 다음 항목을 바꿀 수 있습니다.

  • 기본 템플릿
  • 새 노트 기본 바탕색
  • 홈 열기 또는 이전 노트 열기
  • 도구 팔레트 자동 접기
  • 암기 기능
  • 문제 풀이 어시스턴트
  • 녹음 문자 변환 언어
  • AI 요약 기본 형식(공부용 / 회의용)
  • 과목 이름
  • 보호 해제 시 생체 인증 요구
  • 왼손잡이 모드
  • 머리말 / 꼬리말
  • PDF 내보내기 배경색
  • 언어

과목 이름 표기를 바꿀 수 있나요?#

네.
설정의 과목 이름에서 과목 / 노트 / 그룹 / 카테고리를 고를 수 있습니다.

왼손잡이 모드에서는 무엇을 바꿀 수 있나요?#

팔레트 기본 위치, 줄 노트의 빨간 기준선 위치, PDF 붙이기 위치를 조정할 수 있습니다.

언어를 바꿀 수 있나요?#

네.
설정 > 언어에서 변경할 수 있습니다.

사용 방법 페이지는 어디서 열 수 있나요?#

설정 > 지원 > 사용 방법에서 열 수 있습니다.
