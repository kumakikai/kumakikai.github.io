Uni:Note Pocket/FAQ

FAQ (Uni:Note Pocket)

업데이트 2026.09.07

시작 전 확인

iOS 17.0 이상을 실행하는 iPhone이 필요합니다.

Pocket은 iPhone용 읽기 앱이며 iPad의 Uni:Note로 만든 백업이 필요합니다. Pocket만으로 새 노트를 만들 수 없습니다. 별도 앱 계정은 필요하지 않습니다.

노트·페이지·폴더·문제집의 생성·편집·삭제·정렬은 iPad에서 하세요.

백업 가져오기 →

백업 실패 또는 갱신되지 않음

손상된 zip이나 필수 파일이 없는 백업은 거부합니다. 실패하면 이전 데이터를 유지하고 원본 zip도 수정하지 않습니다. Uni:Note에서 새 zip을 내보내 압축을 풀지 않고 선택하세요.

간편 백업의 갱신 아이콘은 iCloud 파일 상태를 확인합니다. 새 파일이 아직 도착하지 않으면 날짜는 그대로입니다. 수동 읽기는 확인 후 가져오는 작업입니다. 실행 시 자동 읽기는 사용 가능한 백업이 있을 때만 동작하며 실시간 동기화가 아닙니다.

최신 백업 읽기 →

노트·녹음·스티커가 없음

검색 대상은 가져온 노트의 명시적 제목입니다. 손글씨·본문·PDF·과목 이름은 검색하지 않습니다. 문제집과 스티커는 백업에 포함되어야 표시됩니다. 스티커 탭은 표시만 바꾸고 편집하지 않습니다.

오디오가 없는 백업은 녹음을 재생할 수 없습니다. iPad에서 오디오를 포함해 다시 내보내고 가져오세요. Pocket에서는 녹음·문자 변환·AI 요약을 하지 않습니다.

읽는 위치나 표시가 다름

마지막 페이지부터 보려면 이전 위치에서 재개를 켜세요. 언어·테마·과목 이름은 홈의 톱니바퀴에서 변경합니다. 핀치·두 번 탭으로 확대하고 보통 노트는 세로, 세로 노트는 가로로 넘깁니다.

이미지 가이드는 앱의 설정 → 지원 → 사용 방법에서도 열 수 있습니다.
