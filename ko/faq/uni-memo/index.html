기본#

Uni:Memo는 어떤 앱인가요?#

Uni:Memo는 Uni:Note의 companion app입니다.
Uni:Note에서 만든 백업을 가져와 iPhone에서 읽기 전용으로 다시 볼 수 있게 해 주는 앱입니다.

Uni:Memo만으로 사용할 수 있나요?#

아니요.
Uni:Note에서 만든 백업 파일이 필요합니다.

지원 기기는 무엇인가요?#

iPhone 전용입니다.

로그인이나 계정 등록이 필요한가요?#

필요하지 않습니다.

백업 가져오기#

무엇을 가져올 수 있나요?#

Uni:Note에서 만든 백업 zip 파일을 가져올 수 있습니다.

가져오기 중 원본 백업 파일이 변경되나요?#

아니요.
선택한 zip을 검증한 뒤 앱 안에서 펼쳐서 읽기 때문에 원본 파일은 수정되지 않습니다.

가져오기에 실패하면 어떻게 되나요?#

손상되었거나 잘못된 백업은 안전하게 중단됩니다.
이미 이전에 가져온 데이터가 있으면 그 데이터는 유지한 채 오류만 안내합니다.

자동 동기화가 있나요?#

현재는 없습니다.
Uni:Memo는 백업 데이터를 다시 보는 방식으로 설계되어 있습니다.

열람#

앱에서 무엇을 할 수 있나요?#

주요 기능은 다음과 같습니다.

  • 노트 목록 보기
  • 노트와 섹션 열기
  • 페이지 보기
  • 암기 레이어 표시 / 숨기기

노트나 페이지를 편집할 수 있나요?#

없습니다.
Uni:Memo는 읽기 전용입니다.

노트를 만들거나 삭제하거나 순서를 바꿀 수 있나요?#

없습니다.
생성과 편집은 Uni:Note에서 하는 것을 전제로 합니다.

암기 기능은 무엇인가요?#

페이지 단위의 암기 레이어를 보이거나 숨기면서 다시 볼 수 있는 기능입니다.
Uni:Memo에서는 암기 내용 자체를 편집하지 않습니다.

페이지를 확대할 수 있나요?#

네.
핀치 제스처나 더블탭으로 확대할 수 있습니다.

마지막으로 보던 위치에서 다시 시작할 수 있나요?#

네.
설정에서 켜고 끌 수 있습니다.

  • 가로 흔들림 방지
  • 상위 분류 이름
