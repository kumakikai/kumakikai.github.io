GigaPoke

iPhone

받은 데이터 혜택,만료 전에 사용하세요.

povo 2.0 혜택 코드를 만료일이 가까운 순서로 모아 관리하세요. 필요한 코드를 바로 복사하고, 위젯에서도 다음에 쓸 데이터 혜택을 확인할 수 있습니다.

배포 지역
  • 🇯🇵

povo 2.0 혜택 관리를 돕는 비공식 앱입니다. KDDI 주식회사, povo, au와 제휴·협찬·공인 등 어떠한 관계도 없습니다.

화면은 일본어 버전입니다.

받은 코드의 등록부터 사용까지.

povo 2.0 특전 메일을 다시 찾는 대신, 등록한 코드와 기한을 한곳에서 확인하세요. 데이터 코드뿐 아니라 외부 쿠폰 코드와 수령 URL도 정리할 수 있습니다.

메일에서 공유해 등록하고, 기한이 가까운 항목을 선택한 다음 코드를 복사해 사용합니다. 기가포케는 이 흐름을 iPhone에서 관리하는 비공식 앱입니다.

주요 기능

  • 메일에서 등록

    특전명·코드·기한이 포함된 내용을 공유하거나 붙여넣고, 인식한 정보를 확인한 뒤 저장합니다. 직접 입력할 수도 있습니다.

  • 기한을 보고 사용 순서 선택

    각 카테고리에서 기한이 가까운 특전을 먼저 표시합니다. 기한 전 알림을 설정해 사용할 시점을 확인할 수 있습니다.

  • 복사한 뒤 povo 2.0으로

    코드를 복사한 후 povo 2.0 앱을 여는 설정을 제공합니다. 코드 붙여넣기와 사용 절차는 povo 2.0에서 진행합니다.

  • 홈 화면 위젯에서 확인

    데이터 코드의 특전 내용과 남은 일수를 홈 화면에서 확인하고, 사용할 코드를 복사하는 단계로 이동할 수 있습니다.

코드와 기한을 하나의 목록으로

특전 내용과 기한을 나란히 보여 주는 홈 화면입니다. 붙여넣기로 추가하고 원하는 코드의 사용 동작으로 이동할 수 있습니다.

다음에 쓸 데이터를 홈 화면에

작은 위젯과 중간 위젯에서 기한이 가까운 데이터 코드를 확인합니다. 버튼으로 기가포케를 열어 코드를 복사할 수 있습니다.

이렇게 활용하세요

  • 특전 메일을 정리할 때

    매번 원래 메일을 찾는 대신 필요한 코드와 기한을 등록해 두고 싶은 분에게.

  • 기한이 가까운 것부터 쓸 때

    데이터 코드나 외부 특전이 여러 개 있어 기한을 기준으로 다음에 쓸 항목을 고르고 싶을 때.

  • 홈 화면에서 확인할 때

    앱을 열기 전에 위젯에서 특전 내용과 남은 일수를 보고 싶을 때.
