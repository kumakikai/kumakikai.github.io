iPad에서 정리한 학습 내용을 iPhone으로.

Uni:Note Pocket은 Uni:Note의 노트와 문제집을 iPhone에서 다시 보는 열람 전용 앱입니다. 이동 중이나 수업 전, iPad를 펼치기 어려울 때도 학습 내용을 확인할 수 있습니다.

먼저 Uni:Note 백업을 가져옵니다. 과목별 노트를 찾아 페이지를 세로로 읽고, 문제의 답과 해설을 확인할 수 있습니다. 작성과 편집은 Uni:Note에서, 휴대하며 읽기는 Pocket에서 하세요.

주요 기능

  • 백업 가져오기

    Uni:Note 백업 ZIP 또는 간편 백업을 선택해 불러옵니다.

  • 페이지 이어 읽기

    노트를 세로로 스크롤하고 핀치나 두 번 탭하기로 손글씨를 확대합니다.

  • 제목으로 찾기

    노트 제목으로 검색하거나 과목별로 노트를 찾습니다.

  • 문제집과 암기 복습

    가져온 답과 해설을 확인하고 노트의 스티키 마커를 탭해 전환합니다.

시작은 Uni:Note 백업 가져오기부터.

Uni:Note에서 준비한 백업을 불러오면 Pocket에서 노트와 문제집을 볼 수 있습니다. 수정된 내용을 보려면 새 백업을 다시 가져오세요.

잠깐의 여유에 답을 확인하세요.

iPad에서 만든 문제집도 가져온 뒤에는 iPhone에서 복습할 수 있습니다. 문제를 읽고 답과 해설을 확인하며 통학 중이나 수업 전의 짧은 시간을 활용하세요.

이럴 때 사용하세요

  • 통학하거나 이동할 때

    iPad를 꺼내지 않고 수업 노트를 조금씩 다시 읽습니다.

  • 수업 시작 전

    이전 노트를 찾아 내용을 바로 확인합니다.

  • 시험 전 확인

    가져온 문제집과 스티키 마커로 기억을 점검합니다.
