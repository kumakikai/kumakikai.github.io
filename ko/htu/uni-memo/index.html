사용 방법 (Uni:Memo)

Uni:Memo 사용 방법
번역:
  • Ja
  • En
  • De
  • Zh-Hant
  • Fr

Uni:Memo는 Uni:Note 백업을 iPhone에서 다시 보기 위한 읽기 전용 companion app입니다.
글을 쓰는 앱이 아니라, 백업을 가져와 노트를 안전하게 확인하는 데 초점을 둡니다.

전제 조건:

  • iPhone 전용
  • Uni:Note에서 만든 백업 zip 필요
  • 편집이나 동기화가 아니라 열람과 암기 레이어 확인이 중심

1. Uni:Note에서 백업 준비하기#

먼저 Uni:Note에서 백업 파일을 만들고, 파일 앱 등에서 접근할 수 있는 위치에 저장합니다.

Uni:Memo 자체로는 노트를 만들 수 없기 때문에, 확인하려는 내용은 미리 Uni:Note 백업에 들어 있어야 합니다.

2. 백업 가져오기#

책장 화면의 가져오기 에서 Uni:Note 백업 zip을 선택합니다.

  • zip 선택
  • 앱이 내용 검증
  • 문제가 없으면 snapshot 로드

손상되었거나 잘못된 백업은 안전하게 중단됩니다.

3. 책장에서 노트 확인하기#

가져오기가 끝나면 책장에서 상위 분류별 목록을 확인할 수 있습니다.

  • 노트 수 / 페이지 수 요약
  • 최근에 보던 노트로 다시 들어가는 경로

아직 백업을 가져오지 않았다면 먼저 가져오기 안내가 표시됩니다.

4. 노트와 페이지 열기#

책장에서 분류를 열고, 노트와 섹션을 따라가 원하는 페이지를 표시합니다.

  • 노트 목록 열기
  • 보고 싶은 노트 선택
  • 세로 연속 흐름으로 페이지 확인

Uni:Memo는 읽기 전용이므로 노트 이름 변경이나 페이지 편집은 하지 않습니다.

5. 페이지 다시 보기#

페이지 화면에서는 가져온 내용을 그대로 확인할 수 있습니다.

  • 핀치로 확대 / 축소
  • 더블탭으로 확대
  • 세로 스크롤로 페이지 이동

무거운 노트에서도 우선 안전하게 다시 보는 데 초점을 맞춘 구성입니다.

6. 암기 레이어 전환하기#

오른쪽의 눈 버튼으로 페이지 단위 암기 레이어를 표시하거나 숨길 수 있습니다.

  • 가린 상태로 먼저 확인
  • 다시 보여 정답 확인

Uni:Memo에서는 암기 마스크 자체를 편집하지 않습니다.

7. 설정 조정하기#

설정에서는 주로 다음 항목을 바꿀 수 있습니다.

  • 언어
  • 테마
  • 마지막 위치에서 다시 열기
  • 가로 흔들림 방지
  • 상위 분류 이름

자신에게 맞는 읽기 방식으로 조정해 사용하세요.

8. 더 새로운 백업으로 바꾸기#

Uni:Note에서 새 백업을 만든 뒤, Uni:Memo에서도 다시 가져오기 를 실행합니다.

새 zip 검증이 성공한 경우에만 내용이 새 버전으로 바뀝니다.
