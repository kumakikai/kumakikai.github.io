시작하기

실제 화면으로 Uni:Note의 기본 조작을 안내합니다. Apple Pencil은 기존처럼 사용할 수 있고, 손가락으로 그리기를 켜면 한 손가락으로도 쓸 수 있습니다.

iPadOS 17.0 이상을 실행하는 iPad가 필요합니다. 녹음 문자 변환에는 지원되는 iPadOS 26 이상 환경이 필요합니다.

사용 방법 검색

기능이나 작업을 입력하면 관련 설명으로 바로 이동할 수 있습니다.

    기본 사용법

    과목과 첫 노트 만들기

    1. 홈 오른쪽 아래의 **+**를 탭하고 새 과목을 선택합니다.
    1. 이름, 줄, 종이색, 표지색을 선택합니다.
    2. 과목을 열어 첫 노트의 이름을 입력합니다. 비워 두면 오늘 날짜가 이름이 됩니다.

    같은 +에서 폴더도 만들 수 있습니다. 과목을 폴더로 드래그해 옮깁니다. 폴더를 삭제해도 안의 과목은 홈에 남습니다. 과목을 길게 누르면 이름과 종이를 수정할 수 있습니다.

    도구를 골라 쓰기

    1. 팔레트에서 펜, 형광펜, 지우개를 선택합니다.
    2. Apple Pencil로 쓰세요. 손가락으로 그리기가 켜져 있으면 한 손가락으로 그리거나 지울 수도 있습니다.
    3. 마지막 페이지에 쓰기 시작하면 다음 페이지가 자동으로 추가됩니다.

    손가락으로 그리기는 설정 메인 화면의 현재 플랜 카드 바로 아래와 첫 실행 안내에서 설정할 수 있습니다. 끄면 한 손가락으로 스크롤합니다. 단, 설정 → 노트 설정에서 두 손가락으로 스크롤을 켜면 두 손가락으로 스크롤합니다. 켜면 한 손가락이 그리기에 사용되므로 두 손가락으로 스크롤합니다. 확대·축소는 두 상태 모두 두 손가락 핀치로 합니다. Apple Pencil은 두 상태 모두에서 계속 사용할 수 있습니다.

    팔레트는 드래그로 옮길 수 있습니다. 노트 상단에서 자를 표시하고 한 손가락으로 이동한 뒤, 보이는 회전 핸들을 한 손가락으로 잡아 자 중심 주위로 돌립니다. Apple Pencil로 자의 가장자리를 따라 그리면 직선이 됩니다. 손가락으로 그리기가 켜져 있을 때는 손가락으로도 선을 그을 수 있습니다. 범위 이동은 손글씨 획 전체를 선택하며 사진·PDF·스티커는 따로 조작합니다. 세로 노트는 가로로 넘기며 만든 뒤 방향은 바꿀 수 없습니다.

    노트 전환과 제목 검색

    홈 검색창에 노트 제목의 일부를 입력하고 결과를 탭합니다. 손글씨, 페이지 본문, PDF, 과목 이름은 검색하지 않습니다.

    노트 안의 노트 목록에서 같은 과목의 다른 노트를 열거나 새 노트를 만듭니다. 노트 목록과 최근 노트에서 노트를 탭하면 열리고, 길게 누르면 편집·보호·삭제 메뉴가 나타납니다. 보호된 노트에는 해제만 표시됩니다. 삭제하면 확인 없이 바로 휴지통으로 이동합니다. 순서는 ≡ 핸들을 드래그해 바꿉니다. 페이지 목록에서 썸네일을 탭해 이동하고 길게 눌러 삭제합니다.

    2단 화면과 시간표

    홈 왼쪽 위 휴지통 옆의 2단 화면으로 전환을 탭하면 폴더와 과목을 왼쪽에 표시하고 노트를 빠르게 전환할 수 있습니다. 처음 표시할 화면은 설정 → 표시 설정 → 2단 화면을 기본으로 사용에서 고릅니다.

    홈 왼쪽 위의 달력 버튼을 탭하면 시간표가 열립니다. 요일·교시 칸에 과목을 등록하고 과목 칸을 탭하면 그 과목의 노트 목록이 열립니다. 설정 → 표시 설정 → 실행 시 열기에서는 시간표 표시나 현재 수업 노트 열기를 포함한 5가지 중에서 고를 수 있습니다.

    사진·PDF 첨부와 내보내기

    1. 노트 오른쪽 위의 기타를 엽니다.
    2. 사진, 문서 사진 또는 PDF 첨부를 선택합니다. 사진은 카메라로 촬영 또는 사진에서 선택을 고릅니다.
    3. 붙일 PDF 페이지를 고릅니다. 펼침면 문서는 나누어 붙일 수 있습니다.

    손가락으로 그리기가 꺼져 있으면 고정된 사진이나 PDF를 두 번 탭해 잠금을 해제하고 한 번 탭해 선택합니다. 다시 두 번 탭하면 고정됩니다. 켜져 있으면 팔레트 반대쪽에 있는 편집 버튼을 눌러 파란색으로 바꾼 뒤 자료를 탭합니다. 드래그하거나 크기 조절 핸들을 사용하세요. 빈 곳을 탭하거나 편집을 다시 누르면 손가락 필기로 돌아갑니다. 두 손가락 핀치는 노트 자체를 확대·축소합니다. 사진, 문서 사진, PDF, 텍스트, 도형은 오른쪽 위의 회전 핸들을 한 손가락으로 원을 그리듯 움직여 회전하며, 45°마다 맞춰집니다.

    기타 → PDF 내보내기로 공유할 수 있습니다. PDF에서 종이색을 빼려면 설정 → 표시 설정 → PDF 내보내기 설정의 PDF 내보내기에서 종이색 제외를 사용하세요.

    Uni:Note 4.0.0(2026년 10월 30일 공개 예정)의 내용입니다. 현재 공개 중인 3.8.3에서는 아직 사용할 수 없습니다.

    PDF 내보내기 설정에 스티커 메모 포함(기본값 켬)과 스티커 마커 포함(기본값 끔)이 추가됩니다.

    입력한 글과 도형·표 추가하기

    기타 → 텍스트를 고르고 노트 위치를 탭해 입력합니다. 입력 영역 밖을 탭하거나, 텍스트를 다시 고르거나, 위쪽 텍스트 입력 표시의 ×를 탭하면 확정됩니다. 키보드를 내리는 것만으로는 입력이 끝나지 않습니다. 배치한 글은 이동·크기 조절·회전할 수 있지만 내용은 다시 편집할 수 없으며 노트 제목 검색 대상도 아닙니다. 기타 → 도형에서 사각형, 원·타원, 말풍선 또는 표를 만듭니다. 색·선 굵기·실선/점선을 고르고 표는 행과 열도 지정합니다. 배치한 뒤 이동·크기·각도를 조절할 수 있습니다. 손가락으로 그리기가 켜져 있으면 편집을 누른 후 도형을 선택하세요. 표 셀에 글을 직접 입력하거나 배치 후 행·열 수를 바꿀 수는 없습니다.

    수업 녹음하기

    1. 노트 위의 마이크를 탭합니다.
    2. 빨간 녹음 버튼으로 시작하고 필요하면 일시정지·재개합니다.
    3. 중지해 저장한 뒤 녹음을 선택해 재생합니다.

    녹음, 재생, 변환된 텍스트 보기는 Premium 또는 Premium Plus 기능입니다. 30분마다 나누어 저장하며 노트당 최대 5개입니다. 홈 화면으로 가거나 다른 앱을 전체 화면으로 열거나 잠자기 상태가 되어 Uni:Note가 백그라운드로 이동하면 녹음이 자동으로 저장되고 중지됩니다. 앱 안에서 노트를 나갈 때는 저장하고 종료할지 확인합니다. 지원되는 iPadOS 26 기기에서는 녹음 중 문자 변환이 가능합니다. 언어는 설정 → 학습 지원 → 녹음 지원에서 고릅니다. AI 요약은 변환된 텍스트와 AI 잔액을 사용하므로 예상 사용량을 먼저 확인하세요.

    설정 → 학습 지원 → 녹음 지원의 문자 변환 정확도 우선을 켜면 정확도를, 끄면 속도를 우선합니다. 변경은 다음 녹음부터 적용됩니다.

    Uni:Note 4.0.0(2026년 10월 30일 공개 예정)의 내용입니다. 현재 공개 중인 3.8.3에서는 아직 사용할 수 없습니다.

    4.0.0을 새로 설치하면 문자 변환 정확도 우선은 꺼진 상태로 시작합니다.

    스티키 마커·메모지·문제집으로 복습하기

    팔레트에서 스티키 마커를 선택하고 한 번 더 탭해 상세 설정을 연 뒤 위쪽 전환에서 스티키 마커를 고릅니다. 숨길 부분을 Apple Pencil로 긋고 손가락으로 마커를 탭해 표시·숨김을 전환합니다. 삭제하려면 마커를 길게 누른 뒤 휴지통 버튼을 탭합니다.

    글을 쓸 수 있는 메모지를 쓰려면 상세 설정에서 메모지로 전환하고, 9가지 모양·크기와 4가지 색 중에서 고른 뒤 페이지를 탭해 붙이고 그 위에 씁니다. 위쪽 풀 부분을 드래그하면 이동하고, 풀 부분을 길게 누른 뒤 휴지통 버튼을 탭하면 삭제합니다. 메모지를 탭하면 반투명해져 아래 페이지를 볼 수 있습니다. 추가·이동·삭제는 실행 취소할 수 있으며, 붙인 뒤에는 크기와 각도를 바꿀 수 없습니다.

    내비게이션 바의 영역 선택 풀이를 탭하고 Apple Pencil로 문제를 둘러싼 뒤 범위를 확인하고 풀이를 요청합니다. 버튼 표시는 설정 → 표시 설정 → 노트 화면에서 바꿀 수 있습니다.

    결과를 다른 앱으로 보내려면 풀이 결과 오른쪽 위에서 복사 버튼(왼쪽) 또는 공유 버튼(오른쪽)을 탭합니다.

    기타 → 문제집 만들기에서 페이지를 고르고 후보를 추가·버린 뒤 저장합니다. 홈의 문제집에서 복습하세요. AI 풀이와 생성은 AI 잔액을 사용하며 결과는 수업 자료와 대조해 확인하세요.

    현재 공개 중인 3.8.3에서는: 카드를 탭해 답을 표시하고 이전·다음 버튼으로 이동합니다.

    Uni:Note 4.0.0(2026년 10월 30일 공개 예정)의 내용입니다. 현재 공개 중인 3.8.3에서는 아직 사용할 수 없습니다.

    문제집 화면의 + 메뉴에서 한 문제씩 만들기(손글씨 또는 키보드), 붙여넣기로 만들기, 파일에서 만들기(TSV/CSV, 최대 300문제, Premium 또는 Premium Plus)를 고를 수 있습니다. 학습할 때는 오른쪽 스와이프로 외웠어요, 왼쪽 스와이프로 못 외웠어요를 기록합니다. 한 바퀴가 끝나면 못 외웠어요 문제만 다시 풀거나 나중에 이어서 할 수 있습니다. 문제 옆에 원본 노트를 열 수 있습니다. 문제집은 과목별로 묶여 표시되며 ? 버튼에서 사용법을 확인할 수 있습니다.

    문제집은 AI 잔액을 쓰지 않고 수동으로 만들거나 편집할 수도 있습니다. 노트 상단의 포모도로로 집중·휴식을 시작하며, 집중·휴식 시간은 시작할 때 고릅니다. 자동 종료까지의 세트 수와 캐릭터는 학습 지원 설정에 있습니다. 레이저 포인터는 Apple Pencil의 일시적인 자취를 표시하며 필기로 저장하지 않습니다. 노트 버튼과 팔레트는 설정 → 표시 설정 → 노트 화면에서 배치할 수 있습니다.

    보호·삭제·복원

    노트를 길게 누르고 보호를 선택하면 쓰기를 막을 수 있고, 해제로 보호를 풉니다. 보호 해제 때 생체 인증을 요구하도록 설정할 수 있습니다.

    삭제한 과목과 노트는 홈의 휴지통에서 복원합니다. 폴더를 삭제해도 과목은 남습니다. 페이지, 문제집, 휴지통에서 완전히 삭제한 항목은 복원할 수 없습니다. 노트에 한 페이지만 남은 상태에서 그 페이지를 삭제하면, 페이지 자체는 남고 내용만 지워집니다.

    휴지통의 과목과 노트는 30일이 지난 뒤 정리할 때 완전히 삭제됩니다. 필요한 항목은 그 전에 복원하세요.

    플랜과 AI 잔액

    Free는 과목 10개, 과목당 노트 6권까지입니다. 일회성 Premium과 월간 Premium Plus는 이 제한을 해제하고 녹음과 간편 백업을 제공합니다. Premium은 매월 초 500 AI 잔액을, Premium Plus는 구독 기간마다 10,000 AI 잔액을 제공합니다. 기간 잔액은 다음 기간으로 이월되지 않으며 추가 구매분에는 만료일이 없습니다. AI 풀이·문제집 생성·요약은 어느 플랜에서나 AI 잔액을 사용합니다. 현재 플랜과 잔액, 가격은 설정에서 확인하고 구매가 반영되지 않으면 구매 상태 업데이트를 사용하세요.

    Uni:Note 4.0.0(2026년 10월 30일 공개 예정)의 내용입니다. 현재 공개 중인 3.8.3에서는 아직 사용할 수 없습니다.

    붙여넣기로 만들기나 파일에서 만들기로 문제집을 한꺼번에 만들려면 Premium 또는 Premium Plus가 필요합니다. 한 문제씩 만들기와 학습은 무료입니다.

    백업 보관하기

    1. 홈의 톱니바퀴에서 설정 → 백업을 엽니다.
    2. Pocket에서 녹음도 듣고 싶다면 내보내기 전에 녹음 오디오 포함을 켭니다.
    3. 백업을 내보내고 저장 위치를 고릅니다.

    간편 백업 업데이트·복원에는 Premium 또는 Premium Plus가 필요합니다. iCloud 파일을 저장·불러오며 자동 동기화는 아닙니다. Free에서도 zip 내보내기와 파일 복원을 사용할 수 있습니다. 복원은 확인 없이 바로 시작되며 현재 데이터를 대체하므로 먼저 현재 데이터를 내보내세요. 복원 후 안내에 따라 앱을 다시 여세요. 문제집도 백업에 포함됩니다. Uni:Note Pocket에서 불러오려면 Pocket을 최신 버전으로 업데이트하세요. 언어·왼손잡이 조작·과목 표기도 설정에서 바꿀 수 있습니다.

    iPad 창 두 개 사용하기

    iPad 창 조작으로 Uni:Note를 자료나 동영상 옆에 배치할 수 있습니다. Uni:Note 창 두 개도 열 수 있습니다.

    손가락으로 그리기 설정은 같은 기기의 모든 Uni:Note 창에서 공유됩니다. 한 창에서 변경하면 다른 창의 스크롤에 사용하는 손가락 수도 같이 바뀝니다.

    Dock 조작과 Split View·Slide Over 등의 이름은 iPadOS 버전과 창 설정에 따라 다릅니다.
