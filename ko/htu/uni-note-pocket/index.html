사용 방법 (Uni:Note Pocket)

Uni:Note Pocket 사용 방법
번역:
  • Ja
  • En
  • De
  • Zh-Hant
  • Fr

Uni:Note Pocket은 Uni:Note 백업을 iPhone에서 다시 보기 위한 보조 앱입니다.
글을 쓰는 앱이 아니라, 오른쪽 위의 가져오기 로 백업 데이터를 불러와 노트를 읽기 전용으로 확인하는 데 초점을 둡니다.

전제 조건:

  • iPhone 전용
  • Uni:Note에서 만든 백업 zip 필요
  • 편집이나 동기화가 아니라 열람과 암기 레이어 확인이 중심

1. 처음 안내를 확인하기#

처음 실행하면 Uni:Note Pocket 안내 가 표시됩니다.
여기서 Uni:Note Pocket이 Uni:Note의 보조 앱이며, 사용하려면 Uni:Note 백업이 필요하다는 점을 확인할 수 있습니다.

2. 가져오기에서 백업 선택하기#

오른쪽 위의 가져오기 에서 Uni:Note 백업 zip을 선택합니다.

  • zip 선택
  • 앱이 내용 검증
  • 문제가 없으면 가져오기 완료

아직 아무것도 가져오지 않았다면 백업을 가져와서 복습을 시작하세요 와 백업 선택 버튼이 표시됩니다.

3. 과목 목록과 최근 사용한 노트 보기#

가져온 뒤 메인 화면에서는 다음을 확인할 수 있습니다.

  • 상위 과목별 노트 수
  • 빠르게 다시 들어갈 수 있는 최근 사용한 노트

최상위 이름은 설정의 과목 이름 에 따라 달라집니다.

4. 노트를 열고 페이지 다시 보기#

과목을 열면 노트 목록으로 들어가 원하는 내용을 선택할 수 있습니다.

  • 노트 목록 열기
  • 노트 선택
  • 세로 연속 흐름으로 페이지 확인

Uni:Note Pocket은 읽기 전용이므로 노트 이름 변경이나 페이지 편집은 하지 않습니다.

5. 페이지 화면에서 확대해서 보기#

페이지 화면에서는 가져온 내용을 그대로 다시 볼 수 있습니다.

  • 핀치로 확대 / 축소
  • 더블탭으로 확대
  • 세로 스크롤로 페이지 이동

무거운 노트에서도 우선 안전하게 다시 보는 데 초점을 맞춘 구성입니다.

6. 암기 레이어 표시 / 숨기기#

오른쪽 눈 버튼으로 페이지 단위 암기 레이어를 전환합니다.

  • 암기 레이어 표시
  • 암기 레이어 숨기기

Uni:Note Pocket에서는 암기 마스크 자체를 편집하지 않습니다.

7. 설정 조정하기#

설정에서는 주로 다음 항목을 바꿀 수 있습니다.

  • 언어
  • 테마
  • 마지막 위치에서 다시 열기
  • 가로 흔들림 방지
  • 과목 이름

과목 이름 에서는 최상위 이름을 과목 / 노트 / 그룹 / 카테고리 중에서 고를 수 있습니다.

8. 더 새로운 백업 다시 가져오기#

Uni:Note에서 새 백업을 만든 뒤, Uni:Note Pocket에서도 다시 가져오기 를 실행합니다.

새 zip 검증이 성공한 경우에만 내용이 새 버전으로 바뀝니다.
검증에 실패하면 기존 데이터는 유지한 채 오류만 표시합니다.
