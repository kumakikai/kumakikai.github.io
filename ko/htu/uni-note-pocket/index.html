사용 방법 (Uni:Note Pocket)

Uni:Note Pocket은 Uni:Note 백업을 iPhone에서 다시 보기 위한 보조 앱입니다.
글을 쓰는 앱이 아니라, 백업 데이터를 불러와 노트와 문제집은 읽기 전용으로 확인하고 녹음 데이터는 재생하는 데 초점을 둡니다.

전제 조건:

  • iPhone 전용
  • Uni:Note에서 만든 백업 zip 또는 이 iPhone에 있는 간편 백업 필요
  • 편집이나 동기화가 아니라 열람과 복습이 중심

1. 처음 안내를 확인합니다

처음 실행하면 Uni:Note Pocket 안내가 표시됩니다.
여기서 Uni:Note Pocket이 Uni:Note의 보조 앱이며, 사용하려면 Uni:Note 백업이 필요하다는 점을 확인할 수 있습니다.

2. 홈 화면 오른쪽 아래의 가져오기 아이콘에서 백업을 선택합니다

홈 화면 오른쪽 아래의 가져오기 아이콘에서 Uni:Note 백업 zip을 선택합니다.

  • zip 선택
  • 앱이 내용 검증
  • 문제가 없으면 가져오기 완료

3. 간편 백업을 사용합니다

이 iPhone에 Uni:Note의 간편 백업이 있으면, 앱이 바로 불러올지 안내할 수 있습니다.

설정 > 간편 백업에서는 다음을 확인할 수 있습니다.

  • 마지막 업데이트
  • 실행 시 자동 불러오기
  • 수동으로 불러오기

실행 시 자동 불러오기를 켜면, 사용할 수 있는 Uni:Note 간편 백업이 있을 때만 실행 시 자동으로 불러옵니다.

4. 홈에서 노트와 문제집을 전환합니다

가져온 뒤 메인 화면에서는 다음을 확인할 수 있습니다.

  • 노트 / 문제집 전환
  • 최상위 목록과 노트 수
  • 빠르게 다시 들어갈 수 있는 최근 사용한 노트
  • 가져온 백업에 포함되어 있으면 문제집
  • 녹음 데이터나 스티커 마커가 있는 노트의 표시

최상위 이름은 설정의 과목 이름에 따라 달라집니다.

5. 노트를 열고 페이지를 봅니다

최상위 항목을 열면 노트 목록으로 들어가 원하는 내용을 선택할 수 있습니다.

  • 노트 목록 열기
  • 노트 선택
  • 세로 연속 흐름으로 페이지 확인
  • 녹음 데이터가 있는 노트에서는 페이지 화면에서 녹음 재생

Uni:Note Pocket은 읽기 전용이므로 노트 이름 변경이나 페이지 편집은 하지 않습니다.

6. 페이지 화면에서 확대해서 봅니다

페이지 화면에서는 가져온 내용을 그대로 다시 볼 수 있습니다.

  • 핀치로 확대 / 축소
  • 더블탭으로 확대
  • 세로 스크롤로 페이지 이동

7. 녹음을 재생합니다

백업에 녹음 음성이 포함되어 있으면, 녹음 데이터가 있는 노트의 페이지 화면에 녹음 버튼이 표시됩니다.

  • 녹음 재생에서 재생합니다
  • 녹음이 여러 개 있으면 녹음에서 선택합니다
  • 재생 / 일시 정지, 정지, 재생 위치, 재생 속도를 조작합니다

Uni:Note Pocket에서는 녹음 재생만 할 수 있습니다. 녹음 생성, 편집, 문자 변환, AI 요약은 Uni:Note에서 진행합니다. 백업에 녹음 음성이 포함되어 있지 않으면 재생할 수 없습니다.

8. 문제집을 복습합니다

가져온 백업에 Uni:Note에서 저장한 문제집이 포함되어 있으면, 홈의 문제집에서 열 수 있습니다.

  • 저장된 문제와 답을 다시 확인합니다
  • 저장된 세트를 한곳에서 이어서 봅니다
  • 새로 만들거나 수정하는 작업은 Uni:Note에서 진행합니다

9. 스티커 마커를 확인합니다

노트 목록에서는 스티커 마커가 있는 노트에 표시가 나타납니다. 페이지를 열면 Uni:Note v3.0.0의 스티커 마커 표시 방식에 맞춰 페이지 위에 표시됩니다.

  • 마커를 탭해 일반 표시 / 흐린 표시를 전환합니다
  • 이전 백업의 암기 마스크는 노트를 열 때 스티커 마커로 자동 변환됩니다

Uni:Note Pocket에서는 스티커 마커나 암기 마스크 자체를 편집하지 않습니다.

10. 설정을 조정합니다

설정에서는 주로 다음 항목을 바꿀 수 있습니다.

  • 언어
  • 테마
  • 마지막 위치에서 다시 열기
  • 가로 흔들림 방지
  • 과목 이름
  • 간편 백업

과목 이름에서는 최상위 이름을 과목 / 노트 / 그룹 / 카테고리 중에서 고를 수 있습니다.

11. 더 새로운 백업을 다시 읽습니다

Uni:Note에서 새 백업을 만든 뒤, Uni:Note Pocket에서도 홈 화면 오른쪽 아래의 가져오기 아이콘으로 다시 불러옵니다.
간편 백업을 사용 중이라면 설정 > 간편 백업 > 수동으로 불러오기로도 읽어올 수 있습니다.

새 zip 검증이 성공한 경우에만 내용이 새 버전으로 바뀝니다.
검증에 실패하면 기존 데이터는 유지한 채 오류만 표시합니다.
