Mode d’emploi (Uni:Note Pocket)

Uni:Note Pocket est une application compagnon pour relire les sauvegardes Uni:Note sur iPhone. Ce n’est pas une application d’ecriture. Son role est de charger des sauvegardes et de vous laisser relire les notes et les Lots en lecture seule. Pre-requis : iPhone uniquement un fichier zip de sauvegarde cree dans Uni:Note usage centre sur la consultation et la relecture, pas sur l’edition ni la synchronisation La version actuellement disponible sur l’App Store est v1.1.0. ...

Mode d’emploi (Uni:Note)

Uni:Note est une application iPad concue pour l’ecriture manuscrite avec l’Apple Pencil. Vous pouvez separer vos contenus par matiere et organiser chaque cours dans une note distincte. Environnement pris en charge : iPad uniquement ecriture manuscrite pensee pour l’Apple Pencil le doigt sert surtout au defilement et au deplacement des photos 1.
