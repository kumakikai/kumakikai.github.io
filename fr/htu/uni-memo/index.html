Guide d’utilisation (Uni:Memo)

Comment utiliser Uni:Memo.
Traductions:
  • Ja
  • En
  • Ko
  • De
  • Zh-Hant

Uni:Memo est une application compagnon en lecture seule pour relire les sauvegardes Uni:Note sur iPhone.
Ce n’est pas une application d’écriture. Son rôle est d’importer des sauvegardes et de permettre une relecture sûre des notes.

Pré-requis :

  • iPhone uniquement
  • un fichier zip de sauvegarde créé dans Uni:Note
  • conçu pour la consultation et les calques de mémorisation, pas pour l’édition ni la synchronisation

1. Préparer une sauvegarde dans Uni:Note#

Commencez par créer un fichier de sauvegarde dans Uni:Note, puis enregistrez-le dans un emplacement accessible depuis l’app Fichiers.

Uni:Memo ne peut pas créer de notes par lui-même. Le contenu à consulter doit déjà être inclus dans la sauvegarde Uni:Note.

2. Importer la sauvegarde#

Sur l’écran principal, choisissez Importer, puis sélectionnez un zip de sauvegarde Uni:Note.

  • choisir le zip
  • laisser l’application vérifier son contenu
  • charger le snapshot si tout est valide

Les sauvegardes endommagées ou invalides sont arrêtées de manière sûre.

3. Vérifier l’étagère#

Après l’import, l’étagère affiche vos groupes de notes du niveau supérieur.

  • résumés du nombre de notes et de pages
  • raccourcis vers les notes récemment consultées

Si rien n’a encore été importé, Uni:Memo affiche d’abord l’invitation à importer.

4. Ouvrir des notes et des pages#

Ouvrez une catégorie depuis l’étagère, puis parcourez les notes et les sections jusqu’à la page voulue.

  • ouvrir la liste des notes
  • choisir la note souhaitée
  • consulter les pages dans un flux vertical continu

Uni:Memo est en lecture seule et ne renomme donc pas les notes ni ne modifie les pages.

5. Relire les pages#

Dans l’écran de page, vous pouvez vous concentrer sur la lecture du contenu importé.

  • pincer pour zoomer ou dézoomer
  • double appui pour zoomer
  • défilement vertical pour changer de page

L’application privilégie une relecture sûre et simple, même pour des notes plus lourdes.

6. Afficher ou masquer les calques de mémorisation#

Utilisez le bouton en forme d’œil à droite pour afficher ou masquer le calque de mémorisation de la page.

  • masquer pour tester votre mémoire
  • réafficher pour vérifier

Uni:Memo ne modifie pas le masque de mémorisation lui-même.

7. Ajuster les réglages#

Dans Réglages, vous pouvez principalement modifier :

  • Langue
  • Thème
  • Reprendre au dernier emplacement
  • Limiter le décalage horizontal
  • Nom du niveau supérieur

Adaptez-les à votre manière de relire vos notes.

8. Remplacer par une sauvegarde plus récente#

Lorsque vous créez une sauvegarde plus récente dans Uni:Note, relancez Importer dans Uni:Memo.

L’application ne bascule vers la nouvelle version qu’après validation du nouveau zip.
