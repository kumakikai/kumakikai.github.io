GigaPoke

iPhone

Vos bonus de données.À utiliser avant expiration.

Classez vos codes de récompense povo 2.0 par date d’expiration et copiez celui dont vous avez besoin. Un widget vous indique aussi la prochaine récompense de données à utiliser.

Disponibilité
  • 🇯🇵

App non officielle d’aide à la gestion des récompenses povo 2.0. Elle n’est ni affiliée, ni parrainée, ni agréée par KDDI Corporation, povo ou au, et n’entretient aucun autre lien avec eux.

Les captures montrent la version japonaise.

Du code reçu à son utilisation.

Regroupez les codes enregistrés et leurs échéances au lieu de rechercher vos e-mails de récompenses povo 2.0. Vous pouvez aussi organiser les codes de coupons externes et les URL de retrait.

Partager depuis un e-mail, enregistrer, choisir un code proche de son échéance puis le copier : GigaPoke est une application iPhone non officielle conçue autour de ce parcours.

Fonctions principales

  • Enregistrer depuis un e-mail

    Partagez ou collez le texte contenant le nom de la récompense, le code et l’échéance. Vérifiez les informations avant de les enregistrer. La saisie manuelle est aussi possible.

  • Choisir selon l’échéance

    Dans chaque catégorie, les récompenses qui expirent bientôt apparaissent en premier. Des notifications peuvent être programmées avant l’échéance.

  • Copier, puis ouvrir povo 2.0

    Un réglage permet d’ouvrir povo 2.0 après la copie du code. Le collage et l’utilisation du code se font dans povo 2.0.

  • Consulter un widget d’accueil

    Affichez la récompense et les jours restants d’un code de données sur l’écran d’accueil, puis accédez à l’action de copie.

Codes et échéances dans une même liste

L’accueil regroupe les informations des récompenses et leurs dates, avec les actions pour coller une nouvelle entrée ou utiliser un code.

Le prochain code sur l’écran d’accueil

Les widgets petit et moyen montrent les codes de données proches de leur échéance. Un bouton ouvre GigaPoke pour copier le code.

Pour quels usages ?

  • Organiser les e-mails de récompenses

    Gardez les codes et échéances utiles sans devoir retrouver l’e-mail d’origine à chaque fois.

  • Utiliser d’abord ce qui expire bientôt

    Si vous avez plusieurs codes ou récompenses externes, choisissez le prochain selon sa date limite.

  • Vérifier depuis l’écran d’accueil

    Consultez les détails et les jours restants dans un widget avant d’ouvrir l’application.
