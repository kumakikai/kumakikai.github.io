よくある質問 (すわなび)

基本#

すわなびはどんなアプリですか？#

喫煙 と 我慢 をすばやく記録し、本数や金額をあとから確認するためのアプリです。禁煙補助としても、単純な記録ツールとしても使えます。

「我慢」は何を記録しますか？#

「吸いたいと思ったが吸わずに済んだ1回」を記録します。

医療アプリですか？#

いいえ。医療行為や治療を提供するアプリではありません。

初回チュートリアルはありますか？#

はい。初回起動時にチュートリアルと初期設定があります。

記録と振り返り#

何を確認できますか？#

当日の件数、節約額、前回記録からの経過時間、日別 / 月別 / 年別の一覧、週 / 月 / 3か月のグラフを確認できます。

金額はどう計算されますか？#

1箱の本数 と 1箱の金額 から1本あたりの金額を計算し、喫煙本数や我慢回数を金額換算しています。

間違って削除した記録は戻せますか？#

削除直後であれば 取消し で元に戻せます。

過去日の記録もできますか？#

いいえ。現時点では当日分の記録に対応しています。

データと保存#

データはどこに保存されますか？#

記録と設定は端末内に保存されます。

バックアップやクラウド同期はありますか？#

現時点ではありません。

アカウント登録は必要ですか？#

不要です。ログインや会員登録なしで使えます。

機能#

ホームウィジェットは使えますか？#

はい。当日の 喫煙 / 我慢 件数を表示し、記録導線を開けるホームウィジェットに対応しています。

広告はどこに表示されますか？#

記録 画面にバナー広告が表示されます。 また、カレンダー / グラフ を開いたタイミングで、週に1回だけ全画面広告が表示されます。

広告を消せますか？#

はい。広告削除の買い切り購入を利用できます。購入復元にも対応しています。

言語や通貨は変更できますか？#

はい。設定から変更できます。
