よくある質問 (ギャンカレ)

基本#

ギャンカレはどんなアプリですか？#

収入 / 支出 を短い操作で記録し、あとから 日別 / 月別 / カテゴリ別 で振り返るためのアプリです。

ギャンブル以外の用途でも使えますか？#

はい。初回起動時に ギャンブル、家計簿、推し活貯金、おこづかい帳 から用途に合う初期タグを選べます。タグ名やアイコンもあとから変更できます。

過去日の記録はできますか？#

はい。日付を変更して過去日の記録や修正ができます。未来日は選べません。

間違って削除した記録は戻せますか？#

削除直後であれば 取消し で元に戻せます。

振り返りと設定#

何を確認できますか？#

日別、月別、カテゴリ別 で収支を確認できます。全期間累計から通算の振り返りもできます。

折れ線グラフや予測、アドバイスはありますか？#

ありません。数字を並べて確認する設計です。

タグはいくつまで使えますか？#

初期状態では4つです。タグ拡張を利用すると最大12まで増やせます。

アプリロックはありますか？#

はい。追加購入でアプリロックを利用できます。パスコードロックに対応しており、利用環境によっては Face ID での解除も使えます。

ホームウィジェットは使えますか？#

はい。ホーム画面から 収入 / 支出 をすぐ記録できます。ウィジェット用のデフォルトタグも設定できます。

言語や通貨は変更できますか？#

はい。言語は 日本語 と 英語、通貨は複数の候補から設定できます。

課金と保存#

広告はどこに表示されますか？#

登録 画面にバナー広告が表示されます。 また、収支 画面を開いたタイミングで、週に1回だけ全画面広告が表示されます。

広告を消せますか？#

はい。アプリ内購入で無効にできます。購入復元にも対応しています。

バックアップや自動同期、データのエクスポートはありますか？#

現時点ではありません。
