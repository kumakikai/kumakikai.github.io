Uni:Note Pocket/FAQ

FAQ (Uni:Note Pocket)

Basics

What kind of app is Uni:Note Pocket?

Uni:Note Pocket is a companion app for the iPad app Uni:Note.
It lets you load backup data created in Uni:Note, review notes, pages, and Question Sets on iPhone, and play recording audio.

Can I use Uni:Note Pocket by itself?

No.
You need a backup file created in Uni:Note.

Which devices are supported?

iPhone only.

Do I need to log in or create an account?

No.

Import and backups

What should I do first?

Use the import icon in the bottom right of Home and choose a backup from Uni:Note.
If this iPhone already has a Uni:Note Easy Backup, the app may also ask whether you want to load it right away.

What can I import?

You can import:

  • backup zip files created in Uni:Note
  • Uni:Note Easy Backup found on this iPhone

Uni:Note v3.0.0 backups are supported.

Does importing change the original backup file?

No.
The selected zip is validated and expanded inside the app, so the original file is not modified.

What happens if import fails?

Damaged or invalid backups are stopped safely.
If you already have imported data, the app keeps it and shows Import Failed instead of replacing it with broken data.

Is automatic sync available?

Not at this time.
Uni:Note Pocket is designed around reviewing backup data.

What is Auto Load on Launch?

It is an option in Settings > Easy Backup.
When enabled, the app loads automatically on launch only when a usable Uni:Note Easy Backup is available on this iPhone.

What is Load Manually?

It is the action in Settings > Easy Backup > Load Manually.
Use it to load the Uni:Note Easy Backup currently detected on this iPhone.

Viewing

What can I do after import?

The main functions are:

  • switch between Notes / Question Sets on Home
  • resume from Recent Notes
  • browse top-level subjects
  • view pages
  • play recordings when the backup includes recording audio
  • check sticky markers

Can I edit notes or pages?

No.
Uni:Note Pocket is read-only.

Can I create, delete, or reorder notes?

No.
Creation and editing are meant to stay in Uni:Note.

Can I review Question Sets?

Yes.
If the imported backup includes Question Sets saved in Uni:Note, you can open them from Question Sets on Home.

Can I play recordings?

Yes. If the imported backup includes recording audio, you can play it from the page view for notes that have recordings. When multiple recordings are available, you can choose which one to play.

What if the backup does not include recording audio?

Recordings cannot be played when the backup does not include the audio files. In that case, the app shows This backup does not include the recording audio.

Can Uni:Note Pocket record, transcribe, or create AI summaries?

No. Uni:Note Pocket is playback-only for recordings. Recording creation, editing, transcription, and AI summaries stay on the Uni:Note side.

Can I view sticky markers?

Yes. Notes with sticky markers show an indicator, and the markers are shown on the page. Tap a marker on the page to switch between normal and faint display.

Uni:Note Pocket does not edit sticky markers or the memorization mask itself.

Can I zoom pages?

Yes.
You can zoom with pinch gestures or a double tap.

Can I resume from the last place I was reading?

Yes.
You can turn that behavior on or off in Resume Last Location.

Settings

What settings are available?

The main settings are:

  • Language
  • Theme
  • Resume Last Location
  • Prevent Horizontal Drift
  • Subject Name
  • Easy Backup

What does Subject Name change?

It changes the top-level label to Subject / Note / Group / Category.

Are there pages for how to use and privacy policy?

Yes.
Inside the app, you can also open it from Settings > Support > How to Use.
