How to Use (Uni:Note Pocket)

How to use Uni:Note Pocket.
Translations:
  • Ja
  • Ko
  • De
  • Zh-Hant
  • Fr

Uni:Note Pocket is a companion app for reviewing Uni:Note backups on iPhone.
It is not a writing app. Its job is to load backup data from Import in the top right and let you review notes in read-only mode.

Requirements:

  • iPhone only
  • a backup zip created in Uni:Note
  • focused on viewing and memorization layers, not editing or sync

1. Read the first companion notice#

On first launch, the app shows About Uni:Note Pocket.
This notice explains that Uni:Note Pocket is a companion app for Uni:Note and that you need a backup from Uni:Note before you can use it.

2. Choose a backup from Import#

Use Import in the top right and select a backup zip from Uni:Note.

  • choose the zip
  • let the app validate its contents
  • finish the import if it is valid

If nothing has been imported yet, the app shows Import a backup to start reviewing with a Choose Backup button.

3. Check subjects and Recent Notes#

After import, the main screen shows:

  • top-level subjects with note counts
  • a Recent Notes section for quick resume

The top-level label changes according to Subject Name in Settings.

4. Open Notes and review pages#

When you open a subject, you can move into the Notes list and choose what to review.

  • open the note list
  • choose a note
  • review pages in a continuous vertical flow

Uni:Note Pocket is read-only, so it does not rename notes or edit pages.

5. Zoom and read in the page view#

In the page view, you can focus on reading the imported content.

  • pinch to zoom in or out
  • double tap to zoom
  • move through pages with vertical scrolling

The app is designed to keep review simple and safe even for heavier notes.

6. Show or hide the memorization layer#

Use the eye button on the right side to switch the page-level memorization layer.

  • Show Memorization Layer
  • Hide Memorization Layer

Uni:Note Pocket does not edit the memorization mask itself.

7. Adjust Settings#

In Settings, you can mainly change:

  • Language
  • Theme
  • Resume Last Location
  • Prevent Horizontal Drift
  • Subject Name

Subject Name lets you rename the top-level label to Subject / Note / Group / Category.

8. Import a newer backup later#

When you create a newer backup in Uni:Note, run Import again in Uni:Note Pocket.

The app switches only after the new zip passes validation.
If validation fails, the previous imported data stays in place and the app shows an error.
