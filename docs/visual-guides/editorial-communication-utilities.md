# 日本語ガイドの画像・文章対応の目視レビュー

確認日: 2026-09-07。対象: production buildを配信する `http://127.0.0.1:1314`。独立した一時プロファイルの実Google ChromeをPlaywrightから操作。各ページをスクロールし、1440×1000 / 390×1000、deviceScaleFactor 1、Light表示で確認。

各画像の約180px手前までスクロールした通常のviewport screenshotを保存し、その画像と前後の本文を読んだ。全ページを1枚へ縮小した画像による合否判定はしていない。モバイルは390pxの画像を縮小せず横に3枚並べた閲覧用シートでも読み比べた。サイト本文・CSS・素材には、このレビュー中の変更を加えていない。

### オトミル

- テレビ・会話・グループは縦に3個すべて入り、モバイルでもラベルを大きく読める。操作順の1、2の直後にある。
- 通常モードは上部タブ/歯車と下部の開始ボタンを2枚に分離。説明の「上部」「下部」と対応し、無関係な空白を挟んだフル画面より位置が分かる。
- 字幕例は終了と反転の位置まで保持。文字例とボタンの役割は読み取れる。字幕例自身の折り返しはアプリが描画したもの。
- 表示設定はプレビュー、文字サイズ、シンプルモード、テーマが欠けず入る。周囲の環境は選択項目と説明を含む。
- 残り15分、5分追加、Plusの3要素を読め、前後の利用時間説明と対応。過剰な画像横幅や横スクロールを認めない。

### ギガポケ

- ホーム上部とペーストボタンを1枚に収め、次の確認フォームで登録までの流れが分かる。コードはDEMOと明示され、実ユーザー情報はない。
- 期限行には特典名、コード、期限、利用ボタンが入る。モバイルでも主要操作名と期限表示を読める。
- ゴミ箱は全体削除と各特典削除の位置関係を保持。通知設定と整理設定も該当ラベル・現在値・スイッチまで入り、crop境界で欠けていない。
- 下記 E1 のみ、本文と画面種類の接続を1文補うとよい。画像追加・crop変更は不要。

### Nocca

- 役割の説明と実画面の本人/家族が一致。招待はコピーと共有を含む全画面を320pxで表示し、承認が必要という本文とデモコードのキャプションが読める。
- 意思表示は3アイコンを適切にcrop。送信結果は返信と取り消し操作を保持。家族の返信は「対応」「完了」の区分まで含み、本文の例と一致。
- 会話は上の「閉じる」から下の入力まで位置関係を保持。通信休止は赤ボタンと説明を保持。
- 画像と文が前後しない。長い画面も適切な最大幅で、画像を読むための横スクロールは不要。

### すわなび

- 緑/赤アイコンと当日の回数をcropで明確に読める。3手順の直後に表示。
- 履歴は時刻・アイコンの3行を保持。左スワイプの対象を判別できる。
- カレンダーは切替・日付行・本数と金額が入る。グラフは期間切替、推移、凡例、下部ナビまで保持し、凡例が切れていない。
- 設定は銘柄と本数/価格、追加購入の項目を保持。本文の通常1銘柄/購入後4銘柄と画像の表記が一致。
- Watchは「対応版1.2.0は審査中」の注記が機能説明の前にある。購入条件とwatchOS条件、記録・当日件数・同期の順序が読める。Desktopは画像と4手順の2列、Mobileは画像の後に手順が続く。

## 指摘

### E1: ギガポケの特典詳細画像へ至る経路を1文補う（軽微）

`特典を使う`の本文は「特典の右側にあるボタン」を説明する一方、直下の`benefit-actions`画像は特典詳細画面の下部アクション。直前の期限セクションには正しい一覧行画像があるため、両者を混同しないよう「特典名を開いた詳細画面からも『povo 2.0で使う』を選べます」などの1文を画像直前へ置くと対応が明確になる。rootへ報告済み。画像を増やす必要はない。

### E2: 操作用語の前後に可視バッククォート（軽微・共通CSS）

本文中のinline codeにTypography由来と考えられるバッククォートが表示される。たとえばオトミルの開始ボタン名、Noccaの設定経路、すわなびの見出し。内容の誤りやレイアウト崩れではないが、一般ユーザー向け操作説明には不要な記号。`code::before/after`の生成contentを無効化する程度の共通変更で改善可能。rootへ報告済み。

## 判定の範囲

画像の可読性、crop範囲、本文との対応と順序、Lightでの2viewportに重大な表示問題は見つからない。上記2点の軽微な改善候補を記録した。画像を開いて拡大できる導線もあり、細かい補助文字を確認できる。

このレビューは実ブラウザ表示の確認であり、実機のアプリ動作・App Store公開承認・Dark/WebKitの検証結果を代用しない。これらは親タスクの別の証跡を参照。後続修正があれば対象箇所の再撮影結果を追記する。

## 最終版での指摘解消確認 (2026-09-07)

親タスクによる E1/E2 修正後、production build を同じ `http://127.0.0.1:1314` から新しいChrome一時コンテキストで読み込み、1440×1000 / 390×1000で再撮影・目視した。

- **E1 解消**: ギガポケの画像直前に「特典名をタップして開く詳細画面からも、povo 2.0で使うなどの操作を選べます。」が入り、一覧右側ボタンと詳細画面の区別がつく。2幅とも短い説明の直後に対象画像があり、追加画像・余分な遷移はない。
- **E2 解消**: オトミルの「字幕をはじめる」「戻す / 反転」、すわなびの「履歴」「カレンダー」見出し、ギガポケの利用ボタン名を両幅で読み、不要なバッククォートが消えたことを確認。対象ページの全inline codeについて、`::before/::after`の生成contentがnone相当であることも確認した。
- ギガポケ`benefit-actions`、オトミル`mode-and-settings`、すわなび`history`の各1440/390、計6 viewport画像を最終版で上書き。再確認の計測記録は `editorial-communication-utilities-recheck.json`。
- 最終判定: **E1/E2とも解消、このレビューの未解決指摘なし**。本文・CSS・アプリ画像のfreezeを維持し、監査文書とスクリーンショットだけを更新した。
