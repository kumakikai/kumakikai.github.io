監査日: 2026-09-26。サイト上ではユーザー指定により3.7.0を現行版として扱う。アプリの配布審査結果を確認した記録ではない。

- アプリ: `uni_note` の `MARKETING_VERSION = 3.7.0`、`docs/FEATURE_SUBSCRIPTION.md`、`FEATURE_NOTE_EDITOR.md`、`FEATURE_SHAPE_TOOL.md`、`FEATURE_RULER.md`、`FEATURE_RECORDING.md`、画面・課金の実装を確認。仕様書だけで公開機能と断定しない。
- 既存のURL、25旧ガイドアンカー、6機能カード構成、サポート導線、ページの訴求軸は維持する。

## A・C: 古い記述、意味が変わった記述

| 対象 | 差分と処置 |
| --- | --- |
| 課金 | 「Premiumのみ／買い切りだけ」の前提を、Free・買い切りPremium・月額Premium Plusへ更新。録音・かんたんバックアップは両有料プラン。変動価格は記載せずアプリ内確認へ誘導。 |
| AI | 囲って解答、問題集生成、AI要約はそれぞれAI残量を消費。Premiumの月初500、Premium Plusの加入・更新期間ごと10,000、期間分の繰越なし、追加購入分の期限なしを区別。無制限とは書かない。 |
| 指で描画・素材 | ON時の旧「長押し → 移動・サイズ変更」を削除。「編集 → 素材選択中 → タップ」と終了操作へ更新。OFF時は固定中の素材の解除操作を明記。Apple Pencil筆記はON/OFF両方で使える。 |
| 回転 | PDF・書類画像・図形・定規の旧タップ90度／2本指操作を、明示されたハンドルの1本指円運動へ更新。通常写真とテキスト画像の回転は掲載しない。 |
| 文字起こし | iPadOS 26以降の対応端末・言語・音声モデル条件を明記。新しい「文字起こしの精度を優先」のON/OFFと次の録音から反映される条件を使い方へ追加。 |
| バックアップ | かんたんバックアップとFreeでも使えるzip書き出し／ファイル復元を区別し、自動同期とは書かない。 |

## D: ページ間整合と画像判断

Product・日本語詳細ガイド・5言語の概要ガイド・FAQの課金、AI残量、素材選択、録音条件を同じ仕様へ揃えた。FAQは操作の重複説明を増やさず、利用条件と誤解しやすい例外へ集中させた。法務上の「買い切りのみ」も修正した。Newsと過去のPress Releaseは公開時点の記録なので改稿しない。

既存の3.5撮影画像を点検した。PDFの選択枠など、現在も同じ目的で読める画像は保持する。3.7の自動テスト画像には仮の教材・テスト用ノート名が写っており、公式Guide素材の条件を満たさないため転用しない。回転ハンドルなど画像で補えない新操作は本文に具体的な位置と操作を記載した。今回、新たなSimulator撮影・画像差し替えは行わない。

## 検証境界

ローカル生成HTMLと静的リンク・画像・SEO・本文レビューを検証する。実機Apple Pencil、実App Store価格・公開状態、本番の購入／AI付与や端末ごとの音声認識をこの監査だけで実測したとは扱わない。
