# Uni:Note 年齢制限対応の確定記録

決定・確認日: 2026-09-08。決定者: 運営者。

**対応状況: 完了（プロジェクト判断）。本件はリリース／公開ブロッカーとしない。**

## 確認できた事実

- [Gemini API追加規約](https://ai.google.dev/gemini-api/terms)には、18歳未満を対象とする、または18歳未満がアクセスする可能性が高いAPIクライアントでの使用に関する制限がある。
- GoogleがApp Storeの18+指定のみをもって当該条件を満たすと明示した個別の公式記載は確認できていない。Googleによる適合保証を確認済みとは記録しない。
- 運営者は、本会話でApp Store Connectの「アプリ情報 > 年齢制限指定」における開発者による指定を、次のとおり変更済みと確認した。設定変更の完了はこの運営者確認を根拠とし、監査担当による管理画面の独立確認とは区別する。

| 国・地域 | 変更済みの年齢制限指定 |
| --- | --- |
| 173か国・地域 | 18+ |
| ブラジル | A18 |
| 大韓民国 | 19+ |

## 確定したプロジェクト判断

1. Uni:Noteは18歳以上を対象とするアプリとして運営する。
2. App Store Connect上の年齢制限指定の変更を、本プロジェクトにおける年齢制限対応として採用する。対応は完了とする。
3. アプリ内に追加の年齢確認、生年月日入力、年齢ゲート、本人確認、身分証確認、顔認証等は実装しない。Googleが要求していない追加の本人確認方式を要件として推定しない。
4. Gemini APIは継続利用する。
5. 親の端末を18歳未満が使用する、年齢を偽る等、開発者が合理的に防止できない利用まで技術的に完全排除することは要件としない。
6. Googleの明示的な保証が確認できていない点は、既知の規約解釈上の留保事項として記録する。本件をリリース／公開ブロッカー、未解決課題、追加実装必須、Gemini移行必須とは扱わない。追加の適合性調査や代替AIの検討を今回の公開条件にしない。
