## 保持すべき合理的な差

- **Nocca**は端末だけに保存するアプリではなく、家族通信・認証・購入・招待・引き継ぎの情報を扱う。Privacyの期間表、削除対象時刻と実消去の差、バックアップ、固定日数で消さない照合情報、本人/家族別の削除範囲を、章数合わせのために短縮しない。問い合わせは対応完了後1年以内という固有期間があるため、privacyInquiriesを重ねる必要はない。
- **Uni:Note**は購入確認/AI残量・AWS/Gemini・Apple音声認識・Crashlyticsを区別している。診断で送信しない情報はAI送信の例外否定ではない、と対象を明示している。
- **Pocket**は閲覧用取り込みとiCloudバックアップ読込があり、元zipの書換えやiPadへの書戻しと区別。利用状況解析、AI新規生成、IAPを持つ製品として扱わない。
- **オトミル**は端末内音声認識と字幕の一時表示、広告/Apple購入を分ける。Plusは自動更新、無料利用枠は製品固有。無音声送信の説明を広告や購入を含む全通信の否定へ拡張しない。
- **GigaPoke**は秘密性のあるコード/URL、元メールの非保存、バックアップ除外、利用者の選ぶ標準共有/外部サービス、ゴミ箱の期間を保持。無料なので有料機能の章は設けない。
- **Smokeless**は広告削除/銘柄パックの買い切りと未公開Watchを区別。**ギャンカレ**は収支・タグ・PIN・買い切りが固有。2製品とも独自Crashlyticsがなくても広告SDKに診断処理がある点を記載している。
- **SIGNAL**は取得先への通信、端末内の閲覧傾向、記事サイト側のCookie/広告等を区別。学習リセットが全キャッシュや外部サイト情報の削除ではない点を残す。

## 内部技術と用語

GitHub Pages、Privacy Manifest、Extension、Deep Link等の内部事情は、法務の表示本文から除かれている。旧IDの互換アンカーに残る過去の見出しは表示本文とは区別した。

AWS/Apple/Google、認証用情報、通知用トークン、識別情報のハッシュ等は、実際の情報処理先・保持対象・削除例外を説明するために残っている。これらまで一律削除するのは不適切。SDKという単語自体は一部の広告/解析の説明に残るが、アプリ開発の手順やサイトホスティングの紹介にはなっていない。

日本語で1か所、Pocket Privacyのバックアップ節に「開発者がその内容を取得することはありません」が残っていた。共通呼称の「当方」へ揃え、任意の問い合わせ提供を否定しない「当方がバックアップ内容を自動取得することはありません」等に限定することを親担当へ報告した。他製品の本文は今回のクロスレビューでは変更していない。
