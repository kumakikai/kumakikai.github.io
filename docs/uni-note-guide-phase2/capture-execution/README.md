## 残件と理由

- **040／再撮影**：拡大後の写真は撮れたが、台帳が求める選択枠のある状態ではなく固定後。再起動・ページ再選択・ダブルタップを再試行したが、選択枠を確認できず採用しない。画像を捨てず候補として保存。拡大自体はSimulatorで成功している。
- **058／実機**：レーザーONと実タッチのドラッグを試したが軌跡にならず、実装もApple Pencilタイプの入力限定（Drawing/LaserPointerOverlayView.swift:160,175,202）。通常筆跡の補助手段ではレーザーを偽装しない。
- **043/044/045/047／外部環境**：音声認識許可後もSimulatorの文字起こし利用不可、録音保存は「音声なし」。録音・再生・追従の有効データを取得できない。
- **048/049/050/051／外部環境**：有効な録音文字起こしがなく、AI endpointも未設定。実要約、保存済み再表示、ノートへの貼付結果がない。
- **062/066/067/073／外部環境**：問題集生成の実行で「AI endpoint is not configured.」。実解答・AI問題候補・保存・AI問題の手修正を得られない。手動問題集の070をAI生成レシピの画像へ転用していない。
- **078／外部環境**：撮影用SimulatorのiCloud未接続。FilesのZIPバックアップ保存・復元選択は079/080で取得済み。

ID別の目的・具体的理由・完了条件は[全86原本の分類](final-disposition.md)と[capture-status.json](capture-status.json)。仕様HOLDを勝手に解除したものはない。064/065は生成前UIのみでAI生成成功の証拠ではない。035/036は実際の選択／拡縮結果で、本文のすべてのジェスチャを実証したものではない。
