# 使い方・サポート導線整理

2026-09-19の明示指示に基づく、Phase 2後の情報設計変更である。

- `/htu/uni-note/` は、最低限の説明、検索、「機能から探す」だけを表示する。
- FAQ・お問い合わせ・プライバシーポリシー・利用規約は、親のUni:Note「使い方とサポート」導線の責務とする。使い方本文に重複リンクは設けない。
- 各カテゴリ完全ガイドと独立レシピから、記事末尾の回遊用リンク一覧を削除する。操作文中で必要な参照リンクは残す。
- 旧 `/htu/uni-note/troubleshooting/` はFAQの `#help` を含む既存FAQへ誘導する。単独の中継ページは残さない。
- 日本語のカテゴリ構造は大項目15と独立レシピ12を維持し、196操作、178掲載スロット、画像台帳と撮影セッションの対応を変更しない。
- 翻訳版は既存の操作本文を維持し、重複するHelp/Contact終端だけを取り除く。
