## 52原本の再評価

- **47標準原本：3.5.0撮影対象へ昇格。** 筆記、ページ、資料配置、AI要約貼付、付箋、ポモドーロ、レーザー、ナビゲーション／パレット設定等。次版の指描画を待つ必要はない。
- **5標準原本：引き続き個別画面を保留。** R-M21 / R-M23はプラン画面へ混在する未確認の販売・本番情報、R-M25 / R-M27 / R-M28は採用OSと外部アプリの実画面を確認する必要がある。
- 上記5枚に加え、もともと安定画面扱いだったOS入口R-M24 / R-M26も実画面確認待ちとする。標準110の内訳は**撮影可能103、個別確認待ち7**。今回はどちらも撮影していない。
- 任意24原本は標準110と混ぜず維持。原本ごとの判断はimplementation-map.jsonのmastersに記録した。

「撮影可能」は公開版アプリで撮影準備へ進める意味で、撮影済み・UIを目視確認済みという意味ではない。原本を用意する際は配布build、表示状態、教材、個人情報不在を確認してから採用する。

元のPhase 1.5は変更しない。そこにある「次版で撮る」「指描画OFF」等の指示は、3.5.0撮影では適用せず、指描画項目のない公開版を使用する。

## 2026-09-23 素材選択仕様の訂正

現行ガイドでは、指描画OFF時の素材選択を1回タップ、ON時を素材の長押し後に「移動・サイズ変更」を選ぶ操作として扱う。ONのまま移動・サイズ変更へ進めるため、素材操作前のOFF切替は案内しない。ダブルタップによる固定／固定解除は廃止予定のため、長期利用する現行ガイドの標準手順には掲載しない。Phase 1 / 1.5、撮影計画、撮影実行記録は当時の履歴として変更しない。
