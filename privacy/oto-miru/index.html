プライバシーポリシー (オトミル)

本プライバシーポリシーは、オトミル（App Store 表示名: オトミル - 聞こえを字幕でサポート。以下「本アプリ」）および本公式サイトにおける、ユーザー情報の取扱いについて説明するものです。

1. 基本方針

本アプリは、テレビ、映画、身近な会話、グループ会話の音声を字幕として表示するためにマイクを使用します。

字幕本文、音声データ、会話内容、テレビ内容、映画内容を、開発者のサーバーへ送信しません。また、これらの内容をアプリ内に永続保存しません。

本アプリは、会員登録やログインを必要としません。氏名、住所、メールアドレスなど、ユーザー個人を特定できる情報をアプリ内入力として直接収集しません。

2. 本アプリが扱う情報

本アプリは、以下の情報を利用します。

  • マイク入力: リアルタイム字幕を表示するために利用します。
  • 音声認識結果: 字幕表示中の画面表示にのみ利用します。
  • 表示設定: シンプルモード、テーマ、前回選択したモードなどを端末内に保存します。
  • 無料利用時間の状態: 1 日の無料利用時間、広告視聴による追加時間、当日の広告視聴回数を端末内に保存します。
  • 広告表示状態: 字幕終了後広告の表示頻度を調整するための状態を端末内に保存します。
  • 購入状態: App Store のサブスクリプション状態を確認するために StoreKit を利用します。

3. マイクと音声認識について

本アプリは、テレビ音声、映画音声、対面会話、グループ会話を字幕として表示するためにマイクを使用します。

マイク入力は、端末上の音声認識および字幕表示のために利用します。本アプリの字幕機能として、音声ファイルや字幕本文を開発者のサーバー、または開発者が運用する外部文字起こし API へ送信しません。

音声データを録音ファイルとして保存する機能、字幕履歴を保存する機能、会話内容をあとから見返す機能は提供していません。

4. Apple のサービスについて

本アプリは、音声認識、Apple Intelligence / Foundation Models の利用可否判定、App Store のアプリ内課金、購入復元のために Apple が提供する OS / App Store の機能を利用します。

App Store での購入、返金、サブスクリプション管理、Apple ID に関する情報は Apple により処理されます。Apple による情報の取扱いについては、Apple プライバシーポリシーをご確認ください。

5. 広告について

無料版では、Google Mobile Ads SDK / Google AdMob による広告を表示する場合があります。

広告配信のため、Google または広告配信事業者が、端末情報、広告識別子、IP アドレス、広告表示・クリックなどの情報を取得または利用する場合があります。広告に関する Google の情報の取扱いについては、Google プライバシーポリシーおよびGoogle の広告に関する説明をご確認ください。

字幕本文、音声データ、会話内容、テレビ内容、映画内容を広告リクエストへ渡すことはありません。

オトミル Plus に加入している場合、アプリ内広告は表示しません。

6. 課金について

本アプリは、App Store のアプリ内課金による自動更新サブスクリプション「オトミル Plus」を提供します。

購入処理、請求、サブスクリプションの更新、解約、返金は Apple により処理されます。開発者は、クレジットカード番号などの決済情報を取得しません。

7. 端末内保存と削除について

本アプリが端末内に保存する情報は、主に表示設定、無料利用時間、広告表示頻度、購入状態の表示に必要な軽量な状態です。

字幕本文、音声データ、会話内容、テレビ内容、映画内容は端末内にも永続保存しません。

本アプリを削除すると、端末内に保存された本アプリの設定情報や無料利用時間の状態も削除されます。ただし、App Store の購入履歴やサブスクリプション状態は Apple ID 側で管理されます。

8. 第三者提供について

本アプリは、法令に基づく場合を除き、開発者が取得した個人情報を第三者へ提供しません。

ただし、広告配信、App Store の課金、OS の音声認識など、第三者が提供するサービスについては、それぞれの提供元の規約およびプライバシーポリシーが適用されます。

9. 本公式サイトについて

本公式サイトは、アプリのサポート情報、使い方、FAQ、プライバシーポリシーを掲載するために運用しています。

お問い合わせメールを送信された場合、返信のためにメールアドレスおよびお問い合わせ内容を利用します。お問い合わせ内容は、サポート対応、品質改善、不正利用防止のために必要な範囲で保管する場合があります。

10. 子どもの利用について

本アプリは、子ども向けに設計されたアプリではありません。未成年の方が利用する場合は、保護者の同意または管理のもとで利用してください。

11. プライバシーポリシーの変更

本ポリシーの内容は、法令、利用サービス、アプリ仕様の変更に応じて改定することがあります。

変更後のプライバシーポリシーは、本サイト上に掲載された時点で効力を生じます。
