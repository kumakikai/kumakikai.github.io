使用說明 (Uni:Note)

Uni:Note 使用說明。
語言:
  • Ja
  • En
  • Ko
  • De
  • Fr

Uni:Note 是一款為 Apple Pencil 手寫體驗設計的 iPad 筆記應用程式。
你可以依科目分類，並把每堂課整理在不同筆記中。

支援環境：

  • 僅支援 iPad
  • 手寫功能以 Apple Pencil 為前提設計
  • 手指操作主要用於捲動與移動照片

1. 在首頁建立科目#

從首頁的 + 按鈕建立新科目。

  • 科目名稱
  • 紙張樣式：橫線 / 方格 / 空白
  • 紙張顏色
  • 封面顏色

建立後的科目會顯示在首頁。
點選即可開啟該科目的筆記。

2. 開啟第一本筆記#

第一次開啟新科目時，會顯示第一本筆記的標題輸入。

  • 可用 OK 或 直接開始寫 開始
  • 標題輸入是選填
  • 若留空，會以日期作為標題
  • 若未確認任何內容就返回，第一本筆記不會保留

之後再次開啟時，會直接回到上次正在寫的筆記。

3. 用 Apple Pencil 書寫#

  • 手寫功能以 Apple Pencil 為主
  • 頁面會以垂直連續方式顯示
  • 在最後一頁開始書寫時，下一頁會自動新增

Uni:Note 的設計重點是打開筆記後就能直接開始寫。

4. 切換工具#

可從浮動工具列切換：

  • 筆
  • 螢光筆
  • 筆劃 / 像素
  • 復原
  • 重做

補充：

  • 工具列可拖曳移動
  • 筆可調整樣式、顏色與粗細
  • 在左手模式中可變更工具列初始位置

5. 使用 筆記列表 與 頁面列表#

可從左上角開啟 筆記列表。

  • 可用 新增筆記 在同一科目中加入新筆記
  • 新筆記標題同樣是選填
  • 若留空，會以日期作為標題
  • 在列表向左滑動，可更名、保護 或刪除

可從上方按鈕開啟 頁面列表。

  • 點選縮圖可移動到該頁
  • 長按頁面可刪除

若筆記只有一頁，頁面本身不會刪除，只會清除內容。

6. 使用 更多#

更多 選單包含以下項目：

  • 貼上照片
  • 將照片作為文件貼上
  • 貼上 PDF
  • 輸出 PDF
  • 建立題組

7. 使用照片與 PDF#

從 更多 選擇 貼上照片。

  • 可用手指移動 / 縮放
  • 雙擊可 鎖定照片 / 解除照片鎖定
  • 長按可刪除

從 更多 選擇 將照片作為文件貼上。

  • 從相機或照片圖庫選擇圖片
  • 在校正介面中調整文件範圍後確認
  • 校正後的文件會被保存，重新開啟後也會保留

從 更多 選擇 貼上 PDF。

  • 從 PDF 檔案中選擇任一頁
  • 貼到目前正在查看的頁面
  • 若該頁已有 PDF，Uni:Note 會詢問是否替換
  • 可在設定中將 PDF 貼上位置改為左側或右側

從 更多 選擇 輸出 PDF。

可輸出：

  • 只輸出這則筆記
  • 整個科目

可在 PDF 輸出背景色 中調整背景。

8. 使用 記憶功能#

請先在 設定 > 記憶 中開啟 記憶功能。

開啟後，筆記畫面的浮動工具列會顯示 記憶工具。

  • 使用 記憶標記 劃過想遮住的部分
  • 用 記憶標記橡皮擦 清除
  • 使用右上角的眼睛按鈕開啟或關閉記憶遮罩
  • 記憶遮罩關閉時無法編輯

9. 使用 問題解答助理#

先在 設定 > 學習支援 中開啟 問題解答助理。

接著在筆記畫面的浮動工具列選擇 問題解答助理。

  • 用封閉線條圈住題目範圍
  • 確認選取範圍
  • 執行 開始解答

支援公式題與 PDF 或圖片中的短題目。長文閱讀、自由作答與高度依賴圖表的題目不支援。

10. 使用 建立題組#

從 更多 選擇 建立題組。

  • 用 選擇頁面 指定目標頁面
  • 執行 建立題組
  • 用 加入 與 捨棄 檢查候選題目
  • 用 儲存題組 儲存

儲存後可從 立即複習 繼續查看。之後若要重看，可從首頁（書架）各科目下方的題組開啟。也可以在首頁長按題組將其刪除，但刪除後不會進入垃圾桶，因此無法復原。

11. 保護筆記並使用 垃圾桶#

  • 在 筆記列表 中選擇 保護 後，該筆記會變成唯讀
  • 可在設定中要求解除保護時使用生物辨識
  • 首頁的 垃圾桶 會依科目分組顯示已刪除項目
  • 可還原整個科目或個別筆記
  • 刪除頁面不會進入 垃圾桶，而是立即刪除
  • 在 垃圾桶 中永久刪除後無法復原

12. 設定與備份#

在 設定 中主要可調整：

  • 預設範本
  • 開啟上次的筆記
  • 記憶功能
  • 問題解答助理
  • 科目名稱
  • 解除保護時要求生物辨識
  • 左手模式
  • 頁首 / 頁尾
  • PDF 輸出背景色
  • 語言

在 設定 > 備份 中可使用：

  • 更新簡易備份
  • 從簡易備份還原
  • 匯出備份
  • 從檔案還原

還原後請先關閉 App，再重新開啟一次。
