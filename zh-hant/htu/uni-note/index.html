使用說明 (Uni:Note)

Uni:Note 使用說明。
語言:
  • Ja
  • En
  • Ko
  • De
  • Fr

Uni:Note 是一款以 Apple Pencil 手寫為核心設計的 iPad 筆記 App。
你可以依科目分類，並將每堂課整理成不同筆記來使用。

支援環境:

  • 僅支援 iPad
  • 手寫功能以 Apple Pencil 為前提設計
  • 手指操作主要用於捲動與調整貼附素材
  • 支援語言: 日本語 / English / 한국어 / Deutsch / 繁體中文 / Français

使用 Split View、Slide Over 與雙窗格#

Uni:Note 支援 iPad 的多視窗顯示。

  • 先開啟 Uni:Note，然後叫出 Dock
  • 從 Dock 將其他 App 或 Uni:Note 拖到螢幕側邊可使用 Split View
  • 將其他 App 或 Uni:Note 以浮動方式疊放可使用 Slide Over

若想同時開啟兩個 Uni:Note 視窗，先開啟第一個視窗，再長按 Dock 裡的 Uni:Note 圖示，選擇開新視窗的選項。
開啟第二個視窗後，可並排成雙窗格的 Split View，也可重疊為 Slide Over。

實際介面與名稱會因 iPadOS 版本不同而略有差異。

1. 在首頁建立科目#

從首頁右下角的 + 建立新科目。

  • 科目名稱
  • 紙張樣式: 橫線 / 直線紙 / 方格 / 空白
  • 紙張顏色
  • 封面顏色
  • 作為直式筆記使用（僅在選擇 直線紙 時可用）

建立後的科目會出現在首頁。
點一下即可開啟該科目的筆記。

開啟 作為直式筆記使用 後，顯示方式如下:

  • 橫向畫面: 類似跨頁顯示
  • 直向畫面: 一次顯示 1 頁
  • 捲動方向: 橫向

建立後可在首頁長按該科目並開啟 編輯。
之後可以修改科目名稱、紙張樣式、紙張顏色與封面顏色，但筆記方向建立後無法更改。

2. 開啟第一本筆記#

第一次開啟新科目時，Uni:Note 會顯示第一本筆記的標題輸入。

  • 透過 OK 或 直接開始寫 開始
  • 標題可不填
  • 若留白，會以今天日期作為標題
  • 若未確認任何內容就返回，第一本筆記不會保留

之後再次開啟該科目時，會直接回到你上次書寫的筆記。

3. 使用 Apple Pencil 書寫#

  • 手寫功能以 Apple Pencil 為前提
  • 一般筆記會以垂直連續方式顯示頁面
  • 在最後一頁開始書寫時，下一頁會自動新增
  • 一本筆記最多可有 150 頁
  • 直式筆記在直向畫面會一次顯示一頁，並以橫向切換頁面

這個 App 的設計重點，是讓你打開筆記就能直接開始寫。

4. 用雙指縮放#

在筆記畫面中，可使用雙指捏合來放大或縮小。

若在書寫中，或正在調整照片、文件照片、PDF 時不容易縮放，先把手指放開一次再重新操作即可。

5. 切換工具#

可從工具面板切換以下工具:

  • 筆
  • 螢光筆
  • 線條橡皮擦
  • 像素橡皮擦
  • 復原
  • 重做

補充:

  • 工具面板可以拖曳移動
  • 筆可使用 自動鉛筆、原子筆、簽字筆
  • 可調整筆的顏色與粗細
  • 可調整螢光筆的顏色、粗細與濃度
  • 在 左手模式 中可調整工具面板的預設位置

6. 使用 筆記列表 與 頁面列表#

從左上角開啟 筆記列表。

  • 可透過 新增筆記 在同一科目中再新增一本筆記
  • 新筆記標題也可不填
  • 留白時會以今天日期作為標題
  • 在筆記列表中向左滑動，可重新命名、保護 或刪除筆記

開啟 頁面列表 可查看目前筆記中的頁面縮圖。

  • 點一下縮圖即可跳到該頁
  • 長按頁面可刪除

若該筆記只有一頁，則頁面本身會保留，只會清除內容。

7. 使用 其他#

其他 選單包含以下項目:

  • 貼上照片
  • 將照片作為文件貼上
  • 貼上 PDF
  • 匯出 PDF
  • 建立題組

問題解答助理 目前暫時停止提供，因此現在不會顯示在設定或工具面板中。

8. 使用照片與 PDF#

在 其他 中選擇 貼上照片。

  • 可用手指移動或縮放
  • 雙擊可鎖定或解除鎖定
  • 長按可刪除

在 其他 中選擇 將照片作為文件貼上。

  • 從相機或相簿選擇照片
  • 在修正介面調整文件範圍後確認
  • 貼上後可雙擊鎖定或解除鎖定，並用手指調整位置與大小

在 其他 中選擇 貼上 PDF。

  • 可從 PDF 檔中選擇一頁或多頁
  • 開啟 分割跨頁 可將跨頁 PDF 從中央分開
  • 也可以一次貼上多個 PDF 頁面
  • 貼上後可雙擊鎖定或解除鎖定，並用手指調整位置與大小

在 其他 中選擇 匯出 PDF。

可匯出:

  • 僅此筆記
  • 整個科目

可在 PDF 匯出背景色 中切換背景為 紙張 或 白色。

9. 使用 記憶功能#

請先在 設定 > 學習支援 開啟 記憶功能。

開啟後，筆記畫面的工具面板會顯示記憶工具。

  • 用 記憶標記 標出想遮住的部分
  • 用 記憶標記橡皮擦 清除
  • 透過右上角眼睛按鈕開啟或關閉記憶遮罩
  • 記憶遮罩關閉時無法編輯

10. 關於 問題解答助理#

問題解答助理 目前為暫時停止提供的狀態。
由於正在改善 AI 功能的精度，目前不會顯示在設定或工具面板中。

當功能再次開放時，App 會透過更新通知引導你使用。

11. 使用 建立題組#

從 其他 開啟 建立題組。

  • 免費方案無法使用
  • Premium 可使用

目前 App 內，Premium 的大致額度為 每月 10 題。

基本流程:

  • 透過 選擇頁面 決定目標頁面
  • 執行 建立題組
  • 以 加入 與 捨棄 篩選候選題目
  • 用 儲存為題組 儲存

儲存後可直接從 立即複習 繼續查看。
若想之後再看，可在首頁上方切換到 題庫，再從列表中開啟。

題組可從首頁刪除，但不會進入垃圾桶，因此無法復原。

12. 保護筆記與使用 垃圾桶#

  • 在 筆記列表 中選擇 保護 後，筆記會變成唯讀
  • 可在設定中要求解除保護時進行生物辨識
  • 首頁中的 垃圾桶 會依科目分組顯示刪除項目
  • 可還原整個科目，也可只還原特定筆記
  • 刪除頁面不會進入垃圾桶，而是直接刪除
  • 在垃圾桶中永久刪除的項目無法復原

13. 設定與備份#

在 設定 中，主要可調整以下項目:

  • 預設模板
  • 新筆記預設底色
  • 開啟首頁 或 開啟上次的筆記
  • 自動收合工具面板
  • 記憶功能
  • 科目名稱
  • 解除保護時要求生物辨識
  • 左手模式
  • 頁首 / 頁尾
  • PDF 匯出背景色
  • 語言

在 設定 > 備份 中，可使用:

  • 更新簡易備份（Premium）
  • 從簡易備份還原（Premium）
  • 匯出備份
  • 從檔案還原

簡易備份 會使用 iCloud 進行儲存與還原。
即使沒有 Premium，仍可使用檔案型備份。

完成還原後，請先關閉 App 再重新開啟。
下次啟動時會顯示首頁。
