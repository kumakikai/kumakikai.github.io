基本資訊#

Uni:Note Pocket 是什麼樣的 App？#

Uni:Note Pocket 是 iPad 專用 App Uni:Note 的輔助 App。
你可以在 iPhone 上透過 匯入 載入 Uni:Note 建立的備份，並以唯讀方式重新查看筆記、頁面與 題組（準備中 / 預計於 v1.1.0 支援）。

我可以單獨使用 Uni:Note Pocket 嗎？#

不行。
你需要先有在 Uni:Note 中建立的備份檔。

支援哪些裝置？#

僅支援 iPhone。

需要登入或註冊帳號嗎？#

不需要。

匯入與備份#

一開始要做什麼？#

請先使用右上角的 匯入，選擇 Uni:Note 的備份。
如果這台 iPhone 已經有 Uni:Note 的 簡單備份（準備中 / 預計於 v1.1.0 支援），App 也可能直接詢問是否要立刻讀取。

可以匯入什麼？#

你可以匯入：

  • 由 Uni:Note 建立的備份 zip 檔
  • 這台 iPhone 上找到的 Uni:Note 簡單備份（準備中 / 預計於 v1.1.0 支援）

匯入時會修改原本的備份檔嗎？#

不會。
系統會先驗證你選擇的 zip，再在 App 內展開並讀取，原始檔不會被更動。

如果匯入失敗會怎樣？#

損毀或格式不正確的備份會被安全中止。
如果裝置中已經有先前匯入的資料，會保留原有資料並只顯示錯誤訊息。

有自動同步嗎？#

目前沒有。
Uni:Note Pocket 是以重新查看備份資料為前提設計的。

啟動時自動讀取 是什麼？（準備中 / 預計於 v1.1.0 支援）#

此功能尚在準備中，預計於 v1.1.0 支援。
這是 設定 > 簡單備份（準備中 / 預計於 v1.1.0 支援）中的項目。
開啟後，只有在這台 iPhone 上有可用的 Uni:Note 簡單備份（準備中 / 預計於 v1.1.0 支援）時，才會在啟動時自動讀取。

手動讀取 是什麼？（準備中 / 預計於 v1.1.0 支援）#

此功能尚在準備中，預計於 v1.1.0 支援。
這是 設定 > 簡單備份 > 手動讀取（準備中 / 預計於 v1.1.0 支援）中的動作。
你可以在想要的時候，手動讀取目前這台 iPhone 上找到的 Uni:Note 簡單備份（準備中 / 預計於 v1.1.0 支援）。

瀏覽#

匯入後可以做什麼？#

主要功能包括：

  • 從 最近使用的筆記 繼續查看
  • 瀏覽最上層列表
  • 開啟 筆記 列表
  • 查看頁面
  • 開啟 題組（準備中 / 預計於 v1.1.0 支援）
  • 顯示或隱藏記憶圖層

我可以編輯筆記或頁面嗎？#

不行。
Uni:Note Pocket 是唯讀 App。

我可以新增、刪除或重新排序筆記嗎？#

不行。
新增與編輯仍以 Uni:Note 為主。

可以複習 題組 嗎？（準備中 / 預計於 v1.1.0 支援）#

此功能尚在準備中，預計於 v1.1.0 支援。
可以。
如果匯入的備份包含 Uni:Note 儲存的 題組（準備中 / 預計於 v1.1.0 支援），你可以從首頁的 題組（準備中 / 預計於 v1.1.0 支援）開啟並重新查看。

記憶圖層是什麼？#

它是你在複習時可以切換顯示或隱藏的頁面圖層。
右側的眼睛按鈕可在 顯示記憶圖層 與 隱藏記憶圖層 之間切換。

可以放大頁面嗎？#

可以。
你可以用雙指縮放或雙擊來放大頁面。

可以從上次閱讀的位置繼續嗎？#

可以。
你可以在 從上次位置繼續 中開啟或關閉這個行為。

設定#

有哪些設定可調整？#

主要可調整的項目有：

  • 語言
  • 主題
  • 從上次位置繼續
  • 防止水平偏移
  • 科目名稱
  • 簡單備份（準備中 / 預計於 v1.1.0 支援）

科目名稱 會改變什麼？#

它會把最上層名稱切換為 科目 / 筆記 / 群組 / 類別。

有 使用說明 和隱私權政策頁面嗎？#

有。
在 App 內也可以從 設定 > 支援 > 使用說明 開啟。
