FAQ (Uni:Note)

Uni:Note 常見問題。

基本#

Uni:Note 是什麼樣的應用程式？#

這是一款 iPad 手寫筆記應用程式。
它以 Apple Pencil 書寫為核心，並可依科目整理筆記。

支援哪些裝置？#

僅支援 iPad。

一定要有 Apple Pencil 嗎？#

手寫功能以 Apple Pencil 為前提設計。
手指操作主要用於捲動與移動照片。

需要登入或建立帳號嗎？#

不需要。

筆記與頁面#

筆記標題是必填嗎？#

不是。
若建立時將標題留白，會以當天日期作為筆記名稱。

第一次開啟新科目時出現的標題輸入框是什麼？#

那是第一本筆記的標題。
如果留白後選擇 OK 或 直接開始寫，當天日期就會成為標題。

如果沒有確認任何內容就返回，建立中的第一本筆記不會保留。

可以在同一個科目中建立多本筆記嗎？#

可以。
可從筆記列表中的 新增筆記 來新增。

新頁面會如何增加？#

當你在最後一頁開始書寫時，下一頁會自動新增。

可以刪除頁面嗎？#

可以。
可在 頁面列表 中長按目標頁面進行刪除。

不過，如果筆記只有一頁，頁面本身不會消失，而是只清除內容。

可以保護筆記嗎？#

可以。
從筆記列表中選擇 保護 後，該筆記會變成唯讀。你也可以設定在解除保護時要求生物辨識。

可以更改科目名稱嗎？#

目前還不行。
但筆記標題可以從筆記列表中更改。

垃圾桶可以還原哪些內容？#

可以還原科目，以及筆記列表中的筆記。
垃圾桶會依科目分組顯示，點選科目即可查看其中的筆記。

即使整個科目被刪除，也可以還原整個科目，或只還原其中的個別筆記。
刪除的頁面不會進入垃圾桶，而是立即刪除。

照片與 PDF#

可以插入照片嗎？#

可以。
你可以用 貼上照片 一次插入一張照片。插入後可移動、縮放，並可雙擊 鎖定照片 或 解除照片鎖定。

可以插入 PDF 嗎？#

可以。
你可以選擇 貼上 PDF，並將 PDF 檔案中的一頁放到目前正在查看的頁面上。

如果該頁已經有 PDF，應用程式會詢問是否要替換。

可以匯出 PDF 嗎？#

可以。
你可以從 輸出 PDF 將 僅此筆記 或 整個科目 匯出為 PDF。

資料與儲存#

我的資料會儲存在哪裡？#

儲存在你裝置內的應用程式中。

有自動同步功能嗎？#

目前沒有。
如有需要，請使用設定中的備份 / 還原功能。

有備份功能嗎？#

有。
你可以在設定中建立備份檔，並透過檔案 App 儲存。還原功能也可在設定中使用。

還原後可以馬上使用嗎？#

還原後請先將 App 關閉一次，再重新開啟。
下次啟動會顯示書架。

限制與付費#

免費版有限制嗎？#

有。
免費版最多可建立 5 個科目，每個科目最多 3 本筆記。

Premium 版有什麼不同？#

會解除科目數與筆記數的建立限制。

設定#

可以調整哪些設定？#

主要可以調整以下內容：

  • 新筆記範本
  • 啟動時開啟
  • 科目名稱（科目 / 筆記本 / 群組 / 分類）
  • 解除保護時要求生物辨識
  • 左手模式
  • 標頭 / 頁尾顯示
  • PDF 背景色
  • 語言

可以更改「科目名稱」嗎？#

可以。
在設定中的 科目名稱 裡，你可以改成 科目 / 筆記本 / 群組 / 分類。

左手模式可以調整什麼？#

你可以調整工具列初始位置、橫線紙紅色邊線的位置，以及 PDF 貼附位置。

要在哪裡開啟使用說明頁面？#

可從 設定 中的 支援 進入 使用說明。
